# v0.6 tables, figures, and production sources

The Markdown links PNG previews. Identically named PDFs under `v0.6_assets/` provide vector artwork. The independent audit directory is `reports/local_independent_review/results/` at the audit parent commit. From the repository root, run `python -B paper/v0.6_assets/build_displays.py --paper paper/UARCap_paper_v0.6.md` for the figures and five machine-filled table blocks. The plots show zero-based absolute scores or zero-centered comparisons, and comparable panels share axes where they measure the same units.
