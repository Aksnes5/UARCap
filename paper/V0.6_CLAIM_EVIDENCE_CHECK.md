# Claim and evidence check

Paper inferences use `official_ptb` rows from the independent audit. Archived exact-value and historical uncertainty records remain available separately.

| Claim in v0.6 | Verification and scope |
| --- | --- |
| 1,091,712 FULL clips, 345,437 sources, six nested manifests | `corpus_clip_manifest_audit.json` counts list membership and confirms all adjacent subsets. The two legacy caption-group counts do not establish production index occupancy. |
| 48 configurational means, k=1 highest in 11/12, k=7 in 0/12 | Exact study cells in `summary.json` and selection counts in `output_audit_summary.json`. Observation from dependent settings, not a vote count of independent runs. |
| Main grid has no BH discoveries | `bh_frozen_p_values.csv` replays .15894 and the 72-test independent PTB family in `summary.json` gives .16486. |
| Exploratory cell-average D/CF budget and three-way endpoint contrast | Verified in `paired_contrasts.csv`, family `exploratory`. The +1.59 contrast loses nominal significance after the 47-test adjustment. |
| Changes in selected access and weak alignment with generation | `top1_churn_downstream.csv` joins the selected X-CLIP input scores, source/clip IDs and formal query scores. D uses its `_sims` file rather than the quality-score slot of `_cap`. Observed corpus chain only. |
| Test-set response across datasets | `paired_contrasts.csv`, family `benchmark`. MSR-VTT D3−D7 +1.80 [0.86, 2.76], source q .0007. MSVD +9.86 [5.49, 15.05], source q .0003. D1−D3 is positive after family correction in both. The MSVD seven-example result is budget extrapolation. |
| Oracle gain and joint prefix penalty | `oracle_query_integrity.csv` verifies the actual stored ordering. `paired_contrasts.csv` and `refit_idf_sensitivity.json` reproduce both effects with source clustering and separate Oracle-family correction. With 76 pooled tests the query q for both is .1368. |
| Tail compatibility declines without a measurable rank association with loss | `oracle_and_rank_summary.json` gives prefix means and PTB Spearman association. Observed association cannot exclude quality, redundancy or composition effects. |
| Modality, source and auxiliary controls | `paired_contrasts.csv`, `mechanism` and `loo`. Visual interval gives useful mean-effect precision for the tested compact fusion. Text, source, tail and ordering intervals have wider scope. No validated independent integration mechanism, global visual harmlessness, source reversal, or rank-specific toxicity. |
| Output length, trigram overlap and CIDEr/SPICE divergence | `output_behavior.csv`, reproduced authoritative outputs. The independent MSVD lexical audit lacks its original input CAP artifact. SPICE trends are frozen secondary scores and do not verify video facts. |
| Adaptive comparison and no-evidence boundary | Archived router reads raw similarity and supplies D prefix. The frozen Adaptive condition has no established advantage over D1. Both external test sets compare positive budgets; B is in-domain retrieval and does not identify the no-retrieval contrast. |
