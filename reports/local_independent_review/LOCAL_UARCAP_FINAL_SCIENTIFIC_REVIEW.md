## 1 实验可信度和真正稳健的发现

- **结果可信度。** POST_FIX 评测链的 64 个 val497 主及机制单元格和 7 个 val150 LOO 单元格与正式 CIDEr 表匹配，test2690 与 MSVD 的 11 个单元格也匹配保存的指标。已重跑 CIDEr 评测与统计推断，训练、生成和大规模索引本身按代码与证据产物审查。帧 bug 影响 PRE_FIX val497/150 生成，前稿的显著文本效应和显著 source interaction 失去依据。
- **统计实现。** 历史配对采用空格分词，正式表采用 PTB；编辑时统一为正式 PTB 路径并注明 IDF、来源聚类和比较家族。旧主表最小 BH q=.15894，`0.30+` 为报告错误。独立复算及新探索性聚合均没有主网格家族的校正显著结果。不要把同一查询、相同排序前缀及嵌套库当作独立重复。
- **跨基准效用。** test2690 D3−D7 +1.80、MSVD +9.86 均在来源聚类 CI 和各自的多重校正下支持较小预算。D1−D3 两边也成立，MSVD 的后者最贴合训练预算。固定 k 下扩大库的稳定生成增益未建立，选定相似度及覆盖代理与效用没有稳定同步改善。
- **Oracle。** 用 GT unigram fixed-reference TF-IDF 排序，归档候选的一致性逐条验证。正式 PTB Oracle3−D3 +3.04、Oracle7−Oracle3 −2.73，来源级 CI 分别 [+0.85,+5.27]、[−4.72,−0.80]，各自在 4 项 Oracle 家族中稳健；与 72 项主网格合并校正则均不过阈。相同排序增加四条较低兼容证据且同时改变视觉候选。因果可落到整体输入干预，候选质量、set composition、视觉及文本作用的独立贡献仍未识别。尾部兼容度相关接近零只约束这一代理的单调关系。

## 2 新颖性、主张及投稿竞争力

前作已做质量重排、检索视频融合和 k=1–10 的 in-domain 扫描，也解释过多证据可能稀释。第二篇的独立科学贡献在于 **实际外部规模–预算联合刻画、两基准的冻结预算响应、可回放的参考辅助选择及多证据行为诊断**。只报告六尺度扫描相对于前作偏增量。讨论需用修复后行为证据写出哪些增加候选数量的做法有效，哪些干预还不能辨别机制。

撤回或降级：独立的 `selection + textual integration` 因果证明、显著文本主效应、确认的域反转、`position excluded`、毒尾/HardWrong 机制确证、“外部好于无检索”、Adaptive 优于最佳固定 k、k 随规模单调变化、SPICE 等于语义正确。保留：Oracle 同池选择空间；条件于样本和固定框架的 Oracle 前缀效果；跨基准复现的外部预算响应；覆盖代理提高而生成无稳定改善的描述性证据。

| 投稿层级 | 判定依据 |
|---|---|
| Q4 | 作为透明的固定框架诊断及实证研究，已有可成稿的证据与复验材料 |
| Q3 | 条件性竞争力。核心必须由未调试数据上的预算效应与明确边界的 Oracle 诊断托住；对外部检索本身效用作主张时需匹配 k=0。删掉旧 overclaim 后，机制创新的强度低于先前判断 |
| Q2 | 当前竞争力不足。一个继承框架、一个外部库、机制未解耦及污染/人工质量核验有限，难以给出强泛化或新机制结论 |

## 3 缺陷分级与最多两项补实验

| 等级 | 缺陷与处理 |
|---|---|
| P0 | 修复前后的结果混用、历史配对与正式评分口径混写、BH 摘要错误、Oracle 误称标准 CIDEr；正文与统计附录先全面更正 |
| P0 | 若使用独立因果机制作为标题/摘要主张，现设计缺关键控制；现稿改为整体输入行为可继续 |
| P1 | 匹配 k=0 缺失、来源/质量/训练预算混杂、Oracle 执行时精确命令与输入 hash、去重计数的生产见证缺失。按目标保留限制和人可复现配置 |
| P2 | adaptive 选择偏差、SPICE 与词汇匹配分歧、各负结果精度、先验与事后比较归类。移动到完整表及补充讨论 |
| P3 | 术语、编号、PRE/POST 图表标签和运行元数据陈述统一 |

若预算只能支持最多两项，优先做 **同架构同帧同提示空位的匹配 k=0**，回答外部检索自身有无收益。若仍希望论文以机制为主，则做 **固定视觉、匹配文本质量/冗余的 3→7 干预**，独立于选取规则，预先冻结效应阈值、来源聚类和四项以内主要比较。若接受描述性诊断定位，第二项不作为改稿前置条件。本次审计未启动这两项。

可结束的探索：继续筛 72 项挑显著配置、重复平铺相邻库规模和 k、用更多同类排名尾掩码追显著、在同一验证集上重调 adaptive 映射、沿 PRE_FIX 设置对应机制或重复耗费在旧渲染器。最小充分下一步是先完成主张分级与改稿，然后按论文想回答的问题决定是否运行上述两项。
