# 01 统计实现与独立复算

审计在 Windows 本地完成，使用已冻结的逐样本预测及内嵌参考描述。对比逐视频对齐，并验证每个配置没有重复 ID、空输出或参考描述漂移。`val497`、`test2690`、`MSVD670` 和 `val150` 分别使用 9,940、53,800、27,763 和 3,000 条参考描述。本文所有 CIDEr 差值均为 ×100 后的 points。

## P0 多重比较错误与评分口径

1. 对冻结 `AUDIT_MAIN_GRID_STATS.json` 的 72 个已打印 p 值直接执行 BH 排序、反向累积最小值及截断。16 个 raw p < .05，最小 q = **.15894**，q < .05 的个数为 **0**。独立 q 与冻结 JSON 四位小数最多差 0.00005。`6bd9aee` 同时引入该 JSON 和声称最小 q 为 `0.30+` 的 `reports/post_fix/AUDIT_03_STATISTICAL_REVALIDATION.md`。后者的例子中确有约 .32 的个别 q，无法据此确定误写的实际操作。能确定的是报告摘要错误，排序调整数组可复现。
2. 从样本重新跑 10,000 次随机化时，两种分词各有 15 项 raw p < .05，最小 q 均为 .16486，仍 0 项 FDR 显著。历史报告使用 2,000 次模拟且输入 p 经打印舍入。临界 p 项对种子和重复次数敏感，应保留历史原 p 与独立复算为不同结果。
3. 历史 POST_FIX paired 脚本将原始字符串直接送入冻结的 `Cider` 类，评分器内部空格切词。正式表经过 Stanford PTB 3.4.1、小写和标点清洗，再用同一 `Cider` 类。此次通过原 JAR 和冻结 Python 评分器复算正式路径。val497 的 64 个正式全样本配置均在旧表的两位小数容差内，最大误差 0.004993。test2690 与 MSVD 的 11 个配置也匹配保存的单元格，在浮点精度内重合。旧 paired 差值与单元格减法的差异主要由分词路径解释，另有区间、p 值的蒙特卡洛误差。

| 配对对比 | 历史报告 Δ / p | 本地空格 Δ / p | 正式 PTB Δ / p | PTB 95% source-cluster CI |
|---|---:|---:|---:|---:|
| Oracle3 − D3 | +3.04 / .0096 | +3.044 / .0077 | +3.041 / .0079 | [+0.85, +5.27] |
| Oracle7 − Oracle3 | −2.78 / .0076 | −2.778 / .0077 | −2.726 / .0088 | [−4.72, −0.80] |

正式 PTB 两项在单独四项 Oracle 家族内均经 BH（q=.01760）及 Holm 校正后保留。来源级 sign-flip p 分别 .0073/.0068，BH q 均约 .0146。把 Oracle 和整张主网格合成 76 项的敏感性分析后，两项 query-level q 均为 .1368。分开报告 Oracle 家族需要以独立诊断问题为依据，不应把它们写成整次研究的全局校正结果。没有找到正式预注册时间戳。

## 推断单位与 corpus-level IDF

冻结的 COCO 风格 CIDEr 实现使用 1–4 gram、词频逆文档权重、剪裁余弦和长度惩罚。文档单位是查询的全部参考集合，预测之间共享同一参考 IDF。固定 IDF 时正式表等于逐查询分数平均，可对同查询差值做 bootstrap 与 sign-flip。按查询置换需要差值符号对称或标签可交换的工作假设。复用来源视频的查询不应当作完全独立，这里同时按来源共同翻转，并用抽样聚类内查询数给每个样本集重新加权。MSR-VTT 来源来自带校验指纹的公开镜像，val497 为 361 个、test2690 为 2,004 个，均 100% ID 匹配。MSVD 来源从冻结视频名中严格解析为 522 个。

若目标是对未来参考语料重估的 CIDEr 作推断，IDF 此时是统计量的一部分，不能只固定原分数重采样。对两项 Oracle 反差，另以 999 个来源级样本同时运行固定与每次重拟合 DF 的 bootstrap。独立稀疏实现与冻结逐样本评分最大差约 2.3e−13 points。重拟合区间分别为 **[+0.78,+5.30]** 和 **[−4.87,−0.94]**，同批抽样的固定区间 [+0.81,+5.35] 和 [−4.75,−0.80]，结论不变。其余比较的区间条件于冻结参考 IDF。参考依赖使得 BLEU 等非加性语料级指标不能套用此处的 CIDEr 重采样；未提供其推断。

`results/bh_frozen_p_values.csv`、`paired_contrasts.csv`、`*_per_query.csv`、`metric_reconciliation.csv` 和 `refit_idf_sensitivity.json` 保留逐项结果及两套口径。似然或机制解释不由 p 值单独决定。
