# 02 Oracle 排序、实际输入与因果解释

**Oracle3 相对 D3 的选择空间成立，Oracle 同序 7 对 3 的总输入效应也成立。两者的设计没有分离候选内容、数量、视觉融合与文本利用。**

## 排序与执行证据

- 归档 `external_val_top20.json` 与 raw sims 逐条对应。用 `scripts/oracle_fixeddf.py` 的可核对规则独立重写并回放全部 497×20 个候选，Oracle1/3/7 和 Good/Hard/Easy 的各 497 个查询均逐顺序匹配 caption、clip-id list 和实际 raw X-CLIP scores。D7 的 ROUGE-L 重排也 497/497 匹配，Oracle 和 D 都完全在同一 top20 候选池中。
- Oracle 使用正则 `[a-z0-9']+` 小写 unigram、每个参考句一个 DF 文档、9,940 个文档和 5,924 个观察到的词。权重为计数 × log(N/df)，未见词 df=1。候选和每个参考向量归一化后平均余弦，平分按 raw 顺序打破。GT 用于排序，prompt 从相应候选文本取前缀；生成 JSON 的 `captions` 是评估参考，不能把该字段误当提示内容。独立回放确认数值实现，官方 CIDEr 的 PTB 分词、1–4 gram 和长度惩罚只用于下游评分。
- Git 中存在同名输出的两套生成路径。`scripts/build_oracle_distractor_val.py` 用重复查询参考的 global-batch `Cider` 回写 Oracle7 和三类尾部文件。`scripts/oracle_fixeddf.py` 回写同名文件，并为 Oracle1/3 复用 7 条列表。历史登记已标旧路径 `INVALID_ORACLE_SCORER`。当前归档基线的路径与后一脚本完全一致，源码和排序归档在 `7ecc6c55ec9e62023c80402f5f8d6dbb7550df40` 可追溯，POST_FIX Oracle manifests 记录 `d9f3ae96aa60bce2bf7c9f19f27cb488eca59e91`、命名输入及结果目录。没有可核查时间戳或服务器执行时输入 hash 证明那一次运行使用了哪个进程或没有临时覆盖。应写成归档排序已完整重现，执行时 lineage 仍有限定。
- 归档三档 Oracle cap 与 sims 对每个查询完全相同。`--topn` 使其实际消费为 1/3/7 严格前缀。D1/3/7 同样从 D7 切前缀。对 D，应从独立 `_sims.json` 读取融合权重，`_cap.json` 第二列是 ROUGE 质量值。生成器以 caption 查找 sims、选对应 clip 后聚合。Oracle3→7 同时增加文本和候选视频输入，融合后 token 数可保持固定。相同 k 的 Oracle−D 同时改变候选顺序和所选邻居视觉内容。已有 runner 把 checkpoint、prompt、beam、seed 和特征目录固定；未复跑模型、未比较缓存张量哈希。

## 质量衰减、相关与具体样本

头 3 条与后 4 条的平均兼容度为 .13801 和 .10314，相差 .03487。按 rank 1–7 依次为 .15587/.13501/.12314/.11394/.10597/.09926/.09337。衰减平滑，后四条质量较低；这仍可能贡献平均下滑。head−tail 与 Oracle3−Oracle7 相关在旧空格口径为 **ρ=.0394，p=.3806**，正式 PTB 为 **ρ=.0458，p=.3077**，聚类 95% CI [−.044,+.131]。如果只用 tail 平均，PTB ρ=.0104，CI [−.069,+.087]。60.4% 查询的 CIDEr 差为零。分半均值受幅度与极端值影响，PTB 高/低衰减组均值差异为 +5.06/+0.38 points，应与秩相关并列而不可择优。兼容度与 CIDEr 均为词汇/参考代理，视频语义、补充与冗余、候选联合质量没有单独量化。一次相关检验不能排除平均尾部效应，也不构成中介分析。

## 可以说到哪里

直接支持：参考辅助排序在 k=3 改善固定系统表现；保持该排序时七条输入在同 497 条查询上差于三条；两项均有固定/重拟合 IDF 和来源依赖敏感性支持。可假设：结果与候选选择空间和多证据利用成本同时存在一致。需撤回：独立因果瓶颈已建立、质量衰减已被排除、或视觉没有影响。现有 PTB Text×Visual 对比对原主张不充分。真正区分需要固定视觉输入并匹配新增文本的质量、相关性和冗余，在输入数量不同但其余条件控制的设计中比较。
