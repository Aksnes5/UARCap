# 从 v0.6 到 v0.7 的科学论证变更

| 问题 | 旧证据能支持什么 | v0.7 的裁决与依据 |
| --- | --- | --- |
| 启用外部证据有无净收益 | v0.6 的正预算端点可比较哪种配置更好。零证据比较缺失。 | **新增受控主张。** A1−A0 为 +1.40，五项 Holm p=.0165。只适用于当前冻结检查点和供证方式。A0 仍有查询视频、提示和可学习融合路径。 |
| 七条证据是否带来净损失 | 历史 D7 低于 D1，无法相对零点定向。 | **家族限定。** A7−A0 为 −1.54，A 族 Holm p=.0271，五项 p=.0813。跨实验的核心结论仅把七条描述为均值低于零点。 |
| 统计效应是否具有明确实际意义 | 原预算比较没有这个新协议下的决策。 | **阈值限定。** 五个预定比较没有任何一个同时满足校正显著且区间整体越过 ±1 点。避免“普遍显著提升”“已证明至少损失一点”等表述。 |
| 新增文本能否充分解释联合预算损失 | 修复后的 497 查询 Text×Visual 主效应有较宽区间，早期退化解码所得强机制裁决已撤回。 | **受控方向性证据。** 三个视觉张量及融合结果匹配。两种文本扩展分别为 −1.27 和 −1.13，B 族校正均未通过。保留对具体扩展的估计，删除“已证实外部文本整合过载”及中介解释。 |
| 相关性与尾部质量 | 旧 HardWrong/EasyWrong 估计不足以区分两组。 | **保留不确定性。** 同数量的 HQ−LQ 为 −0.14 [−1.05, +0.80]。相似度分组不能当作人工质量标签。无法断言两组等效、低相关必然更坏或相关性无用。 |
| 规模与跨基准 | POST_FIX 六尺度的候选改善与生成变化不同步；两个测试基准上短联合前缀占优。 | **保留既有证据层次。** 验证网格为探索性。MSVD 的七条超过其训练预算。A/B 仅在 MSR-VTT 上执行。 |
| Oracle 与备选机制 | 三条参考辅助选择有余量，延长其前缀仍降低效用；对更大检验家族敏感。 | **范围不扩张。** 候选由固定参考 unigram TF-IDF 兼容度重排，生成用正式 PTB CIDEr 评价。不能由 Oracle 分离文本数量、内容与视觉融合效应。 |
| 创新边界 | Displays 前作已研究预算、文本重排和跨门控，历史较短预算优于较长预算本身不足以形成独立创新。 | **重定位。** 贡献落在外库规模与效用的联结、相对零证据的净效用、张量验证的文本干预及其推断边界。当前 D 的全字幕 ROUGE-L 共识近似与前作名词短语伪标签方案有别。相似度间隙策略维持既有基线身份。 |

v0.7 保留原始稿和冻结协议，重写摘要、引言、讨论、限制和结论，把 A/B 放入主要结果。历史正预算端点和新 A1/A7 共用评测样本并有相同输出，不叠加为独立样本或重复发现。历史解码缺陷、修复后不显著的替代解释和家族依赖性均继续披露。[全文](../../paper/UARCap_paper_v0.7.md) · [正式配对统计](FOLLOWUP_FIVE_TEST_HOLM_RESULTS.csv)
