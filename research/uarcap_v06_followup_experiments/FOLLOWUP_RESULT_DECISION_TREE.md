# Decision rules for follow-up results

## Entry rule

Use these branches only for complete runs that pass the fixed trace and reference checks. Interpret a discovery using Holm-adjusted source sign-flip tests. State the point estimate and source interval, with 1.0 CIDEr point as the predeclared practical threshold. Inconclusive intervals are reportable outcomes. Store results under a new prospective study version after execution.

## A. Value of filling the external evidence slots

- **A1 > A0 with adjusted evidence.** A small external D budget improves the inherited system relative to matched null external input. Strong practical evidence requires its interval above +1.0. If A7 does not improve, anchor deployment discussion to the small-budget setting.
- **Both A1 and A7 > A0.** Retrieval adds value in both tested settings. Preserve the separate fixed-budget result for A1 versus A7 from existing evidence. The effect concerns input exposure for this checkpoint.
- **A0 exceeds one or both retrieval arms.** Report a disadvantage of those particular external settings. A difference may depend on the learned use of the null slot and cannot establish the effect of training a separate no-retrieval model.
- **Intervals remain wide or cross zero.** Keep utility relative to no evidence unresolved. If intervals lie within the predeclared practical band, report a bound on effect size for those conditions without an equivalence claim.

## B. Caption-only extensions with fixed retrieved visuals

- **HQ and LQ each decrease relative to Text3.** Two specified caption extensions can harm output with the retrieved visual input held fixed. Quantity and added content remain jointly changed.
- **LQ decreases and HQ fares better at the same count.** Only a corrected HQ−LQ difference supports different responses to relevance bands. With a precise near-zero HQ extension, the data support importance of the added text under this protocol. A significant LQ comparison and a nonsignificant HQ comparison by themselves do not establish an interaction.
- **HQ improves or the bands show an unexpected ordering.** Report that finding with actual assignments and uncertainty. Relevance is a visual proxy and could correlate with semantics, wording and template effects.
- **Three wide or near-zero intervals.** Report lack of detectable improvement or harm with the corresponding precision. The Oracle joint prefix loss can still depend on altered candidate and visual composition. A residual subword-token imbalance restricts the interpretation of the HQ–LQ comparison under every branch.

For a Q3 submission, A closes the central baseline omission with the lowest interpretive burden. B contributes more to a mechanism-centered paper if its fixed-visual protocol passes and estimates are precise. Either can be appended as new evidence after completion. v0.6 remains a separate frozen article based on the prior evidence.
