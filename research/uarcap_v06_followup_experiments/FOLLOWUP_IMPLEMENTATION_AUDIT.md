The builder takes only the archived retrieval records and two query manifests. Its B tails carry empty clip associations and all B arms share identical SIM rows for the first three captions. The tests implement a NumPy tensor double to exercise actual hook calls, including the three feature loads, aggregation, attention inputs and prompt length. This establishes adapter logic on CPU. Tensor digests from the real PyTorch process and device determinism remain execution checks. Visual digest mismatch fails closed before writing a scored result.

Pre-extracted query frame TSVs, label/caption files and offsets under the archived test YAML were not opened on BN. Archive and deployment receipts have different scope. The archived YAML identifies the inputs. Actual server availability, count, size and hash will be receipted before execution. Exact path configuration is supplied in a separate deployment JSON and never added back to the frozen evaluator.
