## 摘要与核心设计判断

现有 UARCap `v0.8` 稿件已经形成一篇证据完整、统计严谨、可复现的实证诊断论文，具备直接作为 SCI Q3 投稿备选方案的成熟度。然而，若希望将其提升至具有扎实竞争力的 SCI Q2 研究，当前稿件面临四个结构性瓶颈：其一，核心结论高度依赖 n-gram 表面指标 CIDEr，未能揭示外部检索在视频语义事实层面究竟“纠正了什么”与“污染了什么”；其二，实验 B 虽严密锁定了视觉中间张量，但受限于原始 X-CLIP 相似度带的窄间隔（均值 `0.00835`）与多重校正边界，未能将大预算退化清晰归因于具体语义机制；其三，核心干预仅在单一 2023 年代跨门控架构（Video-LLaMA / Vicuna-7B）与单一已反复分析的 MSR-VTT 基准上完成；其四，面对 2024–2026 年迅速成熟的多模态检索效用文献（尤其是 Luo 等 ACL 2026 的效用导向视觉证据选择与 Li 等 ACL 2024 的检索鲁棒性研究），简单堆叠一个新的重排器或门控模块不仅缺乏独立创新，还面临显著的算力公平性陷阱与过拟合风险。

针对 ChatGPT 提出的六条初步升级构想，本文进行了独立红队审查与 2023–2026 年最新文献核查，提出**保留并重塑“检索诱发的事实状态转移”与“跨接口/跨基准验证”，严格重构“受控原子事实干预”以避免重演历史 `HardWrong` 失败模式，同时对“事后最优预算上界”和“新增轻量级证据选择模块”施加硬性止损门控**。在此基础上，本文将零散构想统一收敛为**方案 III：外部检索增强视频描述的“证据效用—事实风险联合框架”（Evidence Utility–Factuality Risk Framework）**，围绕单一核心科学问题建立 4 项可证伪假设（H1–H4）与 5 层递进式实验（E1–E5），并明确区分最低成本诊断升级（路线 A）、完整 Q2 竞争方案（路线 B）与止损回归 `v0.8` Q3 投稿（路线 C）。本文稿不预设任何新方法必然有效，所有新实验均设有先验数据隔离规则与阶段性停止阈值。

## 1. 研究背景与现有成果

检索增强生成（Retrieval-Augmented Generation, RAG）在视频描述任务中常隐含两项未经充分检验的工程假设：其一，扩大外部视频—字幕记忆库规模能够提供更接近查询视频的候选样例，从而单调提升生成质量；其二，向生成器提供更多检索到的外部样例能够带来更丰富的语义支撑。然而，视频本质上是动态时序事件流，两段在全局视觉表征（如 X-CLIP）上高度相似的视频片段，往往在关键动作谓词、参与者角色、动作方向或事件结果上存在根本差异；当多条由机器自动生成的外部字幕与对应视觉特征共同注入冻结的多模态解码器时，检索可得性的提升与下游描述质量之间并不必然存在正相关。

围绕这一问题，UARCap 迄今已完成从百万级嵌套外部记忆构建、验证集视频解码缺陷修复、独立本地复算审计到预注册受控干预实验（实验 A 与实验 B）的完整证据链，并固化为 `v0.8` 投稿稿件。在规划任何 Q2 升级方案之前，必须首先确立**现有科学事实的不可逾越边界**，禁止以“升级研究”为名推翻或淡化已冻结的统计事实：

1. **嵌套百万级外部语料与“检索可得性—生成效用解耦”**：基于 VideoUFO 构建六个严格嵌套的外部片段清单（`10K`、`50K`、`100K`、`250K`、`500K`、`FULL = 1,091,712` clips，覆盖 `345,437` 个 YouTube 来源视频），并经精确来源 ID 审计确认与 MSR-VTT 训练/验证/测试划分零重叠。在修复后的 MSR-VTT 验证集（`val497`，`361` 个来源簇）上，将语料从 `10K` 扩至 `FULL` 使 `494/497`（CF 原始排序）与 `495/497`（D 全句成对 ROUGE-L 共识重排近似）查询的 top-1 候选发生更替，所选 top-1 X-CLIP 相似度分别单调上升 `+0.0259` 与 `+0.0319`；然而固定预算下的下游生成 CIDEr 在整个 72 项验证网格中无一通过 Benjamini–Hochberg（BH）校正（最小查询级 BH $q = 0.1649$），且查询级相似度变化与 CIDEr 变化的秩相关几乎为零（$\rho = .011$ / `.007`）。
2. **跨基准联合证据预算梯度与前作训练区间区分**：在排除 300 条开发先导样本后的 MSR-VTT 测试集（`test2690`，`2,004` 来源簇，继承检查点原训练预算 $k = 7$）上，联合图文预算从 `D1` 扩至 `D7` 呈单调下降（`71.21 → 70.08 → 69.48 → 68.27`，`D1 − D7 = +2.93`，`95%` 来源聚类 CI `[+1.83, +4.06]`，BH $q = .0007$）。在 MSVD 测试集（`test670`，`522` 来源簇，原训练预算 $k = 3$）上复现同样下降趋势（`156.39 → 151.45 → 144.39 → 141.59`），其中训练区间内的 `D1 − D3 = +4.94`（`[+1.50, +8.39]`，$q = .0069$）构成无预算外推混杂的跨基准证据，而 `D3 − D7 = +9.86` 明确界定为超出原训练预算的外推压力测试。基于相邻相似度落差的受限 Adaptive 基线在两基准上分别取得 `70.67` 与 `151.94`，均未超过固定 `D1`（MSVD 上显著落后 `−4.46`）。
3. **预注册实验 A（匹配零外部证据对照，MSR-VTT `n = 2,690`, `2,004` 来源簇）**：在保持完整 prompt 骨架、查询帧张量、cross-gating 融合路径、模块状态与解码参数逐查询一致的前提下，空外部输入 `A0`（`0` 条文本、`0` 条检索视觉特征、跨注意力 K/V 确认为精确零张量）得分为 `69.81` CIDEr；单条外部图文对 `A1` 为 `71.21`，七条图文对 `A7` 为 `68.27`。配对来源聚类推断显示：**`A1 − A0 = +1.40`（`95%` CI `[+0.45, +2.36]`，原始 $p = .0033$，A 族内 Holm $p = .0066$，五检验联合 Holm $p = .0165$）**，确立了当前研究最稳健的新增实证结论——单条外部证据确实带来优于零外部输入的条件性净收益；而 **`A7 − A0 = −1.54`（`[−2.94, −0.18]`，原始 $p = .0271$）** 仅通过 A 族内 Holm（$p = .0271$），未通过五检验联合 Holm（$p = .0813$）。此外，`A1`/`A7` 在全部 2,990 条输出记录上与历史 `D1`/`D7` 完全一致，仅构成端点复现核验，不可重复计作第二份独立样本。
4. **预注册实验 B（固定视觉中间表示的文本扩展，MSR-VTT 合格子集 `n = 2,618`, `1,969` 来源簇）**：逐查询运行时 trace 证实 `B3`、`B7HQ` 与 `B7LQ` 三组加载的 3 条检索视觉特征张量、原始相似度权重、融合聚合张量、注意力 K/V、门控输入与视觉投影完全一致。在 `B3`（`69.88`，平均 prompt 长度 `150.69`）基础上追加 4 条长度与重叠度匹配的较高或较低原始 X-CLIP 相似度文本后，`B7HQ` 为 `68.62`（`226.86` tokens），`B7LQ` 为 `68.75`（`226.38` tokens）。配对效应 `B7HQ − B3 = −1.27`（`[−2.34, −0.20]`，原始 $p = .0191$，族内 Holm $p = .0573$，五检验 Holm $p = .0764$）与 `B7LQ − B3 = −1.13`（`[−2.15, −0.14]`，原始 $p = .0306$，族内 Holm $p = .0612$，五检验 Holm $p = .0813$）呈一致负向但均**未通过预定 B 族 Holm 校正**；高低相似度带直接对比 `B7HQ − B7LQ = −0.14`（`[−1.05, +0.80]`，$p = .7698$）无定论。实验 A 与 B 全部五项对比均未满足预定的“校正显著且 95% 区间完全越过 `±1.0` CIDEr”实践清晰标准，且因两实验参考 IDF 分别在各自队列拟合，绝对均值不可跨实验比较。
5. **修复后历史诊断链与可复用资产**：解码器修复后，验证集 Oracle 重排仍显示存在同池选择空间（`Oracle3 − D3 = +3.04`, $q = .0146$）且 `Oracle7 − Oracle3 = −2.73`（$q = .0146$，但该对比同时改变条数、候选池衰减兼容度与视觉特征，不能单独归因于文本过载）；而 18 项验证机制对照（包括 `T × V` 因子、匹配域内对照、顺序反转、`GoodTail`、`HardWrong`、`EasyWrong`）与 8 项 `val150` 留一对照在修复后均未通过 BH 校正。与此同时，BN 服务器（RTX A6000 48GB）已固化 VideoUFO 百万级数据、X-CLIP 索引、冻结模型权重、以及 6 组正式 A/B 实验共 17,940 条预测与逐查询 trace（6 组全程实测耗时仅 `11.2245 GPU 小时`），为下一阶段低成本精准分析提供了极高复用基础。

## 2. 当前论文（v0.8）的科学瓶颈

将 `v0.8` 置于偏重方法论普适性、机制深度或评价范式创新的 SCI Q2 期刊审稿标准下审视，可以识别出四个决定其当前上限停留在“扎实 Q3 诊断论文”的深层科学瓶颈。这些瓶颈决定了 Q2 升级究竟应该解决什么问题，而不是盲目堆砌更多实验。

**第一，表面词面指标（CIDEr）与真实视频语义之间的解释鸿沟。** `v0.8` 的所有主要推断均建立在 PTB CIDEr 之上，尽管正文如实报告了描述性输出变化（`test2690` 从 `D1` 到 `D7` 平均词数由 `7.92` 增至 `8.75`，与所供外部字幕并集的 trigram 匹配率由 `0.142` 飙升至 `0.334`，甚至对固定 top-1 的匹配率也从 `0.142` 升至 `0.190`，且历史 SPICE 反而微升而 CIDEr/BLEU/ROUGE-L 下降），但单凭 CIDEr 的 `+1.40` 或 `−1.54` 变动，审稿人无法回答最核心的视觉语言问题：*`A1` 相对 `A0` 究竟是纠正了视频动作/实体错误，还是仅仅提供了更贴近 MSR-VTT 语料风格的词面模板？`A7` 相对 `A0`/`A1` 究竟是引入了外部字幕中的错误事实（事实污染），还是因为句子变长偏离了参考句长分布而被 CIDEr 高斯长度惩罚？* 只要缺乏经过人工校准的原子级视频事实性证据，这篇论文的诊断深度就始终停留在“得分波动”而非“多模态语义因果”。

**第二，机制归因停留在“排除若干假说后的不确定区间”，尚未完成正向因果识别。** 历史验证集机制实验在修复帧加载缺陷后全军覆没（0/26 通过 BH 校正），实验 B 虽然在工程控制上无懈可击（逐查询哈希锁定视觉张量），但因为受限于同一 top-20 候选池内匹配四元组的窄相似度间隔（`0.00835`），既未能确认文本扩展的家族级显著性，也未能把“相似度代理”与“真实语义相容/冲突”剥离开来。因此，`v0.8` 诚实但被动地以“大预算损失的精确机制仍属开放问题”收尾。对于 Q3 期刊，这种高度自律的负结果与边界报告是加分项；但对于 Q2 期刊，审稿人通常会追问：*既然已知 X-CLIP 相似度带分离度太窄、无法识别语义机制，作者为何不进一步在真正分离“视频支持 vs. 视频冲突”的语义维度上进行受控识别？*

**第三，单架构、单零点基准与旧模型年代带来的外推脆弱性。** 现有核心证据（A 与 B）全部锚定在 2023 年代的 Video-LLaMA + Vicuna-7B + cross-gating 冻结检查点上，连 MSVD 都尚未补齐匹配的 `k = 0` 对照。随着 2024–2026 年原生多帧长上下文视频大语言模型（如 Qwen2.5-VL、LLaVA-Video、InternVL2.5）成为主流，Q2 审稿人极易质疑：`A1 > A0 > A7` 以及外部检索的效用—风险权衡，究竟是外部检索增强视频描述的共性规律，还是特定于旧式 32-token cross-gating 架构与特定微调检查点的局部伪影？

**第四，反复分析同一 `test2690` 队列带来的确认性推断透支。** MSR-VTT `test2690` 已经经历了多轮历史预算评估、Adaptive 对比、v0.6 协议设计与 v0.7 A/B 检验。正如 `FOLLOWUP_STATISTICAL_ANALYSIS_PLAN.md` 已诚实指出的，在该队列上继续提出新假说、调优新阈值或验证新方法，本质上都属于条件于已观察基准的后验验证，难以满足 Q2 期刊对独立外部泛化的严格要求。

## 3. 最接近的已有研究与创新性缺口

为避免闭门造车或重复发表，本轮对 2023–2026 年四大相邻领域开展了系统文献核查，并对每篇关键文献的作者、发表年份、会议/期刊、证据单位、干预方式与评价指标进行了逐一核实（完整对照表见附录 `CLOSEST_PRIOR_WORK_MATRIX.md`）。

### 3.1 四大相邻领域的真实前沿进展

1. **检索增强图像/视频描述与检索鲁棒性**：前作 Fang 等（*Displays*, 2026）提出基于 X-CLIP 检索、质量感知重排与跨门控融合的域内视频描述框架；早期工作如 Open-Book（Zhang 等，CVPR 2021）、RA-Transformer（Sarto 等，CBMI 2022）、SmallCap（Ramos 等，CVPR 2023）、EgoInstructor（Xu 等，CVPR 2024）、CM²（Kim 等，CVPR 2024）、HiCM²（Kim 等，AAAI 2025）和 Sali4Vid（Jeon 等，EMNLP 2025）主要聚焦架构与记忆设计。与 UARCap 诊断视角最接近的论文是 **Li 等（ACL 2024）《Understanding Retrieval Robustness for Retrieval-Augmented Image Captioning》**，该工作在静态图像描述模型 SmallCap 上操纵检索字幕的排序与相关性，结合输入归因揭示了模型倾向于直接复制多条检索字幕中的“多数派词元（majority tokens）”并由此产生幻觉，进而提出多样化采样训练缓解该问题。但该研究限于**静态图像与纯文本检索**，未涉及视频动态动作/时序事件，未控制多模态检索视觉特征张量，也未在零外部证据反事实下对事实纠错与事实诱错进行对称解构。
2. **多模态检索效用导向选择、选择性利用与自适应截断**：这一方向在 2024–2026 年竞争已极为拥挤！**SURf（Sun 等，EMNLP 2024）** 训练多模态大模型选择性利用检索信息并忽略噪声上下文；**SePer（Dai 等，ICLR 2025）** 与 **Sufficient Context（Joren 等，ICLR 2025）** 在文本 RAG 中从语义困惑度降低与上下文充分性角度定义检索效用；**Adaptive-k（Taguchi 等，EMNLP 2025）** 利用相似度分布几何落差实现无阈值动态截断；**SpecUBench（Zhang 等，arXiv 2025 / CIKM 2026）** 揭示检索效用具有显著的生成器特异性（LLM-specific utility）；最为关键的是 **Luo 等（ACL 2026, arXiv:2605.13277）《Utility-Oriented Visual Evidence Selection for Multimodal Retrieval-Augmented Generation》**，已经直接将信息论意义下的效用增益用于多模态 RAG 的免训练视觉证据重排与筛选（评测于 MRAG-Bench 与 Visual-RAG）。这一最新文献事实发出明确预警：**若 UARCap Q2 升级把核心创新押注在“提出一个通用的效用感知重排器/动态证据选择器”，将与 Luo 等（ACL 2026）、SURf（EMNLP 2024）和 Adaptive-k（EMNLP 2025）发生正面撞车。**
3. **多模态检索干扰与上下文噪声**：**Cuconasu 等（SIGIR 2024）**、**Liu 等（TACL 2024）** 探讨了文本 RAG 中的噪声与位置效应；**MAD-RAG（Zhao 等，ICML 2026）** 在多模态大语言模型视觉问答任务中诊断了检索引发的注意力分散并提出缓解机制。但这些研究以多模态 QA/精确答案抽取为主，尚未覆盖自由文本视频描述中“信息增量 vs. 事实污染 vs. 原有信息遗漏”的复杂权衡。
4. **视频描述事实性与幻觉评估**：该领域在 2023–2026 年已建立成熟的原子事实与误差解构范式，包括 **FactVC（Liu & Wan, EMNLP 2023）**（首个面向自由文本视频描述的事实一致性人工标注集与评价指标）、**FaithScore（Jing 等，EMNLP Findings 2024）**（描述子句识别 → 原子事实分解 → 视觉核验三步法）、**EventHallusion（Zhang 等，2024）**（事件/动作级语言先验幻觉）、**VideoHallucer（Wang 等，2024）**（内在/外在幻觉分类）、**VidHalluc（Li 等，CVPR 2025）**（高相似低差异视频对上的动作、时序与场景转换幻觉）、**ARGUS（Rawal 等，ICCV 2025）**（面向自由文本视频描述的 `ArgusCost-H` 幻觉与 `ArgusCost-O` 遗漏双指标），以及 **CapQuiz（Wang 等，ACL 2026）**（基于视频问答的 `CapP` 事实精确率 / `CapR` 信息覆盖率 / `CapF1`）。**关键缺口在于：上述所有视频事实性基准都只评测“无检索的独立 Video-LLM”的内生先验幻觉，无一将其用于诊断“检索增强视频描述中，外部检索证据相对零证据反事实如何双向改变视频事实正确性”！**

### 4.2 四大核心方法学隐患的专题解剖

#### 4.2.1 “动作相容性”为何过于狭窄，应采用何种视频事实表示？
仅围绕“动作相容性（action compatibility）”建构理论存在两处明显失真：首先，真实视频描述（MSR-VTT、MSVD、VATEX、VideoUFO brief）中的检索误导不仅发生在动词/动作上（例如将“切菜”误导为“炒菜”），也频繁发生在**核心实体**（将“吉他”误导为“小提琴”）、**参与者角色与动作对象**（“狗追猫” vs. “猫追狗”）、**显著属性**（颜色、数量、室内外场景）以及**时序/事件结果**（“投篮未中” vs. “投篮得分”）；其次，若反过来发明一套包含十余类子标签的庞大事件本体（如精细角色框架、子事件因果图），在每段 10–15 秒的短视频和平均 8–10 词的简短字幕上根本无法获得可靠的人工标注者间一致性（Krippendorff's $\alpha$ 会急剧崩塌）。

结合 **FactVC（EMNLP 2023）**、**FaithScore（EMNLP 2024）**、**VidHalluc（CVPR 2025）** 与 **ARGUS（ICCV 2025）** 的成熟实践，最适配当前视频描述数据与人工标注可操作性的方案是**紧凑四类原子视觉命题表示（Compact Four-Facet Atomic Visual Claims）**：
1. **实体/对象（Entity / Object）**：画面中出现的具体人物、动物、物体或明确场景载体；
2. **属性/状态（Attribute / State）**：实体的视觉可观察外观属性、数量或静态状态；
3. **动作/事件及其论元角色（Action / Event & Role）**：核心动态谓词及其主语/宾语/工具关系（对应原“动作相容性”的核心，但自然纳入施事—受事角色）；
4. **时序与事件结果（Temporal Order / Outcome）**：先后顺序、动作方向或可见状态变化结果。

该表示既避免将多模态事实狭隘化为单一动作维度，又与主流视频幻觉文献完全对齐，且一条 8–12 词的视频字幕通常仅拆解出 **2–4 条可独立核验的原子命题**，人工标注负担可控、一致性高。

#### 4.2.2 “拒绝检索”为何不是独立新模块，应如何界定其理论地位？
检索文献中常混用五种完全不同的操作，必须严格区分：
- **检索前跳过（Pre-retrieval skipping）**：不调用检索器（节省检索 I/O）；
- **检索后弃用 / 零证据工作点（Post-retrieval abstention / $S = \emptyset$）**：执行了检索并审视候选池，但决定向生成器提供空外部证据；
- **候选剔除（Candidate filtering）**：从候选池 $C$ 中删除特定高风险项；
- **早停（Budget early stopping）**：在已选前缀 $S$ 基础上停止追加新项；
- **回答拒答（Generation abstention）**：模型拒绝生成视频描述（输出“无法判断”）。

当前 `A0` 对应的严格来说是**冻结融合架构内的零外部证据工作点**，而非一种“拒绝检索算法”。若分别设计“检索门控器 + 冲突过滤器 + 早停器”，不仅在架构上显得拼凑冗余，还会招致“把成熟 gating 包装成新概念”的审稿批评。规范的做法是将上述四种证据侧决策统一为单一决策空间 $\mathcal{S}(C) = \{S \subseteq C : |S| \le B\}$ 中的子集选择问题（其中明确允许 $S = \emptyset$），而将“是否值得开发自动决策器”本身交由前置诊断门控来决定。

#### 4.2.3 “错误传播”的因果识别条件与混杂排除
在自然检索样本中观察到“检索字幕 $c \in S$ 包含错误事实 $f^*$，且生成字幕 $y(v, S)$ 也包含 $f^*$”，**绝不能自动声称发生了“检索错误传播”**。至少存在六类竞争性解释：
1. **生成器固有先验**：即使在 $S = \emptyset$ 时，模型基于查询视频模糊画面也会凭语言先验说出 $f^*$；
2. **查询视频自身歧义**：低分辨率或快速剪辑导致人类自身都难以判定 $f^*$ 是否存在；
3. **同域高频共现**：检索器与生成器均倾向使用该领域的常见模板动词（如“playing”、“talking”）；
4. **文本模板与句长效应**：加入外部文本改变 prompt 长度与句式习惯，间接诱发更激进的猜测，而非针对性复制 $f^*$；
5. **语义编辑不自然伪迹**：人工改写反事实字幕时若破坏语言流畅度，模型可能因异常文本触发分布外退化；
6. **多模态图文失配混杂**：若修改了外部字幕 $c_i$ 的语义，但仍保留其原始视频特征 $v_i$，则该外部样例内部产生了“图—文不一致（cross-modal mismatch）”的新混杂，模型表现下降可能源于“外库内部图文打架”，而非“外部字幕与查询视频冲突”。

因此，操作上必须严格区分为两级证据：
- **观察级关联证据（Observational Retrieval-Aligned Error Shift）**：以同一视频的零证据输出 $y(v, \emptyset)$ 为配对基线，仅当 $f^* \notin y(v, \emptyset)$、$f^* \in y(v, S)$、$f^*$ 被视频核验为 `Contradicted`、且 $f^*$（或其语义等价命题）存在于 $S$ 中时，才记录为“检索对齐的新增错误（retrieval-aligned newly introduced error）”；
- **干预级因果证据（Interventional Targeted Contamination Effect）**：必须在**逐查询锁定相同视觉输入**（且在文本—视觉解耦条件下消除内部图文打架）的前提下，比较长度与流畅度严格匹配的 **Video-Supported (`Sup`) vs. Video-Contradicted (`Con`) vs. Video-Neutral (`Neu`)** 三臂对**同一目标事实 $f^*$ 采纳率**的配对差异，且表述严格限定在**行为级输入—输出因果效应（behavioral input–output causal effect）**，绝不臆测内部神经元或注意力权重机制。

#### 4.2.4 事后最优预算上界（Oracle Budget Upper Bound）的统计幻觉与检验方法
ChatGPT 路线一建议对每个查询取 $\max_{k \in \{0,1,3,5,7\}} \text{CIDEr}(v, k)$ 来估计“个性化预算上界”。这是一项典型的**统计陷阱**：单条视频的 CIDEr 对微小措辞变化（甚至单复数、冠词或一个低频词）高度敏感，噪声方差远大于跨预算的真实平均效应（实验 A 中配对标准差约为 `24–25` CIDEr 点，而真实均值差仅 `1.40` 点！）。当我们在 $K=5$ 个策略中按事后得分取最大值时，极值统计量天然产生巨大的**选择乐观偏差（Winner's Curse）**——即便五个策略的真实质量完全相同、仅存在独立随机扰动，$\mathbb{E}[\max_{k} \varepsilon_k]$ 仍会虚增数个乃至十余个 CIDEr 点！

因此，任何事后预算上界分析都必须同时执行两项反幻觉检验（纳入 E1）：
1. **参考集劈半交叉验证上界（Split-Reference Cross-Validated Ceiling）**：MSR-VTT 每条查询拥有 20 条人工参考句，可随机劈分为不相交的两组 10 条参考句（$R_1, R_2$），在 $R_1$ 上为每条查询挑选最优预算 $k^*(v; R_1)$，却在**独立的 $R_2$** 上评估该选择的真实得分！这样立刻剥离单条参考句采样引起的指标噪声膨胀；
2. **零假设置换基线与推理前折外预测（Null Permutation & Out-of-Fold Pre-Inference Predictability）**：将跨臂预算标签在视频内部随机置换估计纯噪声上界，并在来源簇分组交叉验证下检验仅凭推理前可观测特征能否显著超越固定 `A1`/`D1`。若劈半上界极小或推理前无可泛化预测信号，则直接否定“开发复杂动态预算器”的立项依据！

### 4.3 与历史失败机制实验（GoodTail / HardWrong / EasyWrong / Oracle / B）的实质差异审查

基于本轮对 `reports/local_independent_review/audit_retrieval.py` 源码的核查，历史 `GoodTail7`、`HardWrong7`、`EasyWrong7` 与 `Experiment B` 均未能确证“候选语义质量导致生成退化”，其深层原因如下表所示。任何新的受控干预实验（E3）必须逐一消除这些根本缺陷，否则就是“给旧失败实验换个新名字”：

| 对比维度 | 历史 `GoodTail / HardWrong / EasyWrong`（`val497`） | 历史 `Experiment B`（`test2618`） | 新设计 `Experiment E3`（受控原子事实干预） |
|---|---|---|---|

## 5. 统一科学问题

通过上述文献缺口定位与红队剖析，我们不再将“动作相容性、事后上界、事实错误、拒绝检索”拼凑成四个松散话题，而是将其收敛为一个层次清晰、可形式化、可证伪的统一科学问题：

> **核心科学问题（Unified Research Question）**：  
> **在面向大尺度外部记忆的检索增强视频描述中，外部证据预算与候选事实相容性如何共同决定相对于零外部证据基线的“净效用—事实风险前沿”（即真实信息增益/事实纠错与检索诱发事实污染/信息遗漏之间的权衡），单条原子事实冲突在视觉受控条件下是否因果地驱动目标事实污染，以及这一效用—风险权衡在不同多模态证据接口之间如何迁移？**

该核心问题自然分解为四个递进子问题，与后续实验体系形成严格一一映射：

- **SQ1（异质性与可分性）**：在冻结系统中，`A1 > A0 > A7` 的平均净效用背后，是否存在扣除参考句采样噪声后的真实查询级效用异质性？这种异质性在推理前是否具有可泛化的可预测信号？
- **SQ2（对称事实状态转移）**：超越表面词面指标 CIDEr，启用外部证据（$k = 1$ 与 $k = 7$）相对于零外部证据（$k = 0$）究竟如何改变生成描述的原子级视频事实结构——真实信息增益与事实纠错能否抵消检索诱发的事实污染与原有正确事实遗漏？
- **SQ3（视觉受控的原子事实因果敏感性）**：在逐查询锁定视觉输入、匹配文本长度与语言自然度并引入中性对照的条件下，将外部字幕中的单一视频支持事实替换为视频冲突事实，是否因果地提高对应错误事实的生成概率？这一效应在自然检索冲突样本中是否同样成立？
- **SQ4（跨接口迁移与决策空间边界）**：上述“净效用—事实风险”权衡在补齐 MSVD 零外部证据对照以及迁移至现代原生视频大语言模型（如 Qwen2.5-VL-7B-Instruct）和未触碰外部确认队列后，呈现何种架构共性与接口差异？在严格同算力约束下，统一子集决策空间 $S \subseteq C$（含 $S = \emptyset$）能否形成优于固定小预算的帕累托前沿？

## 6. 基本概念、形式化框架与操作性定义

本节遵循“最小必要原则”（Occam's Razor）：只保留可操作测量、彼此正交且直接支撑科学假设的概念，明确剔除冗余或不可可靠观测的构念（完整核查表见附录 `CONCEPT_DEFINITION_AND_MEASUREMENT_MATRIX.md`）。

### 6.1 基本符号系统

对任意查询视频 $v \in \mathcal{V}$，记：
- $C(v) = \{(c_1, \tilde{v}_1, s_1), \dots, (c_M, \tilde{v}_M, s_M)\}$ 为外部检索器返回的固定 top-$M$（本文 $M = 20$）候选集合，其中 $c_i$ 为外部简短字幕，$\tilde{v}_i$ 为对应外部片段视觉特征，$s_i$ 为原始跨模态相似度；
- $S \subseteq C(v)$ 为实际提供给生成器的证据子集，**允许空集 $S = \emptyset$**（对应架构匹配零外部证据工作点）；
- $G$ 为固定参数与解码配置的视频描述生成器，$y(v, S) = G(v, S)$ 为生成的自由文本描述；
- $\mathcal{A}(y) = \{a_1, \dots, a_m\}$ 为由标准化拆解规程从字幕 $y$ 中提取的**四类原子视觉命题集合**（实体、属性、动作/论元角色、时序/结果）；
- $\phi(a \mid v) \in \{\mathrm{Sup}, \mathrm{Con}, \mathrm{Unc}\}$ 为以真实查询视频 $v$ 全片画面为真值依据的三值视觉蕴含判定函数，分别表示被视频明确支持（Supported）、与视频明确冲突（Contradicted）或依据当前视频画面无法确认（Unverifiable / Uncertain）。特别规定：**未在人工参考字幕中出现不等于 `Con`；`Unc` 严禁与 `Con` 合并**。同时严格区分候选字幕对其*来源视频* $\tilde{v}_i$ 的保真度 $\phi(a \mid \tilde{v}_i)$ 与其对*当前查询视频* $v$ 的事实相容性 $\phi(a \mid v)$——外部检索的核心风险往往源于 $\phi(a \mid \tilde{v}_i) = \mathrm{Sup}$ 而 $\phi(a \mid v) = \mathrm{Con}$（即外部字幕本身没有错，只是不适用于当前查询视频）。

### 6.2 五个核心操作性定义（含通俗解释）

#### 定义 1：净表面效用与净事实效用（Net Utility Vector）
对于给定证据子集 $S$，相对于同一生成器在零外部证据下的输出 $y_0 = y(v, \emptyset)$，定义二维净效用向量：
$$\Delta U_{\text{lex}}(v, S) = \text{CIDEr}(y(v, S), R_v) - \text{CIDEr}(y_0, R_v)$$
$$\Delta U_{\text{fact}}(v, S) = \text{FactPrec}(y(v, S) \mid v) - \text{FactPrec}(y_0 \mid v)$$
其中 $\text{FactPrec}(y \mid v) = \frac{|\{a \in \mathcal{A}(y) : \phi(a \mid v) = \mathrm{Sup}\}|}{|\{a \in \mathcal{A}(y) : \phi(a \mid v) \in \{\mathrm{Sup}, \mathrm{Con}\}\}|}$（对可判定原子命题计算事实精确率，并同步单独报告 `Unc` 比例，避免隐藏不可核验表述）。  
**通俗解释**：不再只看 CIDEr 涨跌，而是同时衡量“启用证据集合 $S$ 后，相对于不给任何外部证据时，词面一致性变好了多少、可核验事实的准确比例变好了多少”。需要明确的是，该净效用条件于当前冻结生成器 $G$ 及零输入接口定义，不同模型架构间不假定数值可比，仅比较方向与前沿形态。

#### 定义 2：条件边际效用（Conditional Marginal Utility）
在已提供证据子集 $S$ 的条件下，追加单个候选 $e \in C(v) \setminus S$ 带来的条件边际效用定义为：
$$\Delta_U(e \mid v, S) = U(y(v, S \cup \{e\})) - U(y(v, S))$$
**通俗解释**：同一条外部字幕在单独提供（$S = \emptyset$）时可能很有帮助，但在已有 3 条相似或冲突字幕（$|S| = 3$）之后再加入，可能毫无增益甚至造成伤害。**严禁默认该集合函数满足可加性、单调性或次模性（submodularity）**；它仅作为集合级诊断概念，用于检验“前缀扩展成本”。

#### 定义 3：检索诱发的四元事实状态转移（Retrieval-Induced Factual Transition Quadruple）
将同一查询视频 $v$ 在零外部证据 $y_0 = y(v, \emptyset)$ 与有证据 $y_S = y(v, S)$ 的原子命题集合进行语义对齐后，对每一查询定义四个对称且互不重叠的事实转移计数（并可标准化为每视频发生率）：
1. **事实纠错（Factual Correction, $\mathrm{Corr}(v, S)$）**：$y_0$ 中存在与视频冲突的错误命题 $a^- \in \mathcal{A}(y_0)$（$\phi(a^- \mid v) = \mathrm{Con}$），在 $y_S$ 中被消除或替换为同一语义槽位上的视频支持命题 $a^+$（$\phi(a^+ \mid v) = \mathrm{Sup}$）；
2. **真实信息增益（Grounded Gain, $\mathrm{Gain}(v, S)$）**：$y_S$ 中新出现且被视频明确支持的正确事实 $a^+ \notin \mathcal{A}(y_0)$（$\phi(a^+ \mid v) = \mathrm{Sup}$），且并非对已有错误的替换；
3. **事实污染 / 诱错（Factual Contamination, $\mathrm{Contam}(v, S)$）**：$y_S$ 中新出现与视频明确冲突的错误命题 $a^- \notin \mathcal{A}(y_0)$（$\phi(a^- \mid v) = \mathrm{Con}$）；在观察性数据中进一步标记其中与外部证据 $S$ 语义对齐的子集为**证据对齐诱错（Evidence-Aligned Contamination, $\mathrm{Contam}_{\text{align}}$）**，用以区分“外部直接引入”与“提示扰动诱发的非对齐幻觉”；
4. **原有正确事实遗漏（Grounded Omission, $\mathrm{Omit}(v, S)$）**：$y_0$ 中原本存在且被视频明确支持的正确事实 $a^+ \in \mathcal{A}(y_0)$，在 $y_S$ 中消失。

**通俗解释**：这四个指标把“检索到底对视频描述做了什么”彻底摊开在阳光下——它既可能帮你**改错**或**补充真实细节**（正向收益），也可能把**外部错误带进答案**或让你**丢掉原本看对的画面信息**（负向风险）。这种对称记账彻底避免了只看幻觉或只看 CIDEr 的片面性。

#### 定义 4：目标事实定向污染效应（Targeted Factual Contamination Effect, TFCE）
在受控原子事实干预实验（E3）中，设某查询视频 $v$ 上选定一个视频明确支持的靶事实 $f^+$ 及其最小语义冲突版本 $f^-$（$\phi(f^- \mid v) = \mathrm{Con}$），在锁定视觉输入与文本长度/自然度的条件下构造三条干预证据 $S_{\text{Sup}}(f^+)$、$S_{\text{Con}}(f^-)$ 与 $S_{\text{Neu}}$。定义目标事实定向污染效应为：
$$\mathrm{TFCE} = \mathbb{P}\big(f^- \in \mathcal{A}(y(v, S_{\text{Con}}))\big) - \mathbb{P}\big(f^- \in \mathcal{A}(y(v, S_{\text{Neu}}))\big)$$
并同步度量**靶事实保真损失**：
$$\mathrm{TFFL} = \mathbb{P}\big(f^+ \in \mathcal{A}(y(v, S_{\text{Sup}}))\big) - \mathbb{P}\big(f^+ \in \mathcal{A}(y(v, S_{\text{Con}}))\big)$$
**通俗解释**：如果给模型看包含冲突事实 $f^-$ 的外部字幕后，模型说出 $f^-$ 的概率显著高于给它看同长度中性无关字幕 $S_{\text{Neu}}$（且高于零证据基线），这就构成了无需臆测内部神经机制的、干净的**行为因果证据**，证明外部文本事实冲突确实诱发了对应事实错误。

#### 定义 5：受约束证据子集决策空间与效用—风险前沿（Evidence Decision Space & Utility–Risk Frontier）
将所有证据操作统一表示为在给定算力/成本上界 $\tau$ 下选择策略 $\pi: (v, C(v)) \mapsto S \subseteq C(v)$（允许 $S = \emptyset$），满足 $\mathrm{Cost}(\pi) \le \tau$。任意策略 $\pi$（包括固定 $k=0, 1, 3, 7$、相似度阈值过滤、Adaptive-$k$ 或候选轻量风险过滤器）均映射到二维平面上的一个操作点：
$$\Big(\underbrace{\mathbb{E}[\mathrm{Contam}(v, \pi) + \mathrm{Omit}(v, \pi)]}_{\text{事实风险 } R(\pi)},\;\; \underbrace{\mathbb{E}[\mathrm{Corr}(v, \pi) + \mathrm{Gain}(v, \pi)] \text{ 或 } \mathbb{E}[\Delta U_{\text{lex}}(v, \pi)]}_{\text{净效用 } U(\pi)}\Big)$$
**通俗解释**：不同检索策略的优劣不再用单一 CIDEr 小数点后两位的微弱波动定胜负，而是看它在同算力条件下能否把“事实风险—真实效用”帕累托前沿向外推进。实际部署时，真实效用 $U$ 和真实风险 $R$ 永远是**不可见的评价目标**，策略 $\pi$ 只能依赖推理前可观测代理信号（如跨模态相似度几何特征、候选间一致性、轻量视觉蕴含打分等）。

### 6.3 概念必要性审查与主动精简

经过逐项审查，我们主动**剔除或降级**以下四个在初步构想中冗余、失焦或不可可靠测量的概念：
1. **剔除“独立动作相容性指标”**：纳入四类原子视觉命题中的“动作/论元角色”子维，避免以偏概全；
2. **剔除“检索拒绝模块 / 早停模块 / 过滤模块”的三分命名**：全部收拢至统一子集决策空间 $S \subseteq C$（允许 $S = \emptyset$）；
3. **剔除“内部注意力分散 / 神经级文本过载”作为主要理论构念**：当前实验体系属于行为级输入—输出识别，不宣称识别内部注意力学机制（与 MAD-RAG 清晰划界）；
4. **降级“事后单指标 CIDEr 预算上界”**：不再作为理论核心，仅保留其**参考集劈半交叉验证版**作为 E1 探索性门控诊断指标。

## 7. 候选研究路线比较

在完成文献审查、红队批判与概念收敛后，本节系统比较四条截然不同的研究路线，以帮助作者与导师在“科研创新度、审稿风险、算力与人工成本、失败兜底能力”之间做出理性权衡。

### 7.1 四条候选路线概述

- **方案 I（深化诊断研究）**：不开发任何新选择算法，专注于在现有资产上完成 E1（效用异质性与劈半上界）+ E2（双盲人工原子事实转移评测）+ E3（视觉锁定最小配对原子事实干预）+ E5（MSVD $k=0$ 与一个现代 Video-LLM 验证），构建一篇纯粹的机制诊断与评价研究论文。
- **方案 II（诊断驱动的证据选择方法）**：以推出一个“兼具事实相容性检验、边际效用预测与零证据决策的轻量级证据选择器”作为论文核心卖点，前面诊断仅作为动机铺垫，重头戏放在 E4 方法超越各类基线。
- **方案 III（证据效用与事实风险联合框架，推荐主方案）**：以“外部检索在视频描述中的净效用—事实风险权衡前沿”作为统一理论与实证核心。不预先绑架论文必须由某个新算法打败所有基线，而是把**对称事实转移框架（Corr / Gain / Contam / Omit）**、**视觉锁定最小配对因果干预（TFCE）**、**统一决策空间帕累托前沿评测**与**跨架构接口比较（Cross-Gating Video-LLaMA vs. 原生视频 VLM）**融为一体；并在未触碰外部确认队列上完成严格验证。是否激活轻量风险过滤策略（E4）受 E1/E2/E3 前置门控严格约束，即便最强简单策略就是“固定 $k=1$ + 极简高风险剔除”，整篇论文依然构成完整、可发表的 Q2 贡献。
- **方案 IV（门控式“诊断转轻量策略”两阶段路线，推荐备选方案）**：在阶段 1（E1 + E2 试点）执行硬性量化门控；若且仅若证实推理前特征对检索风险/收益具有稳定折外预测力（例如 AUROC $\ge 0.68$ 且在同算力约束下相对 `D1` 有望降低 $\ge 25\%$ 事实污染而不损真实信息增益），才进入阶段 2 构造一个极简、免微调、同算力公平的校准式零证据/风险决策器（E4）；否则自动退回方案 III 或路线 C（止损投 Q3）。

### 7.3 推荐决策结论

**明确推荐以“方案 III（证据效用与事实风险联合框架）”为主方案，以“方案 IV（门控式诊断转轻量策略）”为备选扩展路径，并始终保留“路线 C（冻结 `v0.8` 直接投稿 SCI Q3）”作为理性止损底线。**

核心理由有三：首先，方案 III 精准避开了 2024–2026 年最拥挤的“通用效用重排器/选择性微调”赛道（Luo 等 ACL 2026、SURf EMNLP 2024），将主战场锚定在没有任何已有工作系统解决的**视频检索增强对称事实转移 + 视觉锁定最小配对因果识别 + 跨接口效用—风险前沿**；其次，它完全继承 `v0.8` 的所有冻结成果（无需浪费此前 11.2 GPU 小时与严密统计审计），把增量资源全部集中在真正决定 Q2 档次的三个缺口上（原子事实核验、最小配对因果控制、第二架构与未触碰确认队列）；最后，方案 III 具有极强的抗风险韧性——即便最终发现检索风险难以在推理前被复杂模块精准预测，论文关于“外部检索如何双向改写视频事实”及“固定小预算/极简门控在帕累托前沿上的支配地位”的发现，依然具备扎实的 Q2 发表价值。

## 8. 推荐的研究框架

基于方案 III，我们将整项 Q2 升级研究组织为一个**四层递进的统一科学架构**：

1. **第一层：零外部证据锚定的“表面效用 × 原子事实转移”双轴观测框架（继承 `v0.8` + 新增 E1/E2）**  
   以架构匹配的零外部证据输出 $y(v, \emptyset)$ 为共同反事实原点，不再只把预算扫掠看作一条一维 CIDEr 曲线，而是将其展开为两条耦合轨迹：词面一致性轨迹 $\Delta U_{\text{lex}}(v, S)$，以及由 $\big(\mathrm{Corr}, \mathrm{Gain}, \mathrm{Contam}, \mathrm{Omit}\big)$ 构成的对称事实转移轨迹。由此可以直接检验：`A1 − A0 = +1.40` 的净增益中，究竟有多少来自真正的事实纠错与信息补充，又有多少伴随了潜在事实污染；而 `A7 − A0 = −1.54` 究竟是事实污染加速压倒了真实信息增益，还是单纯的长度/词面漂移。
2. **第二层：视觉输入逐查询锁定的“最小配对原子事实因果识别”（E3）**  
   针对自然检索中“候选内容、长度、视觉特征、语义相关性混杂在一起”的根本难题（也是历史 `HardWrong` 与实验 B 无法突破的瓶颈），E3 继承并升级实验 B 的运行时张量哈希锁机制，在完全相同的查询视频、检索视觉中间张量与句长/流畅度条件下，仅对单一视频核验原子事实实施 `Sup / Con / Neu` 三臂最小配对干预，并辅以自然 VideoUFO 冲突检索子集作为生态效度校验，直接测量目标事实定向污染效应（$\mathrm{TFCE}$）与保真损失（$\mathrm{TFFL}$）。
3. **第三层：跨接口与未触碰队列的外部泛化检验（E5）**  
   在保持相同 VideoUFO 外部检索候选池的前提下，一方面以极低成本补齐 MSVD 匹配零外部证据对照（验证跨基准零点规律），另一方面引入一个现代开源原生视频大语言模型（首选 **Qwen2.5-VL-7B-Instruct**，Apache 2.0 协议，BF16 约 16–18 GB 显存，单张 RTX A6000 48GB 充裕运行），并在**从未参与过 `v0.1–v0.8` 分析的来源独立确认队列**（如经 YouTube ID 零重叠审计后的 VATEX 验证/测试子集）上检验核心效用—风险规律的迁移边界。正文严格界定两类架构的证据接口差异：Video-LLaMA 采用固定 32-token cross-gating 视觉融合 + 文本拼接，而 Qwen2.5-VL-7B 采用原生动态分辨率视频帧 token + 提示文本上下文拼接（可选配检索关键帧），二者检验的是**跨接口迁移规律**，绝不宣称架构等价。
4. **第四层：同算力约束下的统一决策空间帕累托前沿评估（条件触发的 E4）**  
   在同一决策空间 $\mathcal{S}(C)$ 内，将固定策略（$k=0, 1, 3, 7$）、既有无参几何规则（Adaptive-$k$、相似度阈值弃用）与（仅在 E1/E2/E3 门控通过后才引入的）轻量级免微调风险感知选择规则置于同一“事实风险—净效用”帕累托平面与严格相同算力预算下对比，报告生成器调用次数、校验器额外延迟与显存峰值，彻底杜绝“以强模型滤弱模型”的伪创新。

这一框架使整篇论文形成紧密因果闭环：**现象发现（`v0.8` 规模解耦与预算反转） → 语义解剖（E1/E2 效用异质性与四元事实转移） → 因果识别（E3 视觉锁定最小配对事实干预） → 跨接口外部泛化（E5 MSVD 零点 + 现代 VLM + 未触碰队列） → 部署前沿与门控决策（E4 帕累托权衡）**。

## 9. 核心科学假设

基于方案 III，本设计精炼确立 **4 个高度可证伪的核心科学假设（H1–H4）**，覆盖“表面—事实偏离与对称转移”“视觉锁定原子事实因果污染”“效用与风险的推理前可预测性边界”以及“跨多模态接口的迁移与分化”。每个假设均包含完整的 12 项规范要素，并预设明确的证伪标准与阴性结果解释。

### 假设 H1（检索预算的“事实污染—真实收益”非对称增长假说）
1. **理论动机**：`v0.8` 已证实 MSR-VTT 上存在 `A1 > A0 > A7` 的词面 CIDEr 排序，但单凭 CIDEr 无法判断大预算退化是否伴随真实视频事实的恶化，也无法解释历史 SPICE 微升与 CIDEr 下降的背离。若大预算下新增外部字幕引入的视频冲突命题增速超过真实信息增益与纠错增速，则“事实污染净增”将成为 `k = 1 → k = 7` 效用下滑的语义实质。
2. **形式化定义**：记每查询的净事实平衡指数为 $B_{\text{fact}}(v, S) = \big[\mathrm{Corr}(v, S) + \mathrm{Gain}(v, S)\big] - \big[\mathrm{Contam}(v, S) + \mathrm{Omit}(v, S)\big]$。假设在固定框架内，$\mathbb{E}[\mathrm{Contam}(v, S_7) - \mathrm{Contam}(v, S_1)] > 0$，且 $\mathbb{E}[B_{\text{fact}}(v, S_1)] > \mathbb{E}[B_{\text{fact}}(v, S_7)]$。
3. **预期观察**：相对于 `A0`，`A1` 呈现正向或接近中性的事实平衡（真实信息增益/纠错与污染大致平衡或占优），而 `A7` 相对 `A1` 的检索诱发事实污染（尤其是证据对齐诱错 $\mathrm{Contam}_{\text{align}}$）显著攀升，拉低原子事实精确率 $\text{FactPrec}$。
4. **自变量**：外部联合证据预算 $k \in \{0, 1, 7\}$（即冻结输出 `A0`、`A1`、`A7`）。
5. **因变量**：主要因变量为人工双盲核验的每视频检索诱发事实污染率 $\mathrm{Contam}$ 与净事实平衡 $B_{\text{fact}}$；次要因变量为 $\mathrm{Corr}$、$\mathrm{Gain}$、$\mathrm{Omit}$、`Unc` 比例与 $\text{FactPrec}$。
6. **控制变量**：查询视频、模型权重、prompt 骨架、cross-gating 路径、解码参数、人工标注盲法（标注员不知输出所属 $k$）。
7. **实验单位**：查询视频（聚合视频内原子命题后，按 YouTube 来源视频聚类推断）。
8. **主要对照**：配对对比 `A7 vs. A1` 与 `A1 vs. A0`、`A7 vs. A0`。
9. **主要统计检验**：来源聚类配对自助法（10,000 次重抽样）与双侧来源级符号翻转置换检验，族内 Holm 校正（$\alpha = 0.05$）。
10. **最小有意义效应（MDE）**：`A7` 相对 `A1` 的每视频事实污染发生率绝对增加 $\ge 5$ 个百分点（或 $\Delta \text{FactPrec} \le -3$ 个百分点）。
11. **能够反驳该假设的结果**：若 `A7` 相对 `A1` 的 $\mathrm{Contam}$ 差异接近零或为负（$95\%$ CI 完全覆盖零以下或位于 $[-3\%, +3\%]$ 窄区间），或者 `A7` 的真实信息增益 $\mathrm{Gain}$ 反而抵消了污染使 $B_{\text{fact}}(S_7) \ge B_{\text{fact}}(S_1)$。
12. **假设不成立时的科研解释**：说明 `A1 > A7` 的 CIDEr 下降主要源于**词面风格漂移、输出变长（`7.92 → 8.75` 词）触发的参考长度/n-gram 惩罚**，而非视频事实正确性恶化——这一阴性发现同样具有高度科研价值，直接揭示 CIDEr 在评估多样本检索描述时的指标失真。

### 假设 H2（视觉锁定条件下原子事实冲突的定向污染因果假说）
1. **理论动机**：历史 `HardWrong` 与实验 B 均未能把“真实语义冲突”与“视觉变化、句长变化、窄 X-CLIP 间隔”分离开。若在严格锁定视觉输入与句长/自然度的条件下，外部字幕中的单一视频冲突事实能够定向提高生成描述中该冲突事实的出现概率，则可确立多模态检索文本通道的行为因果污染机制。
2. **形式化定义**：在 E3 的三臂最小配对干预中，目标事实定向污染效应 $\mathrm{TFCE} = \mathbb{P}(f^- \in \mathcal{A}(y(v, S_{\text{Con}}))) - \mathbb{P}(f^- \in \mathcal{A}(y(v, S_{\text{Neu}}))) > 0$，且靶事实保真损失 $\mathrm{TFFL} = \mathbb{P}(f^+ \in \mathcal{A}(y(v, S_{\text{Sup}}))) - \mathbb{P}(f^+ \in \mathcal{A}(y(v, S_{\text{Con}}))) > 0$。
3. **预期观察**：相对于中性对照 $S_{\text{Neu}}$ 与零证据 $y_0$，冲突臂 $S_{\text{Con}}$ 显著提高靶错误事实 $f^-$ 被生成的比例，同时压低靶真实事实 $f^+$ 的保留率；且该效应在动作/事件类冲突与实体类冲突上均可见，并在自然检索冲突子集中得到同向外部印证。
4. **自变量**：固定文本槽位上注入的外部字幕事实关系类型（`Sup`、`Con`、`Neu`）。
5. **因变量**：主要因变量为二元目标事实采纳指标 $\mathbb{I}[f^- \in \mathcal{A}(y)]$ 与靶真实事实保留指标 $\mathbb{I}[f^+ \in \mathcal{A}(y)]$；次要因变量为整句原子事实精确率与 CIDEr。
6. **控制变量**：查询视频帧张量、逐查询哈希锁定的检索视觉特征与融合投影（或零外部视觉槽位）、prompt 骨架、文本槽位位置、词数（差 $\le 1$ 词）、流畅度盲审评分、解码随机种子。
7. **实验单位**：查询视频及其配对的单一目标事实（来源视频级聚类）。
8. **主要对照**：核心因果对照 `Con vs. Neu`（剥离纯文本/长度干扰）与 `Con vs. Sup`（总语义方向效应），辅以 `Sup vs. Neu`（验证正向支持增益）。
9. **主要统计检验**：来源聚类配对风险差自助法 CI 与配对符号翻转检验（当每簇仅 1 视频时退化为精确 McNemar 配对检验），三项主检验执行族内 Holm 校正。
10. **最小有意义效应（MDE）**：$\mathrm{TFCE} \ge +8$ 个百分点（例如 `Neu` 基线误报率 $\le 3\%$ 而 `Con` 采纳率 $\ge 11\%$）。
11. **能够反驳该假设的结果**：若 $\mathrm{TFCE}$ 不显著且 $95\%$ CI 上界低于 $+5$ 个百分点，或 `Con` 与 `Neu` 产生近乎相同的错误率上升（说明伤害主要来自无关文本长度/扰动，而非特定事实冲突本身）。
12. **假设不成立时的科研解释**：说明冻结生成器的视觉通路在单条冲突事实面前具有较强抗干扰能力，或者大预算退化主要属于多条上下文竞争引发的集合级干扰/长度稀释，而非单条原子事实的定向复制污染。

### 假设 H3（检索效用与事实风险的推理前非对称可预测性假说）
1. **理论动机**：若每条查询对检索的净效用和事实污染风险在推理前均不可预测，那么任何复杂的动态证据选择方法（包括 ChatGPT 路线四）在独立数据上都注定退化为过拟合。反之，基于跨模态相似度几何、候选集合内一致性与轻量视觉—文本蕴含代理，系统可能对“高风险事实污染”比对“微小 CIDEr 正增益”具有更强的推理前识别能力（非对称可预测性）。
2. **形式化定义**：令 $\mathbf{x}_{\text{pre}}(v, C)$ 为严格不接触参考答案与生成结果的推理前可观测特征向量。检验两项折外预测任务：（a）在来源簇分组交叉验证下，基于 $\mathbf{x}_{\text{pre}}$ 预测查询级 $\Delta U_{\text{lex}}(v, S_k)$ 的折外决定系数 $R^2_{\text{OOF}}$ 及与劈半参考上界的差距；（b）预测是否发生检索诱发事实污染（$\mathrm{Contam}(v, S) \ge 1$）的折外 $\mathrm{AUROC}_{\text{OOF}}$ 是否显著高于随机基线 `0.50`。
3. **预期观察**：受限于单句 CIDEr 的高参考采样噪声，词面净效用 $\Delta U_{\text{lex}}$ 的折外 $R^2_{\text{OOF}}$ 可能较低（若低于门控阈值则直接放弃 CIDEr 导向动态预算器）；而高置信度的检索事实污染事件（如跨模态检索分偏低且候选间核心谓词分歧大）可能呈现更有意义的折外风险识别力。
4. **自变量**：严格推理前可观测特征集（原始 X-CLIP 相似度、top-1/top-2 落差、候选池 ROUGE-L/语义一致性熵、字幕词数、以及同算力轻量视觉—文本匹配代理）。
5. **因变量**：（a）E1 中扣除参考采样噪声后的跨预算词面净效用；（b）E2 中人工核验的检索诱发事实污染二元事件 $\mathbb{I}[\mathrm{Contam} \ge 1]$ 与净收益事件。
6. **控制变量**：严格的来源视频分组划分（杜绝同一 YouTube 来源跨折泄漏）、零参考答案泄漏、固定特征抽取算力上限。
7. **实验单位**：查询视频（按来源簇分组做折外交叉验证与确认集外推）。
8. **主要对照**：固定策略基线（`A1`/`D1` 与 `A0`）、简单无参几何规则（Adaptive-$k$、单一 X-CLIP 阈值）以及置换零分布基线。
9. **主要统计检验**：来源聚类自助法评估 $\mathrm{AUROC}_{\text{OOF}} - 0.50$ 与帕累托风险降低差值，报告点估计与 $95\%$ 聚类置信区间。
10. **最小有意义效应（MDE）**：风险识别 $\mathrm{AUROC}_{\text{OOF}} \ge 0.65$（且 $95\%$ CI 下界 $> 0.58$）；若要触发 E4 轻量策略开发，需进一步满足在独立确认集上同算力相对 `D1` 降低 $\ge 20\%$ 事实污染且不造成事实精确率或 CIDEr 的显著退化。
11. **能够反驳该假设的结果**：折外 $R^2_{\text{OOF}} \le 0.02$ 且 $\mathrm{AUROC}_{\text{OOF}}$ 的 $95\%$ CI 覆盖 `0.55` 以下。
12. **假设不成立时的科研解释**：明确证明在低额外算力约束下，外部检索的逐查询风险与收益主要由深层细粒度视觉歧义决定，轻量代理无法可靠事前识别——这为工程部署提供了极其清晰的反直觉规范结论：**优先采用固定极小预算（如 $k = 1$）或直接改进底层检索器的事件级对齐，而非在推理侧堆砌复杂启发式门控模块。**

### 假设 H4（跨多模态证据接口的效用—风险迁移与分化假说）
1. **理论动机**：`v0.8` 最大的 Q2 审稿短板在于仅验证了 2023 年代跨门控融合检查点（Video-LLaMA/Vicuna-7B），且未补齐 MSVD 零外部证据基线。现代原生视频大语言模型（如 Qwen2.5-VL-7B-Instruct）拥有远强于 Vicuna-7B 的视觉感知与指令遵循能力，直接处理原生帧序列并以纯文本提示注入检索字幕。检验同一外部记忆在这两类截然不同的接口上如何表现，可以剥离“旧模型弱视觉依赖外部字幕”与“外部检索固有语义风险”的界限。
2. **形式化定义**：在共享同一 VideoUFO 外部检索候选池条件下，分别于（a）MSVD 原框架（补齐 `k = 0`）与（b）现代原生视频 VLM（Qwen2.5-VL-7B-Instruct，在未触碰确认队列及 MSR-VTT 子集上执行 $k \in \{0, 1, 3, 7\}$ 与 E3 最小配对干预）上估计净效用与事实污染斜率，检验跨接口的同向性与幅值分化。
3. **预期观察**：
   - 在 MSVD 原框架上，预测 `D1` 相对匹配 `k = 0` 的净效用方向与 MSR-VTT 类似（或受限于 MSVD 自身超高基线得分而呈现更小的边际净收益），`k = 7` 相对 `k = 0` 下降；
   - 在现代原生视频 VLM 上，由于其 $k = 0$ 自身视觉描述能力显著更强，外部检索带来的**真实信息增益/纠错空间可能更窄**（甚至 `k = 1` 相对 `k = 0` 接近中性或微弱正负），但在大预算（$k = 7$）及最小配对冲突干预（E3）下，**检索诱发事实污染（$\mathrm{TFCE} > 0$）依然存在或呈现不同的接口敏感度**。
4. **自变量**：生成器/证据接口类型（Cross-gating Video-LLaMA vs. 原生视频 VLM Qwen2.5-VL-7B）× 证据预算 $k \in \{0, 1, 3, 7\}$（及 E3 冲突条件）。
5. **因变量**：各接口内部相对于自身 $k = 0$ 的净事实转移（$\mathrm{Corr}, \mathrm{Gain}, \mathrm{Contam}, \mathrm{Omit}$）、$\mathrm{TFCE}$ 与 CIDEr 相对变化（**严格限于接口内部配对差值比较，不跨模型比绝对 CIDEr 均值**）。
6. **控制变量**：完全相同的查询视频集合、完全相同的外部检索候选池与排序规则、一致的原子事实评测规范。
7. **实验单位**：查询视频（按来源视频聚类）。
8. **主要对照**：各模型内部的 `k=1 vs. k=0`、`k=7 vs. k=0`、`k=7 vs. k=1` 及 E3 `Con vs. Neu`。
9. **主要统计检验**：各模型内部执行来源聚类自助法与符号翻转检验（族内 Holm 校正），跨接口差异通过同查询配对交互差（Difference-in-Differences）估计。
10. **最小有意义效应（MDE）**：MSVD 匹配 `k=1 vs. k=0` 设定 $\pm 1.5$ CIDEr 点；现代 VLM 的 E3 $\mathrm{TFCE} \ge +5$ 个百分点或事实污染率在 `k=7 vs. k=0` 上变化 $\ge 4$ 个百分点。
11. **能够反驳该假设的结果**：若现代 VLM 在 $k = 1, 3, 7$ 及 E3 冲突干预下均完全免疫外部字幕干扰（$\mathrm{TFCE} \approx 0$ 且 $\mathrm{Contam} \approx 0$），同时 MSVD `k = 1` 显著低于 `k = 0`。
12. **假设不成立时的科研解释**：将清晰界定“外部检索诱发事实污染”并非所有视频大模型的普遍律，而是**强依赖于弱视觉编码器/特定跨门控微调接口对外部文本先验的过度依赖**——这是一个极其清晰、诚实且对现代 VLM 系统选型具有指导意义的架构边界发现。

## 10. 逐层递进的实验体系设计（E1–E5）

为杜绝“拍脑袋上全套 GPU 实验”，本设计采用严格的**阶段门控递进结构（Stage-Gated Pipeline）**。每一层实验都对应明确假设，且规定了进入下一层的准入条件与随时止损的退出条件。**本轮仅制定设计方案，不执行任何分析或代码。**

### 10.1 Experiment E1：既有资产的效用异质性与反幻觉上界审查（零 GPU 成本，前置门控 Gate 0）
- **对应假设**：SQ1、H3（前半部分）。
- **直接复用资产**：`reports/local_independent_review/results/test2690_per_query.csv`、`msvd670_per_query.csv`、`research/uarcap_v06_followup_deployment/bn_v06_full_ab/` 中冻结的 `A0 / A1 / A7 / B3 / B7HQ / B7LQ` 预测与运行时 trace，以及历史 `D3 / D5` 预测与候选池特征。
- **拟执行分析方案（下一阶段授权后开展）**：
  1. **逐查询净效用分布画像**：在统一参考 IDF 下计算每条查询的 $\Delta_{1,0}(v) = \text{CIDEr}(A1) - \text{CIDEr}(A0)$ 与 $\Delta_{7,1}(v) = \text{CIDEr}(A7) - \text{CIDEr}(A1)$，报告分位数、显著有益/近零/显著有害比例（以对称阈值如 $|\Delta| \ge 5, 10$ 点做敏感性剖面，避免单一武断阈值）；
  2. **反幻觉双校验上界**：对 MSR-VTT 每条查询的 20 条人工参考句执行多次随机劈半（10 条选优 $R_1$，10 条评估 $R_2$），计算**劈半交叉验证最优预算上界**，并与**视频内置换零分布上界**对比，量化朴素事后 $\max_k$ 上界中有多少纯属指标噪声膨胀；
  3. **推理前预测力基线摸底**：在严格按 YouTube `source_id` 分组的 5 折交叉验证下，使用轻量线性/树模型（严格禁止接触任何参考文本或生成输出）检验 X-CLIP 相似度、top-1/top-2 落差、候选池 ROUGE-L 熵、字幕长度等推理前特征对 $\Delta_{1,0}$、$\Delta_{7,1}$ 的折外 $R^2_{\text{OOF}}$ 与分类 AUROC。
- **准入与停止门控（Gate 0）**：
  - 无论 E1 中 CIDEr 异质性的推理前可预测性高低，只要观察到明显的逐查询正负分化（而非所有样本微幅一致平移），即具备进入 E2 探索“事实层面究竟发生了什么”的充分理由；
  - 若 E1 证实劈半上界相对 `A1` 的真实剩余空间微弱（例如 $< +1.5$ CIDEr 点）且折外 $R^2_{\text{OOF}} \le 0.02$，则**立即否决“面向 CIDEr 开发复杂动态预算器”的方向**，彻底避免在路线四上浪费算力。

### 10.2 Experiment E2：零外部证据锚定的视频事实性测量与双盲人工核验（零新增主模型 GPU，核心支柱）
- **对应假设**：SQ2、H1、H3（后半部分）。
- **核心设计**：在冻结的 `A0 / A1 / A7` 输出（以及后续 E5 产生的现代 VLM 输出）上，建立第 11 章规范的四维原子视觉命题拆解与双盲人工视频核验流程，直接量化 $\big(\mathrm{Corr}, \mathrm{Gain}, \mathrm{Contam}, \mathrm{Contam}_{\text{align}}, \mathrm{Omit}, \mathrm{Unc}\big)$ 四元对称事实转移与 $\text{FactPrec}$。
- **样本结构与统计分层**：为避免只挑极端样本造成选择偏差，采用**来源簇分层随机抽样**（严禁一个 YouTube 来源被抽中多个 clip，保证主样本簇间独立）：
  - **第一批（人工核心试点与校准集，120 个独立来源视频 × 3 臂 = 360 条字幕）**：随机均匀分层覆盖低/中/高 top-1 X-CLIP 相似度三层（严禁按事后 CIDEr 涨跌抽样！），由两位独立标注员双盲观看原始查询视频完成全量原子命题核验与裁决；
  - **第二批（确认性与跨模型扩展集，120–180 个独立来源视频）**：仅在第一批验证标注者间一致性达标（Krippendorff's $\alpha \ge 0.70$）且确实观察到非平凡事实污染/纠错转移后追加，并与未触碰确认队列（见第 12 章）结合。
- **自动评价器校准定位**：采用开源视频理解模型（或结构化多帧 VLM 裁判 + FactVC/ARGUS 风格原子核验流）对全量 `2,690` 条输出做辅助扩展，但**严格以双盲人工真值为锚点报告校准指标（人机一致性 $\kappa$、按臂偏差检验——防止自动裁判偏爱长句或偏爱某模型风格）**；主结论始终以双盲人工核验集为黄金标准，自动打分仅作全队列一致性佐证，绝不替代人工真值！

### 10.3 Experiment E3：视觉输入逐查询锁定的最小配对原子事实干预（中等 GPU 成本，核心因果识别）
- **对应假设**：SQ3、H2。
- **彻底区别于历史 `GoodTail / HardWrong / B` 的六重刚性控制**：
  1. **视频真值锚定**：从经人工观看核验的查询视频集合（建议 $N = 160\text{–}200$ 个独立来源视频，覆盖动作/论元与实体/属性两类主靶事实）中，为每个视频明确指定一条视频清晰可见的靶真实命题 $f^+$（例如“a man is slicing carrots”中的动作谓词 `slicing` 或客体 `carrots`）；
  2. **三臂最小配对文本构造（`Sup / Con / Neu`）**：
     - **`Sup`（视频支持臂）**：自然、简洁的单句外部描述，清晰包含 $f^+$；
     - **`Con`（视频冲突臂）**：仅将 $f^+$ 替换为同语义范畴、在 VideoUFO 语料中同等高频且语法完全自然的冲突事实 $f^-$（如 `slicing` → `frying`，或 `carrots` → `onions`），确保 $\phi(f^- \mid v) = \mathrm{Con}$，**总词数差 $\le 1$ 词、句法骨架与流畅度一致**；
     - **`Neu`（视频中性/不可验证对照臂）**：同等词数与流畅度的同域中性描述（如仅描述背景氛围或无关通用信息，既不包含 $f^+$ 也不包含 $f^-$），用于严格剥离“单纯引入非支持文本或改变句长”的效应；
  3. **双轨验证（最小配对 + 自然 VideoUFO 冲突子集）**：为彻底消除“人工最小改写存在编辑伪迹”的质疑，额外从真实 VideoUFO top-20 候选池中筛选经人工核验为自然 `Supported` vs. 自然 `Contradicted`（与视频存在明确单一事实冲突）vs. 自然 `Unverifiable` 的真实检索字幕子集，做生态效度平行检验；
  4. **消除“外部图文打架”混杂的视觉锁定方案**：在原 Video-LLaMA 架构上，E3 主干预采用**双条件视觉控制**——（a）主设置：在 `B3` 固定视觉头（3 条完全相同的检索视觉张量，运行时逐查询哈希校验一致）之外的第 4 个纯文本槽位（空 clip 绑定，不改变任何视觉特征）注入 `Sup / Con / Neu`，完全杜绝“改了文字却留着原视频张量导致外部图文打架”的混杂；（b）敏感性对照：在 $k=1$ 纯文本外部输入（零检索视觉张量，仅改变 1 条外部字幕）下复测三臂，剥离前 3 条头字幕的缓冲效应；
  5. **盲审流畅度质控**：抽取 20% 的 `Sup / Con / Neu` 文本对在不展示视频的情况下进行自然度盲检，确保 `Con` 并非生硬病句；
  6. **高信噪比因果终点**：主终点为双盲判定（辅以精确词形/同义词词表核对）的靶事实定向污染率 $\mathrm{TFCE}$ 与靶保真损失 $\mathrm{TFFL}$，辅以整句事实精确率与 CIDEr。

### 10.4 Experiment E4：同算力约束下的统一证据子集决策评估（严格条件触发，非必选）
- **对应假设**：SQ4、H3（仅当 E1/E2/E3 门控通过时激活！）。
- **激活前提（Hard Entry Gate）**：必须同时满足——（1）E2 证实存在显著的事实污染风险（例如 `A7` 或高风险子集污染率 $\ge 15\%$）；（2）E3 证实语义/事实冲突确实驱动事实污染（$\mathrm{TFCE} \ge +8\%$ 且统计显著）；（3）E1/E2 证实推理前轻量特征在折外验证上具备有效风险识别力（$\mathrm{AUROC}_{\text{OOF}} \ge 0.65$）。**若三者缺一，直接跳过 E4，不强行编造方法！**
- **公平对比规范（若被激活）**：
  - **强基线优先**：必须首先对比固定 `A0`、固定 `A1/D1`、固定 `D3/D7`、无参 `Adaptive-k`、以及基于原始 X-CLIP 绝对阈值的一维弃用基线（“若 top-1 相似度 $< \tau$ 则返回 $S = \emptyset$”）；
  - **严格同算力与反“强模型滤弱模型”红线**：所有候选方法必须共享同一 top-20 候选池；严禁调用比主生成器更强的 VLM（如用 Qwen2.5-VL 过滤字幕再去喂给 Video-LLaMA）却宣称“轻量选择创新”。任何轻量视觉—文本蕴含或风险估计器必须完整核算并报告：**总生成器调用次数、验证器额外延迟（ms/query）、峰值显存（GB）及端到端吞吐量**，并在“同算力帕累托前沿”上比较；
  - **独立确认评估**：阈值或校准参数只能在开发划分上拟合，严禁在最终报告集上微调。

### 10.5 Experiment E5：跨基准与跨多模态接口的外部泛化验证（最小充分组合）
- **对应假设**：SQ4、H4。
- **最小充分组合设计（明确拒绝全面铺开 6 尺度网格）**：
  1. **组件 1：补齐 MSVD 匹配零外部证据对照（`MSVD A0`）**：在 MSVD `test670` 上复现 `v0.6/v0.7` 的 `A0` 协议（全零外部张量、保留原 3-context cross-gating 检查点与完整运行 trace），与已冻结的 `MSVD D1 / D3 / D7` 配对形成完整的 `k = 0, 1, 3, 7` 曲线。预估仅需 **~0.5–0.7 GPU 小时**，投入产出比极高！
  2. **组件 2：引入一个现代开源原生视频大语言模型（首选 `Qwen2.5-VL-7B-Instruct`）**：
     - **选型依据**：Apache 2.0 商用友好许可；原生动态分辨率视频帧编码；BF16 权重约 16–18 GB，在 BN 单张 RTX A6000（48 GB）上无需量化即可流畅推理；与 2023 年代 Video-LLaMA（32-token cross-gating + Vicuna-7B）在视觉表征和证据接口上形成鲜明时代与架构对照。（备选：`LLaVA-Video-7B-Qwen2`，Apache 2.0，约 18–21 GB BF16，均匀 16–32 帧采样，同样适配 A6000 48GB。）
     - **复用策略与接口边界声明**：直接复用同一 VideoUFO FULL X-CLIP 检索候选池（零新建索引成本），在统一提示模板下运行 $k \in \{0, 1, 3, 7\}$（零外部字幕 vs. 拼接 1/3/7 条外部字幕）以及 E3 最小配对干预（`Sup / Con / Neu`）。**文中严格声明**：Qwen2.5-VL-7B 采用原生多帧 token + 提示文本注入接口，不具备 Video-LLaMA 的 32-token cross-gating 视觉融合模块，二者测试的是**外部检索效用—风险规律的跨接口迁移边界**，绝非等价架构复现。
  3. **组件 3：引入未触碰来源独立确认队列（防 `test2690` 复用透支）**：
     - 鉴于 MSR-VTT `test2690` 已反复分析，建议从 **VATEX 公开英文测试/验证集**（源自动作语义极为丰富的 Kinetics-600，每条视频含 10 条高质量英文人工参考句，天然包含大量动作与论元事实！）中，先经精确 YouTube ID 审计剔除任何与 VideoUFO / MSR-VTT / MSVD 重叠的来源，再锁定一个 **未触碰确认队列（建议 600–800 个独立来源视频，内嵌 120–150 个双盲事实人工核验子集）**，在协议冻结后一次性运行 Video-LLaMA（或仅在现代 VLM + 原框架上复用 VideoUFO X-CLIP 索引），作为真正的独立确认性外部验证！
     - *说明*：若原 Video-LLaMA MSR-VTT 检查点在 VATEX 上因域迁移导致基线过低，则需在先导可读性核查阶段如实记录，并将现代零样本 VLM（Qwen2.5-VL-7B）作为 VATEX 独立确认队列的主力模型，避免强行把单域微调旧检查点的域外崩塌误解为通用检索规律。

## 11. 视频事实性评价与双盲人工核验规范

本节旨在解决“如何把自由文本视频描述的事实性测准、测稳、不靠拍脑袋”的方法论难题。

### 11.1 标注对象与四维原子视觉命题切分规则
标注对象为自由文本单句视频描述 $y$（无论是零证据 $y_0$、有证据 $y_S$ 还是候选字幕 $c_i$）。借鉴 FaithScore（EMNLP 2024）与 ARGUS（ICCV 2025）的原子分解范式，采用“**规范化最小可核验命题切分**”：
- 将每句描述拆分为若干彼此独立的最小主谓/修饰命题，归入四类维度之一：`[Entity]`（实体/场景）、`[Attr]`（属性/数量/状态）、`[Action-Role]`（动作事件及施事/受事/工具角色）、`[Temp-Outcome]`（时序先后、方向或事件结果）。
- **切分约束**：去除纯粹主观修辞或不可视觉核验的情绪猜测（如“happily”、“in an interesting way”标为非视觉修辞或 `Unc`）；MSR-VTT/MSVD 平均 8–9 词的短句通常对应 **2–4 条原子命题**，VATEX 稍长句通常对应 **3–5 条原子命题**，确保每条命题可被单一真值判定覆盖。

### 11.2 原始视频观看规范与多事件视频处理
- **必须观看完整原始查询视频**（包含完整时间轴，默认静音或在明确无音频依赖的视觉核验模式下观看，因为当前 Video-LLaMA 与 X-CLIP 仅使用视觉帧、未输入音轨！若字幕提及画面不可见但依赖听觉的内容如“singing a pop song”而画面仅见人张嘴，应按视觉可证性规则标为 `Unc`，严禁把“模型没听见声音”误判为视觉幻觉）。
- **时间范围对齐**：事实的时间范围必须对应模型实际接收的整个视频片段起止窗口（与预提取 16 帧或全片均匀采样窗口一致）。
- **多事件视频处理**：若一段 10–15 秒视频包含多个连续场景或动作（如先切菜再下锅），只要命题描述的事件在视频任一时段真实发生即判为 `Sup`；仅当命题明确主张错误的先后顺序或持续状态时才判为 `Con`。描述只涵盖其中一个主要事件而未涵盖另一事件时，不计为 `Con`，仅在配对比较 $y_0 \to y_S$ 时，若 $y_0$ 原已正确提及的事件在 $y_S$ 中消失，才计为 $\mathrm{Omit}$。

### 11.3 三值视觉蕴含判定与错误/遗漏/纠错/污染区分
对每条原子命题 $a$，严格按三值标签判定：
- **`Supported (Sup)`**：视频画面给出明确直接的视觉证据支持该命题；
- **`Contradicted (Con)`**：视频画面给出明确反证，该实体不存在、属性明显不符、动作/角色明显错误或时序结果相反；
- **`Unverifiable (Unc)`**：因画面模糊、遮挡、视角切出、需音频/外部世界知识（如专有名词人名、地名、具体歌名）而无法从视频画面确认真伪。**严禁将 `Unc` 合并入 `Con`；也不得仅因人工参考字幕未提到某细节而将其标为 `Con`**。

在此基础上，由同一组配对输出 $(y_0, y_S)$ 按语义槽位对齐直接导出四个互不重叠的事件计数：
- `错误 vs. 遗漏`：错误（`Contam`）是说了画面中**不存在或相反**的事；遗漏（`Omit`）是丢掉了 $y_0$ 中原本说对的真实信息。
- `纠错 vs. 污染`：纠错（`Corr`）是 $y_0$ 原本的 `Con` 在 $y_S$ 中被消除/改正；污染（`Contam`）是 $y_S$ 新引入了 $y_0$ 中原本没有的 `Con`（并由独立辅助核对标记该错误是否与外部检索字幕 $S$ 语义对齐，即 $\mathrm{Contam}_{\text{align}}$）。

### 11.4 双人盲法标注、分歧裁决与一致性指标
- **严格盲法（Double-Blind Arm Masking）**：将同一视频对应的多臂输出（如 `A0 / A1 / A7` 或 `Sup / Con / Neu`）打乱匿名编号呈现给两位独立标注员；标注员既看不到臂名（不知道哪条是 $k=0$ 还是 $k=7$），也不在判定视频真值阶段看到外部检索字幕 $S$（仅在真值判定彻底锁定后，由第二阶段独立匹配脚本/复核员标注 `Con` 是否与 $S$ 对齐，杜绝确认偏误！）。
- **培训与标定**：正式标注前在 20 个独立培训视频上校准切分粒度与边界案例，形成《视频原子事实标注手册 v1.0》。
- **一致性指标与达标门槛**：同时报告命题级 **Krippendorff's $\alpha$（名义三值）** 与 **Cohen's $\kappa$**（以及每视频计数的组内相关系数 ICC）。设立硬性质量门控：**若双人三值判定 $\alpha < 0.70$，必须修订手册并重新标定，严禁直接用于正式推断**。所有分歧条目由第三位仲裁者（或双人盲法复核共识会议）最终裁决。

### 11.5 200–300 视频人工试点的统计目的、可行性与工作量评估
不能把“200–300 个视频”当作拍脑袋的模板数字，必须按统计功效与人力可行性定量核算：
- **统计功效估算**：假设在 `A7 vs. A1` 配对比较中，视频级事实污染发生率差异为 $\delta = 8$ 个百分点（如 `12% → 20%`，不一致对比例约为 $p_{\text{disc}} \approx 0.24$），在双侧 $\alpha = 0.05$、检验效能 $80\%$ 条件下，配对 McNemar / 符号翻转检验所需独立来源视频数约为 $N \approx \frac{(1.96 + 0.84)^2 \cdot 0.24}{0.08^2} \approx 294$ 个；若检测 E3 最小配对干预中较大的定向污染效应（$\mathrm{TFCE} = 12$ 个百分点，不一致对约 $0.18$），则 $N \approx 98\text{–}130$ 个独立来源视频即可达到 $80\%$ 效能；若检测 $5$ 个百分点的微小自然差异，200 视频的功效仅约 $40\%\text{–}50\%$，此时 200 视频只能作为精准效应量区间估计与大效应检测，而不可宣称“零差异等价”。
- **实际工作量核算**：每段 10–15 秒视频观看加 3 条短句（共约 8–10 条原子命题）的盲法标注，熟练标注员平均耗时约 **2.5–3.5 分钟/视频**。因此：
  - **120 视频试点（双人盲标）**：每人约 5–7 小时，两人合计约 **12–16 人时**（含培训与分歧裁决约 20 人时），高度可行；
  - **240–300 视频全量核验（双人盲标）**：两人合计约 **28–40 人时**（约 1–2 周兼职标注周期），完全处于个人+导师/同门小团队可承受范围内。
- **自动评价器校准定位**：在完成 120–300 视频双盲黄金集后，可用开源多帧 VLM 裁判（如 Qwen2.5-VL-7B 零样本命题核验）或 FactVC 对其进行校准，**明确报告自动裁判与人工黄金集的 $\kappa$、精确率/召回率及跨臂系统偏差（例如是否对长句偏松或偏严）**。仅当人机一致性达到可接受水平（$\kappa \ge 0.65$ 且跨臂偏差 $< 2\%$）时，才将自动打分作为全队列（`2,690` / `800`）辅助敏感性分析；否则主文仅报告双盲人工核验结果，诚实拒绝使用未校准自动裁判！

## 12. 统计分析、层级聚类与数据泄漏防御

现有 MSR-VTT（`test2690`）与 MSVD（`test670`）在前期多轮审计中已被反复检验，这是 Q2 升级最容易被顶级审稿人“一票否决”的隐患点。本设计制定如下铁律：

### 12.1 严格的探索—确认数据隔离策略
1. **永久降级 `test2690` 的推断角色**：明确承认 `test2690` 已用于历史预算观察与 A/B 检验；因此在该队列上开展的 E1 与 E2 第一批分析，在论文中**明确界定为“在已冻结历史队列上的后验机制解剖与假设校准（retrospective mechanism dissection）”**，绝不冒充独立确认性测试集！
2. **引入未触碰来源独立确认队列**：针对最终核心假设的确认性验证（尤其是 E3 最小配对因果干预、E5 现代 VLM 验证以及若被激活的 E4 策略评估），必须从**从未参与过 `v0.1–v0.8` 任何决策的外部视频集合**中构建独立确认队列（首选经精确 YouTube ID 去重、确认与 VideoUFO/MSR-VTT/MSVD 零源重叠的 **VATEX 公开英文测试/验证子集**，规模约 600–800 个独立来源视频；如因版权或视频可用性受限，备选方案为从 ActivityNet-Captions 或未触碰的公开视频描述集中执行同等零源重叠审计）。
3. **开发—确认源级物理隔离**：所有标注手册修订、自动评价器 prompt 选择、特征筛选或（若启用 E4 的）阈值校准，**必须严格限制在探索/开发集内完成并提交协议哈希冻结**；确认队列在协议冻结前严禁打开、严禁窥探指标、严禁事后调参或继续补采样本追逐显著性（no peeking / no optional stopping）。

### 12.2 事实级评价中的多层聚类与统计推断
自由文本视频描述的事实性数据天然存在**四级非独立嵌套结构**：
$$\text{原子命题 } a \;\subset\; \text{单臂生成字幕 } y(v, S) \;\subset\; \text{查询视频 } v \;\subset\; \text{原始 YouTube 来源视频 } g(v)$$
如果直接把所有原子命题摊平做卡方检验或普通 t 检验，会严重低估标准误、制造大量假阳性！本设计规定：
- **分析与聚类单位**：先在**查询视频层**汇总各臂的事实计数与精确率，形成配对视频级指标（如 $d(v) = \mathrm{Contam}(v, S_7) - \mathrm{Contam}(v, S_1)$），再以**来源视频（source cluster）**为完整重抽样与符号翻转单位执行推断（当所有抽样查询均强制满足“每来源最多 1 条视频”时，查询层与来源层自然重合，彻底消除簇内相关膨胀！）；
- **配对结构与置信区间**：所有跨臂对比均为同查询配对比较，采用固定种子的 **10,000 次来源聚类配对自助法**构造逐项 $95\%$ 百分位置信区间，并采用 **10,000 次双侧来源级符号翻转置换检验**计算精确 $p$ 值；
- **多重比较控制**：事前锁定主检验家族（例如 E2 主族 3 项、E3 主族 3 项、E5 各模型主族各 3 项），各家族内统一采用 **Holm–Bonferroni** 控制族内第一类错误率（$\alpha = 0.05$）；跨实验综合断言额外报告联合 Holm；探索性子维拆分（如按实体/动作/时序分面分析）明确标注为探索性并采用 BH 控制 FDR；
- **`Uncertain` 与缺失标签处理**：严格禁止直接丢弃含 `Unc` 命题的视频导致选择偏差！规定：（a）在计数指标（$\mathrm{Corr}, \mathrm{Gain}, \mathrm{Contam}, \mathrm{Omit}$）上，全部分母为完整抽样视频总数 $N$（`Unc` 命题既不计为 `Sup` 也不计为 `Con`）；（b）在精确率 $\text{FactPrec}$ 上，主分析以 `Sup / (Sup + Con)` 计算并同步报告 `Unc` 占比；若某句全部命题均为 `Unc`（极罕见），在主精确率之外执行保守敏感性分析（分别按全计为 `Sup` 与全计为 `Con` 报告区间边界）；
- **不显著不等于等效**：所有未通过校正的对比严格按置信区间宽度解读，不作任何“无影响”或“两臂等效”的越界断言。

### 14.2 五条硬性阶段性停止条件（Stop Rules）

为防止陷入“为了 Q2 无止境加实验”的沉没成本陷阱，事前确立五条可执行止损准则：

1. **何时彻底放弃“动态证据选择方法（E4）”**：若 E1 显示参考集劈半预算上界相对固定 `A1` 的剩余增益 $< +1.5$ CIDEr 点且推理前特征折外 $R^2_{\text{OOF}} \le 0.02$，**或** E2 中推理前特征对事实污染事件的折外 $\mathrm{AUROC}_{\text{OOF}} < 0.65$，立即取消 E4，坚决不编造复杂选择器。
2. **何时放弃“检索诱发事实错误”主线**：若 E2 120 视频双盲试点中，双人一致性经两次标定仍无法达到 $\alpha \ge 0.70$，**或** `A1`、`A7` 相对 `A0` 的视频事实污染率与纠错率均微乎其微（如跨臂事实变动视频占比 $< 10\%$，且 CIDEr 变动几乎全部源于长度与同义词风格），则停止扩大事实标注与 E3，改以“指标失真诊断”收束或直接退出至路线 C。
3. **何时不值得引入第二模型（Qwen2.5-VL-7B）**：若在路线 A 阶段（E1 + E2 试点）已发现既无显著事实风险分化、也无清晰语义冲突机制，则继续花费 GPU 与人力部署第二模型属于盲目堆量，应立即止损。
4. **何时“纯诊断+评价框架论文（方案 III 无 E4）”优于“带方法论文”**：只要 E2 与 E3 确立了清晰对称事实转移规律与视觉锁定因果污染效应（$\mathrm{TFCE}$ 显著），且 E5 揭示了跨接口的清晰规律或架构边界，即便没有任何轻量策略能在同算力下大幅击败固定 `k = 1`，直接以诊断框架与部署准则成文远比强行拼凑一个勉强提升 `0.3` 点的重排器更具 Q2 学术说服力。
5. **何时立刻停止 Q2 升级、保留 `v0.8` 投 Q3（路线 C）**：若综合评估发现（a）双盲 240–360 视频人工标注人力在当前时间窗口内无法落实，**或**（b）路线 A 试点结果显示事实层效应量极小、无法支撑超越 `v0.8` 的显著科学增量，则应果断冻结升级，立即将已完成视觉质控的 `v0.8` 投稿至范围匹配的 SCI Q3 期刊——这是对作者整体科研产出的最优资源配置。

### 15.2 四种结果分支下的诚实论文组织预案（杜绝“无论何种结果都硬吹成功”）

1. **分支 1（核心机制全面证实：H1 与 H2 均成立，且跨接口存在清晰迁移）**：按上述标准目录组织，形成“对称事实风险分解 + 视觉锁定最小配对因果证实 + 跨接口效用—风险前沿”的强力 Q2 论证主线。
2. **分支 2（H2 因果机制成立或 E2 事实诊断清晰，但 H3 推理前不可预测 / E4 未超越固定 `k=1`）**：诚实报告 E4（或门控未激活原因），将论文定位为**高严谨度实证诊断与评价框架论文**，核心工程洞见转化为反直觉且极具实用价值的结论——*在受限算力下，复杂的事前风险过滤器难以超越极简小预算操作点，检索增强视频描述的真正突破口在于事件级检索对齐而非推理侧启发式重排*。
3. **分支 3（H1/H2 均不成立：事实层几乎无检索诱发污染，`A1 > A7` 纯系 CIDEr 长度/词面漂移所致）**：论文转向**“视频 RAG 评价方法论批判”**主线——用双盲人工事实证据揭露传统 CIDEr 在评估检索增强自由文本描述时的严重指标失真（并顺带解释 `v0.8` 中 CIDEr 下降而 SPICE 上升的长期悬案），同样具备独立发表价值，但需主动下调对“检索污染机制”的理论主张。
4. **分支 4（现代原生视频 VLM 不复现原框架的预算退化或几乎免疫外部冲突）**：绝不掩饰差异或硬拗“大体一致”，而是直接把**“跨接口脆弱性分化（Interface-Dependent Retrieval Vulnerability）”**升格为核心贡献——对比展示“弱视觉 + 32-token cross-gating 微调架构”为何容易被外部文本牵引，而“强原生多帧指令 VLM”在零外部证据下基线更高、外部增益更窄且抗干扰特性迥异，为后 LLM 时代是否还需要为视频描述叠加外部检索提供关键实证判据。

## 16. 尚待用户、ChatGPT 与导师共同讨论裁决的问题

在编写任何一行新代码、启动任何一次分析或下载任何新模型之前，以下 **7 项核心开放决策** 需要作者与导师共同拍板（详细选项与权衡见附录 `OPEN_SCIENTIFIC_DECISIONS.md`）：

1. **总体战略抉择（路线 A / B / C）**：当前时间与精力预算（兼顾法律 RAG 论文）下，是先执行**低成本路线 A**（约 1 GPU 小时 + 120 视频试点）按门控再决定是否扩至路线 B，还是直接把 `v0.8` 投稿至 SCI Q3（路线 C）？
2. **目标期刊画像定位**：若冲刺 SCI Q2，拟瞄准偏**多模态评测与诊断/计算语言学**方向期刊，还是偏**系统与工程方法**方向期刊？（前者高度认可方案 III 无 E4，后者往往更看重是否有轻量方法与现代 VLM 验证。）
3. **双盲人工标注人力来源**：120 视频试点（~16–22 人时）或 280–360 视频全量（~38–55 人时）能否落实至少两位独立标注员（含第三人仲裁）并保证盲法执行？
4. **未触碰确认队列的数据选型与下载可行性**：在 BN 服务器上获取 **VATEX** 公开测试/验证子集（约 600–800 个经 YouTube ID 去重的独立来源视频）是否存在视频失效或网络限制？若受限，是否改用已有公开视频数据集（如 ActivityNet-Captions 切分片段）？
5. **第二模型最终选型**：在 RTX A6000 48GB 上，首选 `Qwen2.5-VL-7B-Instruct`（Apache 2.0，原生动态分辨率）还是 `LLaVA-Video-7B-Qwen2`（Apache 2.0，固定均匀帧采样）？是否仅测文本拼接外部字幕，还是增加一组“检索关键帧 + 字幕”的跨模态提示敏感性臂？
6. **最小配对干预（E3）的靶事实范围**：是集中于两类高频核心维度（`Action-Role` 动作论元 + `Entity` 核心实体，各占 50%，信噪比最高），还是强行覆盖全部四维（可能导致每个子类样本量过薄）？
7. **与 `v0.8` 的投稿关系与学术伦理边界**：若启动 Q2 升级方案，是否明确**暂缓投出 `v0.8`**（避免一稿两投或自我重复发表），将 `v0.8` 作为内部基线版本封存，仅在路线 A 触发止损条件时才启用 `v0.8` 独立投稿 Q3？
