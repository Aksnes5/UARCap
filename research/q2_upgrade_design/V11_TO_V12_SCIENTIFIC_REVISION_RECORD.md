## 一、核心范式转型摘要

`v1.1` 与 `v1.2` 的**核心科学问题（RQ1–RQ3）、统一证据输入表达 $G(v, T, V; I, \theta, d)$、废除主观加权总分 `B_fact` 以及移出 E4 新算法开发**均保持一致。实质性重构集中在**数据基础、事实评价方式与人工资源分配**：

| 对比维度 | `v1.1`（MSR-VTT + VATEX 从零人工标注路线） | `v1.2`（现成高质量公开数据集 + 三值解耦 + 精准人工校准路线） | 科学收益与成本变化 |
|---|---|---|---|
| **E2 事实评价主数据** | 在仅有简短参考的 MSR-VTT 上从零人工建立 160–300 视频原子事实真值 | **复用 `DREAM-1K`（Apache 2.0，1,000 专业人工细粒度描述，仅 `3.85 GB`）**（备选 `ARGUS`）+ 50–60 视频 MSR-VTT 方向桥接 | 样本量从 ~180 扩至 **500–800 独立视频**，兼具国际公认外部基准公信力与未触碰确认队列 |
| **E3 靶事实来源** | 在 MSR-VTT 上从零观看视频、构思并编写 160 视频 $(f^+, f^-)$ 靶对 | **复用 `VidHalluc`（CVPR 2025，`gated: False`）既有同场景强混淆动作对** + 轻量人工核验严格冲突与 `Neu` 构造 | 大幅压低靶构造成本，且冲突动作具真实视觉混淆生态效度 |
| **跨数据集确认队列** | 额外下载与准备 **VATEX**（600–800 视频） | **正式取消 VATEX**（由从未参与 `v0.1–v0.8` 的 `DREAM-1K` 承担独立外部确认队列角色） | 减少数据管线分支，避免多数据集割裂 |
| **评价器与指标命名** | 全依赖人工看片产出 `N_C`、`N_S`、`R_core` | 全队列用**三值解耦本地开源 NLI**（修正官方 `AutoDQ` / `ArgusCost-H` 把 `neutral/underdetermined` 计错的源码缺陷），产出 `N_Contra_ref`、`N_Entail_ref`、`R_core_ref`、`P_Unment_ref`；**绝不偷换命名为人工真值**；80 视频双盲人工看片独立校准/验证 | 既实现规模化评测，又严守“未提及 $\ne$ 错误”与指标诚实边界 |
| **短字幕与长参考兼容** | 无严重长度错配（MSR-VTT/VATEX 均为短句） | 新增四项刚性保护：① 配对差值控制；② **事前无泄漏核心事件子集 `R_core_ref`** 化解地板效应；③ 现代 VLM 主设置强制 **8–18 词短字幕对齐指令**；④ 不逼迫 Video-LLaMA 写长段落 | 防止因任务长度错配导致跨模型比较失真 |
| **前置兼容性试点** | M0-small 纯人工 16 视频流程试标 | **方案 A（30 DREAM-1K + 20 VidHalluc 兼容性试点，~0.7–1.5 GPU h + ~8–12 人时）**：同时验证数据获取、短字幕分辨率、三值裁判人机 $\kappa$ 与 VidHalluc 严格冲突率 | 极低成本前置验证整条新路线是否真可行 |
| **人工与 GPU 成本** | 人工 **130–196 人时**；GPU 16–30 小时 | 人工降至约 **32–46 人时**（以方案 A 实测为准，不提前承诺精确压缩比）；GPU 约 **18–32 小时**（含本地三值 NLI 裁判调用，`$0` 商业 API 费） | **直接解除 130+ 人时人工瓶颈，使小团队真实可落地！** |

## 二、本轮一手审查直接触发的关键决策变更

1. **排除 CapQuiz（ACL 2026）**：实查 Apple 页面与 ACL Anthology 确认数据尚未公开发布，绝不列入依赖；
2. **淘汰 VDC（ICLR 2025）**：实查 `VDCScore_qa/short.jsonl` 发现 `"environment"`、`"lighting"`、`"object"`、`"action"` 等类别占位词污染；
3. **揭露并绕开 `AutoDQ`（L254）与 `ArgusCost-H`（L118）的源码陷阱**：两套官方标量均将 `neutral/underdetermined` 计为错误，故 `v1.2` 强制读取三值原始裁决并分列汇报；
4. **发现 VidHalluc 与 ARGUS 内部同源多片段结构**：明确纳入来源去重与来源聚类规则，防止同源泄漏；
5. **降级 MSVD 匹配 `k=0` 为可选组件**：DREAM-1K 已提供更强外部事实确认队列，MSVD 3 臂（~1.5–2.2 GPU h）按算力余量选做。
