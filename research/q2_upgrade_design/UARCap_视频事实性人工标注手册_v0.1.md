# UARCap 视频描述事实性人工标注手册（v0.1）

> **手册状态**：`DESIGN_REFINED_AWAITING_FEASIBILITY_AUTHORIZATION`（供 M0-small 可行性试点试运行与实测修订，尚未冻结为最终正式版）  
> **适用对象**：独立盲法标注员（Annotator A / B）、规范化切分审核员与第三方仲裁员  
> **配套表格**：`templates/TEMPLATE_01_CORE_FACTS_L2.csv` 至 `TEMPLATE_05_TIME_LOG_M0SMALL.csv`

---

## 1. 任务介绍与分层目标

本标注任务旨在客观核验不同模型或检索配置生成的短视频英文描述（通常 1 句、6–15 词）与**原始视频画面**之间的一致性，为 UARCap 研究提供高质量黄金人工数据。为控制负担并确保可复现性，标注工作分为四个清晰层级：

- **L1（基本事实性，全量样本）**：独立判断每条匿名字幕拆解出的原子视觉命题是否被视频支持（`S`）、反驳（`C`）或无法核验（`U`），产出 `N_C` 与 `N_S`；
- **L2（核心事件覆盖，全量样本）**：**在看任何字幕之前**，仅凭视频画面预先写出 1–3 条核心事实，随后判断每条匿名字幕对核心事实的覆盖程度（`0 / 0.5 / 1.0`），产出 `R_core`；
- **L3（精细配对转移与证据对齐，仅预定随机子集）**：在 L1 真值彻底锁定后，对零证据字幕与有检索字幕执行受限同指对齐（八类状态转移），并标记新增错误是否与外部检索字幕语义对齐；
- **L4（E3 目标事实五态判定，专用于 E3）**：直接针对预先指定的单一目标正确事实 $f^+$ 与目标错误事实 $f^-$，独立判定二者是否出现（允许同时出现）。

## 2. 人工盲法铁律（严禁违背）

1. **严禁知晓实验臂来源**：所有待评字幕一律以匿名随机编号（如 `Cap_1 / Cap_2 / Cap_3`）打乱呈现，标注员不得知道哪条对应 `A0 / A1 / A7`、`Sup / Con / Neu` 或哪个模型。
2. **先看视频定核心，再看字幕判真伪**：完成整批视频的 **L2 核心事实清单（表 1）** 之后，才允许打开对应的匿名生成字幕（表 2）！严禁先看生成字幕再反过来修改视频核心事实。
3. **L1/L2 阶段严禁查看外部检索字幕与参考答案**：外部检索候选字幕与 MSR-VTT 人工参考字幕在 L1、L2 阶段完全隐藏；仅在 L1 真值完全锁死并提交后，才由专门人员在 L3 事后步骤中查看外部检索文本做 `Align(T)` 核对。
4. **双人完全独立判定**：Annotator A 与 Annotator B 必须在各自独立副本上完成标注，提交前禁止互相核对答案。

## 3. 视频观看规则

1. **完整观看全片**：必须从头到尾完整观看每段短视频（通常 10–15 秒），允许暂停、慢放与回看关键动作细节，严禁只看首帧或快进跳过。
2. **强制静音核验（视觉优先原则）**：当前被测视频描述系统仅接收视觉帧，**不输入音轨**。因此标注员**必须关闭声音（静音）**观看视频，一切真伪判定仅以**可见视觉画面**为准。凡必须靠听觉才能确定的信息（如具体歌名、说话内容主题、未见发声体的旁白），一律按第 9 节处理为 `U`（不可核验），不得判为 `C`。
3. **画面模糊与遮挡记录**：若原视频分辨率极低、严重运动模糊或关键主体被遮挡导致人眼无法辨认，在备注栏勾选 `VIDEO_BLUR_OR_OCCLUDED` 并据实判 `U`。

## 4. 原子视觉命题定义与四类事实划分

### 4.1 什么是“原子视觉命题”？
一条原子视觉命题是指从单句字幕中提取出的、**可以独立对照视频画面判定真伪（`S / C / U`）的最小规范化语义单元**。规范格式统一写作简明中文或标准英文短语，如 `[主体 动作 受事]` 或 `[对象 属性]`。

### 4.2 四类基本事实划分（精简、无冗余本体）
每条原子命题归入以下四类之一（不再细分庞大子本体）：
1. **`Entity`（实体与场景）**：画面中出现的具体人物、动物、物体或明确场所（如 `[厨房场景]`、`[一只狗]`）。注意：如果实体已作为主干动作的施事或受事，**不重复单独拆出一条纯存在命题**（见第 7 节常见错误切分）。
2. **`Attribute`（属性与静态状态）**：实体的独立可核验视觉属性、颜色、数量、衣着或静态状态（如 `[红衣]`、`[三个人]`、`[站在桌旁]`）。
3. **`Action-Role`（动作事件及论元角色）**：核心动态谓词及其主语（施事）、宾语（受事）或关键工具（如 `[男子 切 胡萝卜]`、`[狗 追 猫]`）。
4. **`Temporal-Outcome`（时序先后、方向与事件结果）**：明确的先后顺序、运动方向或可见状态变化结果（如 `[先切菜再下锅]`、`[篮球投进篮筐]`、`[杯子摔碎]`）。

## 5. 核心事实预先选取规范（L2 / `R_core` 六项铁律）

在观看完完整静音视频、**未接触任何字幕前**，填写 `TEMPLATE_01_CORE_FACTS_L2.csv`：
1. **数量上限**：每段视频选取 **1–3 条核心事实**（典型短视频为 1–2 条，最多不超过 3 条）。
2. **选取标准**：回答“如果只能用一两句话告诉别人这段视频主要发生了什么，最不能漏掉哪些可见主干事件？”——优先选主干 `Action-Role` 或关键 `Temporal-Outcome`，**排除纯背景装饰**（如墙面颜色、远处模糊路人）。
3. **多个同等重要事件**：若视频包含 2–3 个先后发生或并列显著的主事件（如“先切菜、后炒菜”），各占 1 条核心事实；若镜头切换超过 3 个，按占据主要时长或视觉焦点的前 3 个主事件选取。
4. **语义匹配（非字面匹配）**：进入 L2 打分阶段对照匿名字幕时，只要字幕以同义或合理改写表达了核心事实的全部关键要素，即判完全覆盖。
5. **三档覆盖打分（明确部分覆盖）**：
   - **`1.0`（完全覆盖）**：准确表达该核心事实的全部关键主体、核心动作与关键交互对象（无核心槽位错误）；
   - **`0.5`（部分覆盖）**：主体与大类动作正确，但缺失关键交互对象、仅用笼统上位词替代具体核心动作（例如核心事实 `[男子 切 胡萝卜]`，字幕仅写 `"a man is cooking"` 或 `"a man is cutting vegetables"`），或并列双对象仅对一个；
   - **`0.0`（未覆盖 / 核心错误）**：完全未提及该事件，或该核心事件的关键动作/主体/对象出现明显事实错误（例如把 `[男子 切 胡萝卜]` 写成 `"a man is cutting potatoes"` 或 `"a woman is dancing"`）。
6. **防重复计入**：同一核心事实在一条字幕中被同义复述两次，仍按该条核心事实的最高覆盖分计 1 次（上限 `1.0`），绝不累加。

## 6. `S / C / U / Ø` 四状态的严格边界

| 状态 | 名称 | 严格判定边界 | 常见误判警示 |
|---|---|---|---|
| **`S`** | **Supported（视频明确支持）** | 静音视频全片任意时段给出直接、清晰的视觉证据支持该命题。 | 不需要该细节出现在参考字幕中；只要视频画面清晰可见即为 `S`。 |
| **`C`** | **Contradicted（视频明确反驳）** | 静音视频画面给出清晰反证：该实体/动作明显不存在、颜色/数量/性别/角色明显不符、或方向/结果相反。 | **画面模糊看不清绝不能判 `C`**！必须有清晰反证才判 `C`。 |
| **`U`** | **Unverifiable（无法核验）** | 依赖声音（歌名、讲话主题）、依赖外部专有知识（明星姓名、城市名、比赛名称）、主观心理情绪（`"happily"`, `"angrily"` 若无极端明确表情），或因画面模糊/遮挡/视角外无法判断真伪。 | **严禁将 `U` 合并为 `C`**；也严禁把“参考字幕没写”误判为 `U` 或 `C`。 |
| **`Ø`** | **Absent（未表达）** | 仅用于 L3 跨字幕对齐或 L4 目标槽位：该字幕根本未提及此命题/槽位。 | 没提“唱歌”是 `Ø`；提了“唱披头士的歌”但听不见声音是 `U`。 |

## 7. 切分铁律、常见错误切分与防偏置约束

标注员（及 Stage A 审核员）必须严格遵守以下六条切分规范，防止切分粒度随句长或个人习惯漂移：

1. **禁止上位/下位无限拆分（最多 1 层细化）**：
   - **✗ 错误切分**：将 `"a man plays a guitar"` 拆成 `[有人]`、`[是男性]`、`[演奏]`、`[乐器]`、`[吉他]`（5 条，严重刷高 `N_S`！）；
   - **✓ 正确切分**：保留最具体的核心事件 1 条：`[男子 弹 吉他]`（`Action-Role`）。仅当出现独立可核验修饰语（如 `"in a red shirt"` → 另加 1 条 `Attribute` `[穿红衣]`）或 L3 对比另一句上位词 `"plays an instrument"` 时，才额外拆出至多 1 层细化！
2. **禁止将主干动作中的实体重复单独计数**：
   - **✗ 错误切分**：将 `"a dog chases a cat"` 拆成 `[有狗]`、`[有猫]`、`[狗追猫]`（3 条，同一事实重复计分！）；
   - **✓ 正确切分**：拆为 1 条 `Action-Role`：`[狗 追 猫]`。若画面实为“狗追兔子”，该命题因受事错误判 `C`（若句中额外说了 `"a black dog"`，则 `[狗是黑色的]` 作为独立 `Attribute` 单独判 `S` 或 `C`）。
3. **禁止用服饰、工具或场景自动推断真实职业/身份**：
   - 画面中人物穿白色围裙在厨房切菜，字幕写 `"a chef is cutting carrots"`：
     - 命题 1：`[人物 切 胡萝卜]` → `S`；
     - 命题 2：`[该人物是厨师]` → 若无明确专业餐厅/厨师帽标识，仅凭家用围裙与厨房**不能自动证明真实职业**，判 **`U`**（若明显是小孩在家玩玩具厨房，则判 `C`）。同理，穿白大褂拿听诊器在医院可结合明确职业标识审慎判定，普通便装绝不能仅靠背景判职业为 `S`。
4. **禁止将虚词或句内同义复述拆成多条**：
   - `"a boy is running and racing quickly"` 中 `running` 与 `racing` 指同一奔跑动作，必须合并为单一命题 `[男孩 奔跑]`（若速度明显很快可附加 1 条 `[速度很快]`），禁止算 2 条。
5. **同一字幕内部自相矛盾必须分别保留**：
   - `"a man stands still while running"` 拆为 `[男子 静止站立]` 与 `[男子 奔跑]` 两条独立命题，分别对照视频判真伪（至少一条为 `C`），绝不互相抵消。
6. **规范化表示一致与臂盲性**：
   - 无论哪条匿名字幕出现 `"slicing carrots"` 还是 `"cutting carrots"`，统一规范化记为 `[切 胡萝卜]`；切分粒度绝不因字幕长短而放宽或收紧。

## 8. 同义表达、部分匹配与 L3 精细配对转移规则

> **仅在 L1 真值彻底锁死后，于先验随机指定的 L3 子集上执行本节！**

1. **受限同指对齐原则（严禁强行跨无关事件对齐）**：
   只有满足以下两条件之一，才允许将零证据命题 $a_0$ 与有检索命题 $a_S$ 配对到同一槽位：
   - **语义等价**：同指视觉对象/事件，且语义等价（如 `slicing` ≈ `cutting` → 记为 `S → S`）；
   - **单槽同锚替换**：共享相同的核心锚框架，仅单一槽位取值改变（如 `[男子 切 土豆]` → `[男子 切 胡萝卜]`，共享 `[男子 切 ?]`，受事槽位记为 `C → S` 真正纠错）。
   - 若两句描述完全不同的事件（如 `"男子在客厅说话"` vs. `"女子在厨房炒菜"`），**严禁配对**，必须分别记为 `S→Ø` 与 `Ø→S`（或依真值出入 `Ø`）。
2. **八类互斥转移标签**：
   `1. C→S（真正纠错，不含删错）`｜`2. C→Ø（删除错误）`｜`3. C→C（错误持续，备注原错保留或错换错）`｜`4. Ø→S（新增正确）`｜`5. Ø→C（纯新增错误）` 与 `S→C（同槽正确转错）`｜`6. S→S（保留正确）`｜`7. S→Ø（丢失正确）`｜`8. ·→U / U→·（不确定性变化）`。
3. **事后外部证据对齐（`Align(T)`）**：仅在 L3 对齐完成后，再打开对应视频的外部检索文本 $T$，针对每一条新增错误（`Ø→C` 或 `S→C`），判定该错误事实或其语义等价表述是否出现在 $T$ 中（`1 = 是`，`0 = 否`）。

## 9. 模糊视频、听觉依赖与不确定情况记录方式

遇到任何难以判定或边缘情况，**严禁勉强二选一猜 `S` 或 `C`**，必须按以下规范记录：
- 涉及静音下不可见的听觉信息（谈话主题、语言语种、具体曲目）、专有名词（人名、品牌、地名、具体赛事）、纯主观情绪或严重模糊遮挡 → 标为 **`U`**；
- 在表格的 `uncertainty_reason` 栏填写标准代码：`AUDIO_ONLY`（仅听觉可知）、`WORLD_KNOWLEDGE`（需外部专有知识）、`BLUR_OCCLUSION`（模糊遮挡）、`SUBJECTIVE`（主观心理/评价）、`GRANULARITY_EDGE`（粒度边界争议），以便仲裁员快速定位并修订手册。

## 10. E3 目标事实判定规范（L4 五态，允许共存）

专用于受控干预实验 E3（填写 `TEMPLATE_04_E3_TARGET_L4.csv`）。无需拆解全句，仅针对该视频预先锁定的一对靶事实（视频支持靶 $f^+$ 与最小冲突靶 $f^-$），在隐藏臂名（`Base / Sup / Con / Neu`）下，**分别独立判定**两个问题：
- 问题 A：当前匿名字幕是否清晰表达了目标正确事实 $f^+$（含同义词）？（`1 / 0 / U`）
- 问题 B：当前匿名字幕是否清晰表达了目标错误事实 $f^-$（含同义词）？（`1 / 0 / U`）

由 (A, B) 自动映射到 **L4 五种互斥状态**（绝不强迫 $f^+$ 与 $f^-$ 互斥！）：
1. `NEITHER`（两者均未出现：`A=0, B=0`）；
2. `ONLY_POS`（仅正确事实出现：`A=1, B=0`）；
3. `ONLY_NEG`（仅错误事实出现：`A=0, B=1`）；
4. `BOTH`（两者同时出现，如自相矛盾或并列枚举：`A=1, B=1`）；
5. `AMBIGUOUS`（任一判定为 `U`，如措辞极度含糊无法判断是否指向 $f^+$ 或 $f^-$）。

## 11. 分歧裁决流程

1. 两位标注员提交独立表格后，由汇总脚本标出所有不一致条目（L1 三值分歧、L2 核心覆盖分歧、L3 对齐分歧、L4 五态分歧）。
2. 第三方仲裁员在**同样隐藏实验臂名与外部检索文本**的前提下，观看原视频并审阅两位标注员的理由备注，依据本手册规则做出最终唯一裁决，同时将原两位标注员的独立判断完整存档（绝不覆盖原始双人记录，确保一致性指标可复算）。
3. 若出现手册未覆盖的新型边界情况，仲裁员记录为“规则待补案例”，在标定复盘会统一补充至下一版手册。

## 12. 十二个完整虚构边界示例及标准判定理由

> 以下 12 个示例均为虚构教学案例（不含任何真实 MSR-VTT 样本），专门覆盖高频争议边界。

### 案例 1：单槽同锚真正纠错（`C → S` vs. 删除错误 `C → Ø`）
- **静音视频画面**：一名男子在厨房案板上用刀把整根橙色胡萝卜切成片。
- **L2 预先核心事实**：`CF1: [男子 切 胡萝卜]`。
- **匿名字幕**：`Cap_1`: `"A man is cutting potatoes."`；`Cap_2`: `"A man is cutting carrots."`；`Cap_3`: `"A man is in the kitchen."`
- **标准判定**：
  - L1：`Cap_1` 拆 1 条 `[男子 切 土豆]` → `C`（`N_C=1, N_S=0`）；`Cap_2` 拆 1 条 `[男子 切 胡萝卜]` → `S`（`N_C=0, N_S=1`）；`Cap_3` 拆 1 条 `[男子 在 厨房]` → `S`（`N_C=0, N_S=1`）。
  - L2：`Cap_1` `R_core=0.0`（核心对象错误）；`Cap_2` `R_core=1.0`；`Cap_3` `R_core=0.0`（完全遗漏核心切菜动作，说明 **`N_S=1` 不等于覆盖核心事件！**）。
  - L3（假设 `Cap_1` 为零证据基线）：`Cap_1 → Cap_2` 共享 `[男子 切 ?]` 锚框架，受事由 `土豆(C)` 换为 `胡萝卜(S)` → **真正纠错 `C → S`**；而 `Cap_1 → Cap_3` 未保留动作锚框架，属于 **`[男子 切 土豆] (C → Ø 删除错误)` + `[男子 在 厨房] (Ø → S 新增背景)`**，绝不能算真正纠错！

### 案例 2：禁止上位/下位无限拆分 + 正确细化
- **静音视频画面**：一名穿蓝色 T 恤的年轻女子在公园草地上弹原声木吉他。
- **L2 核心事实**：`CF1: [女子 弹 吉他]`。
- **匿名字幕**：`Cap_1`: `"A woman plays an instrument."`；`Cap_2`: `"A woman in blue plays a guitar in a park."`
- **标准判定**：
  - L1：`Cap_1` 拆 1 条 `[女子 演奏 乐器]` → `S`（`N_S=1`）；`Cap_2` 拆 3 条：`[女子 弹 吉他]` (`S`)、`[女子 穿 蓝衣]` (`S`)、`[在 公园]` (`S`)（`N_S=3`；**严禁**再把 `弹吉他` 拆成 `有女子 + 弹 + 乐器 + 吉他` 刷分！）。
  - L2：`Cap_1` 仅写上位词“乐器” → `R_core = 0.5`（部分覆盖）；`Cap_2` → `R_core = 1.0`。
  - L3（`Cap_1 → Cap_2`）：保留基础 `[女子 演奏 乐器] (S→S)` + 新增 1 层细化 `[乐器是吉他] (Ø→S)` + 新增属性 `[穿蓝衣] (Ø→S)` + 新增地点 `[在公园] (Ø→S)`。

### 案例 3：错误细化（保留基础正确，精准惩罚错误下位词）
- **静音视频画面**：同案例 2（女子弹木吉他）。
- **匿名字幕**：`Cap_1`: `"A woman plays an instrument."`；`Cap_2`: `"A woman plays a violin."`
- **标准判定**：
  - L1：`Cap_2` 核心命题 `[女子 演奏 小提琴]` → `C`（`N_C=1, N_S=0`）。
  - L2：`Cap_2` 核心对象错误 → `R_core = 0.0`。
  - L3（`Cap_1 → Cap_2`）：共享 `[女子 演奏 ?]` 锚，基础演奏行为正确但具体乐器错误，记为 `演奏基础保留 (S→S)` + `错误细化 [乐器是小提琴] (Ø→C)`。

### 案例 4：同义表达绝不拆成一删一增
- **静音视频画面**：一只棕色狗在草坪上追逐一只白色猫。

- **标准判定**：
  - L1：两条均规范化为 `[狗 追 猫] (S)`、`[狗是棕色] (S)`、`[猫是白色] (S)`（`N_S=3, N_C=0`）。
  - L3：`chasing` 与 `runs after` 在该画面中语义等价，全部记为 `S → S`（保留正确），**禁止**记成 `chasing (S→Ø)` + `runs after (Ø→S)`。

### 案例 5：服饰/场景不能自动证明人物真实身份

### 案例 6：静音条件下的听觉依赖事实（严禁判 `C`）

### 案例 7：论元角色反转（施事与受事互换）

### 案例 8：多事件视频中的不相关事件切换（严禁强行槽位对齐）
- **静音视频画面**：前 6 秒是一名男子切洋葱，后 6 秒是一名女子品尝碗里的汤。
- **L2 核心事实**：`CF1: [男子 切 洋葱]`、`CF2: [女子 尝 汤]`（2 条核心事实）。
- **匿名字幕**：`Cap_1`: `"A man is chopping onions."`；`Cap_2`: `"A woman is tasting soup."`
- **标准判定**：
  - L1：两条各自拆 1 条核心命题，均判 `S`（`N_S=1, N_C=0`）。
  - L2：`Cap_1` 覆盖 `CF1=1.0, CF2=0.0` → `R_core = 0.5`；`Cap_2` 覆盖 `CF1=0.0, CF2=1.0` → `R_core = 0.5`。

### 案例 9：句内同义冗余（防重复计数）

### 案例 10：同一字幕内部自相矛盾

### 案例 11：时序与事件结果错误（`Temporal-Outcome`）

  - L2：`CF1 = 1.0`，`CF2 = 0.0`（结果相反）→ `R_core = 0.5`。

### 案例 12：E3 靶事实 L4 五态共存案例（绝不强迫互斥）
- **静音视频画面**：一名男子切胡萝卜（预定义靶事实：$f^+ = \text{切胡萝卜}$，$f^- = \text{切土豆}$）。
- **四条匿名输出**：
  - `Out_1`: `"A man is cooking dinner."` → `A(f^+)=0, B(f^-)=0` → **`NEITHER`**；

  - `Out_3`: `"A man cuts potatoes."` → `A=0, B=1` → **`ONLY_NEG`**；
  - `Out_4`: `"A man is cutting potatoes and carrots."` → `A=1, B=1` → **`BOTH`**（同时包含正确与错误靶事实，必须完整记录，绝不强行二选一！）；
