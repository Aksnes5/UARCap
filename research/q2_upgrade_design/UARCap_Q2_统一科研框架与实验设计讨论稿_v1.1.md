## 摘要与核心修订定位

经过第一轮审阅与共同讨论，各方已就 UARCap Q2 升级的总体定位达成共识：**坚持方案 III——外部证据效用与视频事实风险的联合诊断研究**，即完整继承 `v0.8` 既有冻结资产，以架构匹配的零外部证据条件作为共同参照，深入识别外部检索如何改变视频描述中的真实与错误事实，通过视觉输入受控的最小配对语义干预建立行为因果证据，并开展跨模型与新数据集外部验证，**不再强行开发普通动态检索或重排序算法（E4 移出主要计划贡献）**。

针对 `v1.0` 在理论定义、因果识别、置换检验数学有效性、跨模型/跨数据解耦、统计门控与人工标注可行性上的七项 P0 缺陷，本版 `v1.1` 完成如下定向重构：
1. **重构事实状态转移体系**：放弃将“替换纠错”与“单纯删除错误”混为一谈的旧 `Corr` 定义，结合 `{S, C, U, Ø}` 四状态空间与**严格受限同指槽位对齐规程**（E2 采用规范化命题集 + 同指对齐、E3 采用预定义靶槽位，避免在开放字幕中强行跨不相关事件配对），并给出 10 类完整边界案例与唯一判定规则；
2. **取消未经论证的单一净事实总分 `B_fact`**：确立 E2 的**双主终点**——每视频错误命题数 $N_C(y)$ 与每视频支持命题数 $N_S(y)$（其配对差值天然满足精确会计恒等式，既无任意权重假设，也杜绝通过少说信息或堆砌细节套利），并将 `C→S`（真正纠错）、`C→Ø`（删除错误）等划为清晰的解释性次要终点；
3. **统一结构化多模态证据输入表达**：采用 $y = G(v, T, V; I, \theta, d)$ 完整刻画有序文本序列 $T$、实际视觉张量及对应关系 $V$ 与接口 $I$，将“拒绝检索”规范更名为 `external-evidence withholding` / `zero-evidence selection`；
4. **严密化 E3 因果识别**：构建共享基础输入 `Base` 下的四臂结构（`Base / Sup / Con / Neu`），明确 `Neu` 为**相对靶事实中性且与视频其余画面相容**的对照文本，用 `Con vs. Neu`（错误采纳增加与正确事实抑制）和 `Sup vs. Neu`（正确事实促进）拆解正负效应，剔除混合的 `Sup − Con`；
5. **修正 E1 参考集劈半与置换方案**：指出并纠正“选择侧与评价侧同步置换导致数学恒等”的漏洞，给出**解耦评价侧置换**的手工数值示例与分离 IDF 拟合规范，明确 E1 仅为前置探索诊断；
6. **解耦 E5 的跨模型、跨接口与跨数据集验证**：在共同 MSR-VTT 查询子集上执行跨模型/跨接口比较，在同一现代模型上执行 MSR-VTT 与未触碰确认队列（如 VATEX）的跨数据集泛化；基于对历史 MSVD 收据的复核，将 MSVD 匹配零证据对照修正为含运行时 trace 的 `A0 + A1 + A3` 三臂重跑；
7. **收缩为 3 个主科学问题（RQ1–RQ3）与 3 个主假设（H1–H3）**，严格区分 SESOI、MDE 与试点可行性检查，移除缺乏依据的机械硬阈值，并按任务环节重新核算真实人工标注工作量（约 30–45 人时试点 / 110–160 人时全套）。

## 1. 认知层级声明与既有 `v0.8` 科学事实边界

为杜绝将“尚未验证的设计构想”与“已经冻结的实证结果”混为一谈，本讨论稿在全文严格区分四个认知层级：
- **层级 A（已完成并冻结的 `v0.8` 实证基础）**：百万级嵌套 VideoUFO 外部记忆的检索可得性与生成效用解耦、MSR-VTT/MSVD 联合预算梯度、MSR-VTT 预注册实验 A 与实验 B 的冻结统计结果与运行时完整性验证；
- **层级 B（本稿 `v1.1` 拟提出的评价与形式化定义）**：四状态受限对齐事实转移体系、双主终点 $(N_C, N_S)$ 帕累托平面、结构化多模态证据接口表达 $G(v, T, V; I, \theta, d)$ 与四臂最小配对干预规范；
- **层级 C（尚待实验检验的科学假设）**：H1（自然检索下的事实状态转移）、H2（视觉锁定下的靶事实行为因果效应）与 H3（跨模型/跨接口/跨数据集边界）；
- **层级 D（实验获得支持后可能形成的论文贡献，及未获支持时的有限诚实解释）**：第 14 章分情景预案，不预设任何假设必然成立。

### 1.1 不可逾越的 `v0.8` 冻结事实边界

1. **嵌套语料规模与解耦**：VideoUFO 六个嵌套清单（`10K` 至 `FULL = 1,091,712` clips，`345,437` 来源视频，与 MSR-VTT 零精确来源 ID 重叠）在修复后 `val497`（`361` 源簇）上带来单调的 top-1 X-CLIP 相似度提升（CF `+0.0259`，D `+0.0319`）与近全量候选更替（`494/497` 与 `495/497`），但 72 项验证网格中 0 项通过 BH 校正（最小查询级 $q = 0.1649$），查询级相似度变化与 CIDEr 变化秩相关近零（$\rho = .011$ / `.007`）。
2. **跨基准联合预算梯度**：MSR-VTT `test2690`（`2,004` 源簇，原训练预算 $k=7$）上 `D1 → D7` 从 `71.21` 降至 `68.27`（`D1 − D7 = +2.93`, `[+1.83, +4.06]`, BH $q = .0007$）；MSVD `test670`（`522` 源簇，原训练预算 $k=3$）上从 `156.39` 降至 `141.59`（训练区间内 `D1 − D3 = +4.94`, $q = .0069$；超预算外推 `D3 − D7 = +9.86`, $q = .0003$）。受限 Adaptive 基线（`70.67` / `151.94`）未优于固定 `D1`。
3. **实验 A（MSR-VTT `n = 2,690`, `2,004` 源簇）**：`A0 = 69.81`、`A1 = 71.21`、`A7 = 68.27`。`A1 − A0 = +1.40`（`[+0.45, +2.36]`，原始 $p = .0033$，A 族 Holm $p = .0066$，五检验联合 Holm $p = .0165$）；`A7 − A0 = −1.54`（`[−2.94, −0.18]`，A 族 Holm $p = .0271$，五检验联合 Holm $p = .0813$）。`A1 / A7` 与历史 `D1 / D7` 在全部 2,990 条输出上一致，属于端点复现核验而非独立新样本。
4. **实验 B（MSR-VTT 合格子集 `n = 2,618`, `1,969` 源簇）**：逐查询运行时哈希证实 `B3`、`B7HQ`、`B7LQ` 的 3 条检索视觉特征、相似度权重、聚合张量、注意力 K/V、门控输入与视觉投影完全一致。`B3 = 69.88`（平均 prompt 长度 `150.69`）、`B7HQ = 68.62`（`226.86`）、`B7LQ = 68.75`（`226.38`）。`B7HQ − B3 = −1.27`（族内 Holm $p = .0573$）、`B7LQ − B3 = −1.13`（族内 Holm $p = .0612$）均未通过 B 族 Holm；`B7HQ − B7LQ = −0.14`（`[−1.05, +0.80]`, $p = .7698$）无定论，平均原始 X-CLIP 间隔仅 `0.00835`。A/B 全部五项对比均未达到预定 `±1.0` CIDEr 实践清晰边界，且两实验参考 IDF 各自拟合，绝对均值不可跨实验比较。
5. **修复后历史诊断与可复用资产**：解码修复后验证集 Oracle 显示同池选择空间（`Oracle3 − D3 = +3.04`, $q = .0146$）与前缀扩展下降（`Oracle7 − Oracle3 = −2.73`, $q = .0146$，但同时改变条数、兼容度与视觉特征）；18 项机制对照（含 `GoodTail / HardWrong / EasyWrong`）与 8 项 `val150` 留一对照均未通过 BH 校正。`test2690` 上从 `D1` 到 `D7` 平均句长由 `7.92` 增至 `8.75` 词、外部并集 trigram 匹配率由 `0.142` 升至 `0.334`（固定 top-1 匹配率由 `0.142` 升至 `0.190`），且历史 SPICE 反而微升。

## 2. 文献定位与克制的创新性边界

结合第一轮已核实的 2023–2026 年文献（完整对照表见 `CLOSEST_PRIOR_WORK_MATRIX.md`），本设计严格避免“首次”“真实真空地带”等未经穷尽证明的绝对化宣称，而是以克制、可核验的方式界定与四类最邻近工作的差异：

1. **与检索增强描述架构及鲁棒性研究的差异**：前作 Fang 等（*Displays*, 2026）提出域内检索与跨门控融合架构；Li 等（ACL 2024）在静态图像描述模型 SmallCap 上分析了检索顺序与相关性扰动及多数派词元复制现象。相比之下，本设计聚焦**视频动态多模态场景**，在保留匹配零外部证据基线与视觉输入控制的前提下，考察自由文本视频描述的原子事实变化与跨接口泛化边界。
2. **与多模态效用导向检索与选择性利用研究的差异**：Luo 等（ACL 2026）研究了多模态 VQA 的免训练效用导向视觉证据选择；SURf（EMNLP 2024）与 Adaptive-$k$（EMNLP 2025）分别探索了选择性利用微调与无阈值截断；SpecUBench（CIKM 2026）探讨了生成器特异性效用；MAD-RAG（ICML 2026）诊断了 VQA 中的注意力分散。正因为这一方向已有密集方法工作，本设计**明确不以提出新的通用重排器或门控算法作为核心卖点**，而是聚焦上述文献尚未系统拆解的视频描述事实转移与受控行为因果效应。
3. **与独立视频描述事实性及幻觉评测的差异**：FactVC（EMNLP 2023）、FaithScore（EMNLP Findings 2024）、EventHallusion（2024）、VideoHallucer（2024）、VidHalluc（CVPR 2025）、ARGUS（ICCV 2025）与 CapQuiz（ACL 2026）均建立了无检索独立模型的原子事实、幻觉或遗漏评测工具。本设计主动借鉴其原子视觉命题切分与幻觉/遗漏双重视角，将其迁移至**零外部证据与有检索条件之间的配对状态转移评价**，而非宣称发明另一套通用单模型幻觉基准。

## 3. 收缩后的统一科学问题

为使整篇研究结构紧凑、避免在单一问题中堆砌过多技术细节，我们将核心科学问题精炼为一句清晰主问：

> **核心科学问题**：  
> **相对于架构匹配的零外部证据条件，外部检索如何改变视频描述中的事实正确性与信息覆盖，以及这些变化能否通过视觉受控的证据干预得到解释并在不同模型接口中界定其迁移边界？**

据此收缩为 **3 个主要研究问题（RQ1–RQ3）**，与后续三个主实验（E2、E3、E5）形成严格一一对应（E1 定位为前置探索，E4 移出主要计划贡献）：

- **RQ1（事实状态转移，对应 E2）**：相对于架构匹配的零外部证据基线，外部检索证据（不同预算）如何改变视频描述中的错误事实负担与视频支持事实覆盖（并拆解为真正纠错、删除错误、新增错误、正确转错、新增正确与丢失正确）？
- **RQ2（视觉受控的行为因果效应，对应 E3）**：在查询视频与实际视觉输入保持固定的条件下，外部文本中针对预定义目标事实的冲突（相对于靶事实中性的对照文本）是否因果地提高对应错误事实的生成概率并抑制目标正确事实？
- **RQ3（跨模型、跨接口与跨数据集边界，对应 E5）**：上述检索引起的事实变化与受控干预效应，在共同查询子集上的现代开源原生视频语言模型中以及在新来源确认队列上是否复现，抑或呈现出明确的系统与接口依赖边界？

## 4. 统一证据输入与操作的形式化框架

### 4.1 结构化多模态证据输入模型

`v1.0` 使用无序子集 $S \subseteq C(v)$ 表示检索输入，无法准确表达原 UARCap 的**双模态输入通道、文本顺序属性及图文非一对一配对**（例如实验 B 中 7 条文本配 3 条固定视觉特征，以及 E3 中纯文本槽位干预）。本版统一改用结构化输入函数：
$$y = G\big(v,\; T,\; V;\; I,\; \theta,\; d\big)$$
其中：
- $v \in \mathcal{V}$：查询视频（含固定帧采样与预处理规范）；
- $T = (c_1, c_2, \dots, c_m)$：**有序**外部文本证据序列（$m = 0$ 时记为空序列 $T = \emptyset$）；
- $V = \big((\tilde{v}_1, w_1), \dots, (\tilde{v}_r, w_r);\; \mu\big)$：实际加载并输入生成器的外部视觉特征序列 $(\tilde{v}_j)$、对应融合权重 $(w_j)$ 以及文本—视觉对应映射 $\mu \subseteq \{1,\dots,m\} \times \{1,\dots,r\}$（无外部视觉特征时记为 $V = \emptyset$）；
- $I$：证据接口规范（如 Video-LLaMA 的 32-token cross-gating 视觉融合 + 文本提示模板 $I_{\text{x-gate}}$，或现代 VLM 的原生多帧序列 + 文本提示模板 $I_{\text{prompt}}$）；
- $\theta$：冻结模型权重；$d$：固定解码配置（束宽、随机种子、模块模式等）。

**清晰区分八类易混淆操作**：
1. **候选搜索（Candidate Search）**：检索器在外部记忆库中为查询 $v$ 召回 top-$M$ 候选池 $C(v)$ 的计算过程；
2. **候选选择（Candidate Selection）**：从 $C(v)$ 中确定拟供给生成器的候选子集及排序；
3. **文本输入（Text Input $T$）**：按特定顺序拼入提示词的外部字幕序列；
4. **视觉输入（Visual Input $V$）**：实际加载进入跨模态融合或视觉编码通道的外部视频张量及权重；
5. **文本顺序（Text Order）**：序列 $T$ 中各字幕的位置排列（一般不假设顺序无关）；
6. **模态配对关系（Modality Binding $\mu$）**：文本槽位与外部视觉张量是一对一绑定（$m=r$）、部分绑定（如 $B7$ 中 $m=7, r=3$）还是纯文本无视觉绑定（$r=0$）；
7. **零外部证据 / 外部证据保留不用（Zero-Evidence Selection / External-Evidence Withholding）**：已执行候选搜索后决定向生成器提供 $(T=\emptyset, V=\emptyset)$；**不再使用易混淆的“拒绝检索”作为独立算法术语**，严格区别于“跳过检索搜索计算”与“生成器拒绝输出描述”；
8. **证据追加（Evidence Extension）**：在既有输入状态 $(T, V)$ 上执行显式操作 $\mathrm{op}$（如纯文本追加 $T \oplus (c_{\text{new}})$ 或图文联合追加），其**条件边际效应**定义为：
$$\Delta_U\big(\mathrm{op} \mid v, T, V\big) = U\big(G(v, \mathrm{op}(T, V); I, \theta, d)\big) - U\big(G(v, T, V; I, \theta, d)\big)$$
该定义**不假设**证据顺序无关、文本与视觉模态可交换，或边际效应满足可加性/单调性/次模性。

### 4.2 历史与拟议实验条件在统一表达式下的映射

| 实验条件 | 文本序列 $T$（长度 $m$） | 实际视觉输入 $V$（数量 $r$） | 配对映射 $\mu$ | 证据接口 $I$ |
|---|---|---|---|---|
| **A0**（MSR-VTT / MSVD 零外部证据） | $\emptyset$（$m=0$） | $\emptyset$（$r=0$，聚合与 K/V 为零张量） | 空映射 | $I_{\text{x-gate}}$ |
| **A1 / A7**（冻结联合预算） | D 序前 1 / 7 条字幕 | 对应前 1 / 7 条外部 clip 张量及原始 X-CLIP 权重 | 一对一绑定（$m=r$） | $I_{\text{x-gate}}$ |
| **B3**（实验 B 固定头部） | D 序前 3 条字幕 | 对应前 3 条锁定外部 clip 张量 | 一对一绑定（$m=r=3$） | $I_{\text{x-gate}}$ |
| **B7HQ / B7LQ**（固定视觉文本扩展） | D 序前 3 条 $\oplus$ 4 条 HQ/LQ 字幕（$m=7$） | 与 B3 逐查询哈希一致的 3 条张量（$r=3$） | 仅前 3 条绑定，后 4 条空绑定 | $I_{\text{x-gate}}$ |
| **E3 主设置（Base=`A0`）** | `Base`: $\emptyset$；`Sup/Con/Neu`: 单条靶干预字幕 $(c^*)$（$m=1$） | $\emptyset$（$r=0$，四臂均无外部视觉张量） | 纯文本无外部视觉绑定 | $I_{\text{x-gate}}$ 与 $I_{\text{prompt}}$ 共用 |
| **E3 敏感性设置（Base=`B3`）** | `Base`: D3 头部（$m=3$）；三干预臂：D3 $\oplus (c^*)$（$m=4$） | 四臂共享哈希锁定的 B3 三条外部张量（$r=3$） | 前 3 条绑定，第 4 条纯文本空绑定 | $I_{\text{x-gate}}$ |
| **E5 现代原生 VLM（$k \in \{0,1,3,7\}$）** | 空或 D 序前 $k$ 条外部字幕（$m=k$） | $\emptyset$（仅查询视频原生帧，$r=0$） | 纯文本提示注入 | $I_{\text{prompt}}$ |

## 5. 事实状态转移体系的严格重构（P0 修订一）

### 5.1 对纯四状态槽位矩阵的批判性评估与双轨统一方案

第一轮审查准确指出 `v1.0` 中 `Corr` 混入了“错误被正确事实替代”与“错误被直接删除”，会导致模型仅靠缩短字幕即可赚取虚假纠错收益。针对审查建议的 `{S, C, U, Ø}` 四状态转移空间，本轮进一步检验了其**语义对齐可行性风险**：

- **为什么在自由文本字幕（E2）中不能盲目套用全局强制槽位矩阵？**  
  在受控干预（E3）中，研究预先指定了唯一的**目标语义槽位**（如 `[主动作]` 或 `[核心受事对象]`），因此四状态转移 `{S, C, U, Ø} → {S, C, U, Ø}` 定义完全无歧义。然而，在自然自由文本生成（E2）中，同一视频在 `A0` 下可能输出 `"A man is talking in a room"`，在 `A7` 下却输出 `"A woman is cooking pasta in a kitchen"`。如果为了把所有命题塞进槽位矩阵而强行将“男人在房间说话”与“女人在厨房煮意面”对齐到同一槽位，会人为制造荒谬的“跨事件替换”，引发严重标注分歧与重复计数！

- **因此，`v1.1` 确立严谨且可操作的“分层对齐统一体系”**：
  1. **E3（受控因果干预）**：直接使用**预定义目标事实槽位（Predefined Target Slot）**上的四状态编码 `{S, C, U, Ø}`（外加二元靶事实采纳指示），彻底消除对齐歧义；
  2. **E2（自然自由文本转移）**：采用**规范化原子命题集合 + 严格受限同指槽位对齐（Constrained Same-Referent Slot Alignment）**——首先在隐藏臂标签下分别将 $y_0$ 与 $y_S$ 拆解为规范化原子视觉命题（归入四类：`Entity`、`Attribute`、`Action-Role`、`Temporal-Outcome`），然后**仅在满足以下两条严格条件之一时**才将 $a_0 \in \mathcal{A}(y_0)$ 与 $a_S \in \mathcal{A}(y_S)$ 对齐为同一单元：
     - **条件 A（语义等价对齐）**：指向视频中同一视觉指称对象/事件，且命题语义等价（含同义词、主动/被动语态转换或轻微语法改写）；
     - **条件 B（单槽同锚替换）**：共享完全相同的核心指称锚框架（例如相同的实体指称与动作框架），仅在**单一语义槽位取值**上发生替换（典型例：`"A man cuts potatoes"` 与 `"A man cuts carrots"` 共享锚 `[Entity: man] + [Action: cuts] + [Patient: ?]`，仅受事槽位由 `potatoes` 替换为 `carrots`）。
  - 凡不满足条件 A 或条件 B 的命题**严禁强行跨事件对齐**，一律映射至/来自缺失态 `Ø`！

### 5.2 基于受限对齐的完整八类状态转移定义

在完成上述盲法对齐后，每一个对齐单元（或未对齐独立命题）从零外部证据状态 $s_0 \in \{S, C, U, \emptyset\}$ 到有证据状态 $s_1 \in \{S, C, U, \emptyset\}$ 均落入如下**互斥、完备且无重复计数**的八类转移：

| 编号 | 转移类型（中/英） | 状态跃迁 | 操作性含义与直觉示例 |
|---|---|---|---|
| 1 | **真正纠错（True Factual Correction）** | `C → S` | 同一语义槽位由错误取值替换为视频支持的正确取值（如 `cuts potatoes (C) → cuts carrots (S)`）。**绝不包含单纯删除错误！** |
| 2 | **删除错误（Error Deletion）** | `C → Ø` | $y_0$ 中的错误命题在 $y_S$ 中消失，且未在同一槽位给出正确替代（如删去错误的 `in a park`，但未补出正确地点）。 |
| 3 | **错误持续（Error Persistence）** | `C → C` | 同一错误命题保留，或同一槽位从一个错误取值变为另一个错误取值（如 `cuts potatoes (C) → cuts onions (C)`，在细分记录中可区分“原错保留”与“错换错”）。 |
| 4 | **新增正确事实（Grounded Addition）** | `Ø → S` | $y_S$ 新表达了 $y_0$ 未涉及且被视频明确支持的正确命题（非替换原有 `C` 槽位）。 |
| 5 | **新增错误事实（Error Introduction）** | `Ø → C` 与 `S → C` | 细分为**纯新增污染（`Ø → C`）**与**同槽正确转错（`S → C`，Direct Corruption**，如 `cuts carrots (S) → cuts potatoes (C)`，性质比纯新增更恶劣！）；在真值与对齐锁定后，再单独标记是否与外部文本 $T$ 语义对齐（`Align(T)`）。 |
| 6 | **保留正确事实（Grounded Retention）** | `S → S` | $y_0$ 中已正确表达的命题在 $y_S$ 中继续保持正确。 |
| 7 | **丢失正确事实（Grounded Omission）** | `S → Ø` | $y_0$ 中视频支持的正确命题在 $y_S$ 中消失（且非同槽转为 `C`）。 |
| 8 | **不确定性变化（Uncertainty Shifts）** | `· → U` 与 `U → ·` | 细分为 `Ø→U`、`U→Ø`、`U→U`、`U→S`、`U→C`、`S→U`、`C→U`（如具体动词 `slicing (S)` 退化为笼统表述或无法核验内容 `U`）。始终独立统计，严禁并入 `S` 或 `C`。 |

### 5.3 十类边界案例与唯一人工判定规则

为确保双人标注与仲裁零自由裁量漂移，确立以下 10 条唯一判定规则（写入标注手册核心附录）：

1. **同义表达（Synonymy / Paraphrase）**：`"A man is slicing carrots"` vs. `"A guy is cutting carrots"` → 视觉指称相同且动作语义等价 → 判定为同一单元 `S → S`（保留正确事实），**不拆分为一删一增**。
2. **单槽同锚替换（Same-Slot Substitution）**：`"A man cuts potatoes"`（视频实为切胡萝卜）vs. `"A man cuts carrots"` → 共享 `[Entity: man] + [Action: cuts]` 锚框架（`man: S→S`, `cuts: S→S`），仅受事槽位发生单值替换 → 受事单元判为 **`C → S`（真正纠错）**；若是 `"cuts carrots"` 变为 `"cuts potatoes"` 则判为 **`S → C`（同槽正确转错）**。
3. **事实粒度差异（Granularity Shift，上位词 vs. 下位词）**：
   - 情形 3a（正确细化）：`"A man plays an instrument"`（`S`）变为 `"A man plays a guitar"`（视频确为吉他，`S`）→ 拆分为基础命题 `plays instrument (S→S)` + 细化属性/类别命题 `instrument is guitar (Ø→S)`，记为保留基础正确 + 新增 1 条正确细化，避免误记为替换或丢失；
   - 情形 3b（错误细化）：`"plays an instrument (S)"` 变为 `"plays a violin (C)"`（实为吉他）→ 基础命题 `plays instrument (S→S)` + 细化类别 `is violin (Ø→C)`（记为新增错误，不抹杀原动作正确性）；
   - 情形 3c（正确粗化）：`"plays a guitar (S)"` 变为 `"plays an instrument (S)"` → `plays instrument (S→S)` + 细节 `is guitar (S→Ø)`（丢失 1 条正确细化信息）。
4. **部分匹配（Partial Match / 复合事件拆分）**：`"A woman rides a red bike"` 变为 `"A woman rides a blue bike"` → 按最小原子切分原则拆为三条独立命题：① `[Entity/Action-Role] woman rides bike`（`S→S`）；② `[Attr] bike is red/blue`（同一颜色槽位，依视频真值判 `S→C` 或 `C→S`）。**禁止把整句打包成单个命题**。
5. **实体共指与身份细分（Entity Coreference）**：`"A person"` 与 `"A chef"` 指画面同一人物：若画面可见厨师服（`S`），按规则 3a 记为 `person (S→S)` + 身份细化 `is chef (Ø→S)`；若画面无法判断是否厨师（穿普通 T 恤），则身份细化记为 `Ø→U`。若 `"a man"` 变为 `"a woman"`（视频为男性），则性别属性槽位判为 `S → C`（同槽转错）。
6. **一对多与多对一事实（One-to-Many / Many-to-One）**：`"Two people are fighting"` 变为 `"A man punches another man"` → 若视频确为两人打斗且一方挥拳，分解为共享核心事件 `two people fighting / physical altercation (S→S)` + 新增具体动作/角色 `one man punches the other (Ø→S)`；反之多对一则未保留的子事实计入 `S→Ø`。
7. **句内重复计数防御（Duplicate / Pleonastic Phrasing）**：若单条字幕出现语义重复表述（如 `"A dog is running and racing fast"` 中 `running` 与 `racing` 指同一奔跑动作），在 Stage A 规范化切分阶段**强制合并为单一原子命题**，严禁重复计入多个 `S` 或 `C`。
8. **同一字幕内部自相矛盾（Intra-Caption Self-Contradiction）**：若单条字幕同时写出 `"A man stands still while running down the street"`，两条冲突命题均须**分别独立保留并核验真值**（至少其一必为 `C`，或两者皆 `C`），严禁互相抵消或合并消去。
9. **缺失 vs. 无法核验（Missing `Ø` vs. Unverifiable `U`）**：视频里有人弹吉他且在说话（静音画面看不出在唱哪首歌）。若字幕根本没提唱歌，对应状态为 **`Ø`**；若字幕写了 `"singing a Beatles song"`，画面见张嘴但无法视觉核验是否 Beatles 歌曲，则 `singing` 若有明确口型/麦克风视觉证据可判 `S`（否则 `U`），而 `song is by Beatles` 必须判为 **`U`**（绝非 `C`，也非 `Ø`）。
10. **多事件视频中的不相关事件切换（Unrelated Event Shift）**：视频前半段为“厨师切胡萝卜”，后半段为“女子品尝汤”。若 $y_0$ 写 `"A chef cuts carrots"`（`S`）而 $y_S$ 写 `"A woman tastes soup"`（`S`），二者属于**不同主事件**，**严禁强行槽位对齐为替换**！正确记录为：`chef cuts carrots (S → Ø)` 且 `woman tastes soup (Ø → S)`——清晰体现“丢失了前一个正确事件、新增了另一个正确事件”，总支持命题数 $\Delta N_S = 0$。

## 6. 取消单一净事实总分与多维核心终点体系（P0 修订二）

### 6.1 为何必须废除 `B_fact = Corr + Gain − Contam − Omit` 作为主终点？

第一轮审查精准指出了 `v1.0` 单一标量总分 `B_fact` 的根本方法学漏洞：
1. **隐含未经证明的等权假设**：把“删除一个无关紧要的背景属性”与“引入一个错误的核心动作”按 `1:1` 相抵，或允许“新增三条平庸正确的背景细节（如有人、在室内、有桌子）”去掩盖一条致命的核心动作幻觉（如把“游泳”说成“滑雪”），在语义上完全站不住脚；
2. **诱导句长套利**：仅看 `FactPrec = N_S / (N_S + N_C)` 会强烈奖励“惜字如金、只说一句绝对不会错的废话（如 `A person is doing something`）”的模型；而无约束的线性加减则可能因不同句长下 $N_S$ 与 $N_C$ 的边际斜率不同而产生误导性排序。

因此，`v1.1` **正式废除 `B_fact` 作为主要终点**（仅可在附录中标注“等权敏感性参考”，严禁作为主科学结论依据）。

### 6.2 精简的双主终点与固定帕累托坐标轴

为兼顾**防止多重检验爆炸**与**防止单一标量套利**，E2 仅设立 **2 个共同主要终点（Co-Primary Endpoints）**，其余维度统一归为结构化解释性次要终点：

1. **主终点 1（事实错误负担，Risk Primary Endpoint）**：每视频平均反驳命题数 $N_C(y)$ 及其相对零外部证据的配对变化量：
$$\Delta N_C(v) = N_C(y_S) - N_C(y_0) = \big(N_{\emptyset\to C} + N_{S\to C} + N_{U\to C}\big) - N_{C\to S} - \big(N_{C\to \emptyset} + N_{C\to U}\big)$$
2. **主终点 2（真实信息覆盖，Grounded Coverage Primary Endpoint）**：每视频平均视频支持命题数 $N_S(y)$ 及其相对零外部证据的配对变化量：
$$\Delta N_S(v) = N_S(y_S) - N_S(y_0) = \big(N_{\emptyset\to S} + N_{C\to S} + N_{U\to S}\big) - \big(N_{S\to \emptyset} + N_{S\to C} + N_{S\to U}\big)$$

**为何 $(\Delta N_C, \Delta N_S)$ 是最严谨、不可套利的双主终点？**
- **天然反作弊**：若检索策略只是通过把句子变短、删除信息来降低错误（`C → Ø`），$N_C$ 下降的同时 $N_S$ 会同步下跌，双主终点立刻将其暴露为“缩水换安全”，而非真正改进！唯有同时实现 $\Delta N_C \le 0$ 且 $\Delta N_S > 0$（或 $\Delta N_C < 0$ 且 $\Delta N_S \ge 0$），才代表真正的帕累托支配改进；
- **精确会计恒等式**：无需任何人为权重，八类状态转移恰好构成 $\Delta N_C$ 与 $\Delta N_S$ 的精确加性分解；
- **帕累托前沿坐标轴完全统一**：全文任何模型、任何预算（`A0`, `A1`, `A7`, 现代 VLM）全部固定映射在完全相同的二维平面——**横轴：每视频平均错误命题数 $\mathbb{E}[N_C]$（越低越优）；纵轴：每视频平均支持命题数 $\mathbb{E}[N_S]$（越高越优）**，绝不在不同策略间切换收益或风险口径！

**解释性次要终点（不进入主假设检验家族，采用探索性汇报与 FDR 控制）**：
1. 真正纠错率（每视频 `C → S` 均值，以及在有基础错误的查询中 `N_{C→S} / N_C(y_0)`）；
2. 单纯删除错误率（每视频 `C → Ø`）；
3. 新增错误拆解（纯污染 `Ø → C`、同槽转错 `S → C`，以及证据对齐子集 `Align(T)` 占比）；
4. 原有正确事实保留率（`N_{S→S} / N_S(y_0)`，对 $N_S(y_0) > 0$ 视频计算）与丢失率（`S → Ø`）；
5. 可核验事实精确率 $\text{FactPrec} = N_S / (N_S + N_C)$ 与不确定命题占比 $N_U / (N_S + N_C + N_U)$；
6. **核心事件覆盖率（Core Event Coverage，可选高价值次要指标）**：在 E2/E5 抽样视频中，由标注者在观看视频时独立预先圈定 1–2 个“最显著核心动作/主体事件”，评估生成字幕是否覆盖核心事件，直接反制“靠堆砌次要背景细节刷高 $N_S$”的潜在偏差；
7. 传统词面指标（PTB CIDEr、句长与外部 trigram 复用率，用于与 `v0.8` 衔接）。

## 7. 收缩后的三个核心科学假设（H1–H3）

响应 P0 修订七，本版取消原 `v1.0` 中与动态算法选择耦合的假设（旧 H3），**只保留 3 个直接映射 RQ1–RQ3、边界清晰且严格可证伪的主假设**，并彻底厘清 **SESOI（最小实际有意义效应）** 与 **MDE（给定样本量与功效下的最小可检测效应）** 的区别。

### 假设 H1（自然检索下的非对称事实转移假说，对应 RQ1 / E2）
- **理论动机**：`v0.8` 已发现 MSR-VTT 上 `A1 > A0 > A7` 的 CIDEr 排序，但无法确认其语义实质。H1 检验在冻结架构中，外部证据预算扩张（$k=0 \to 1 \to 7$）究竟如何改变每视频的错误命题数 $N_C$ 与支持命题数 $N_S$。
- **形式化定义**：在配对零证据参照下，检验主比较族（2 主终点 × 2 核心预算跃迁 = 4 项预注册主检验，族内 Holm $\alpha = 0.05$）：
  - `(H1a)` `A1 vs. A0`：$\mathbb{E}[N_S(A1) - N_S(A0)]$ 与 $\mathbb{E}[N_C(A1) - N_C(A0)]$；
  - `(H1b)` `A7 vs. A1`：预期 $\mathbb{E}[N_C(A7) - N_C(A1)] > 0$（大预算显著推高错误负担），同时检验 $\mathbb{E}[N_S(A7) - N_S(A1)]$ 是否出现停滞或下降。
- **自变量 / 因变量 / 控制变量**：自变量为冻结联合预算 $k \in \{0, 1, 7\}$；双主因变量为视频级 $N_C(y)$ 与 $N_S(y)$；控制同一查询视频、冻结权重、解码配置与双人盲法标注。
- **实验单位与统计检验**：独立来源查询视频（每来源至多 1 视频，来源与视频同层）；采用 10,000 次配对自助法 95% 逐项置信区间与 10,000 次双侧 **Monte Carlo 符号翻转置换 $p$ 值**（4 项主检验族内 Holm 校正）。
- **SESOI vs. MDE 区分**：
  - **SESOI（研究领域先验设定）**：每视频平均错误命题数变化 $|\Delta N_C| \ge 0.15$ 条（约每 7 条视频净增/减 1 条错误事实）或支持命题数变化 $|\Delta N_S| \ge 0.20$ 条；
  - **MDE（样本量与功效函数）**：不预设凭空数字，由独立试点测得的配对标准差 $\hat{\sigma}_d$ 与不一致率决定正式确认样本量（详见第 11 章功效表）。
- **反驳条件与有限诚实解释**：若 `A7 vs. A1` 的 $\Delta N_C$ 95% 区间完全落在 $[-0.10, +0.10]$ 内且 $N_S$ 未现退化，则反驳“大预算主要因事实污染恶化”假说。此时**不越界宣称“证明 CIDEr 存在普遍失真”**，而仅在观测精度内诚实解释：*在当前采样精度下，未观测到支持大预算事实错误大幅上升的证据，`A1 > A7` 的 CIDEr 差异可能更多与输出句长、词面选择或未被四维原子命题覆盖的风格差异有关*。

### 假设 H2（视觉输入锁定下的靶事实行为因果假说，对应 RQ2 / E3）
- **理论动机**：自然检索中内容、长度、相关性与视觉输入高度混杂（也是历史 `HardWrong` 与实验 B 无法确证语义因果的原因）。H2 检验在共享基础状态 `Base` 与视觉输入逐查询锁定条件下，单条包含靶冲突事实 $f^-$ 的外部字幕相对靶中性对照 `Neu` 是否因果地改变靶事实输出概率。
- **形式化定义**：在四臂最小配对干预（`Base / Sup / Con / Neu`）下，设立 **2 项预注册主检验**（族内 Holm $\alpha = 0.05$）：
  - `(H2a)` **目标错误事实采纳增加**：$\Delta P(f^-) = \mathbb{P}(f^- \in y_{\text{Con}}) - \mathbb{P}(f^- \in y_{\text{Neu}}) > 0$；
  - `(H2b)` **目标正确事实抑制**：$\Delta P_{\text{supp}}(f^+) = \mathbb{P}(f^+ \in y_{\text{Con}}) - \mathbb{P}(f^+ \in y_{\text{Neu}}) < 0$。
  - 次要分解指标：`Sup vs. Neu`（支持促进 $\Delta P_{\text{fac}}(f^+)$）与 `Neu vs. Base`（中性文本背景偏移）；并按 `Base` 基线状态分层报告**条件性错误新增率**（$f^- \notin y_{\text{Base}}$ 子集）与**错误持续率**（$f^- \in y_{\text{Base}}$ 子集）。
- **自变量 / 因变量 / 控制变量**：自变量为单槽注入文本的靶事实关系（`Sup / Con / Neu`）；主因变量为预定义目标槽位的二元采纳指示 $\mathbb{I}[f^- \in y]$ 与 $\mathbb{I}[f^+ \in y]$；控制查询视频、逐查询锁定视觉输入、共享 `Base`、实际解码器 subword token 长度、词频/句法与盲审流畅度。
- **实验单位与统计检验**：独立来源查询视频（单靶槽位）；10,000 次配对自助法 95% 置信区间 + 10,000 次双侧 Monte Carlo 符号翻转检验（2 项主检验 Holm 校正）。
- **SESOI vs. MDE**：SESOI 设为目标错误采纳概率绝对增加 $\ge 5\text{–}8$ 个百分点；给定正式样本量 $N = 160\text{–}180$ 独立来源视频与预估不一致率，可在 80% 功效下检测约 $7\text{–}9$ 个百分点的 MDE。
- **反驳条件与有限诚实解释**：若 `Con vs. Neu` 在两项主终点上均未达校正显著且 95% CI 覆盖零且窄于 SESOI，则反驳“单条外部文本冲突在视觉固定下稳定诱发靶事实污染”。**不宣称“模型完全免疫”**，而是结合 `Neu vs. Base` 与 `Sup vs. Neu` 的估计精度，如实界定该模型对单条局部冲突具有较强视觉锚定抗性，大预算退化更可能源自多条上下文叠加干扰而非单条冲突复制。

### 假设 H3（跨模型接口与跨数据集的迁移与边界假说，对应 RQ3 / E5）
- **理论动机**：`v0.8` 仅测试了单一 2023 年代跨门控检查点（Video-LLaMA/Vicuna-7B），且 `test2690` 已经过多轮分析。H3 通过**解耦设计**分别检验：① 在共同 MSR-VTT 查询子集上，同一文本干预与预算变化在旧式跨门控架构与现代原生视频大语言模型之间的异同；② 同一现代视频模型在 MSR-VTT 与未触碰新来源队列（如 VATEX）上的跨数据集一致性。
- **形式化定义**：
  - `(H3a 跨模型/跨接口，共同 MSR-VTT 查询)`：在相同查询与相同文本证据下，估计现代 VLM 的内部配对效应（`k=1 vs. 0`、`k=7 vs. 1` 的 $(\Delta N_C, \Delta N_S)$ 及 E3 `Con vs. Neu` 的 $\Delta P(f^-)$），并与 Video-LLaMA 在同一查询子集上做配对交互差（DiD）比较；
  - `(H3b 跨数据集，同一现代 VLM)`：在经来源 ID 零重叠审计的未触碰确认队列（如 VATEX）上，独立复测同一现代 VLM 的预算事实转移与 E3 靶干预效应；
  - `(H3c MSVD 匹配零点复核)`：在原 Video-LLaMA MSVD 3-context 检查点上补跑带完整运行时 trace 的 `A0 + A1 + A3`（训练区间内），检验 MSR-VTT 的 `A1 > A0` 净效用是否在 MSVD 跨基准复现。
- **实验单位与统计检验**：各检验家族内部独立执行来源聚类配对自助法 + Monte Carlo 符号翻转检验 + 族内 Holm 校正；**绝不跨模型直接比较绝对 CIDEr 均值**，仅比较各自相对自身 $k=0$ 或 `Neu` 的内部配对差值。
- **反驳条件与有限诚实解释**：若现代 VLM 在共同查询及新数据集上均未表现出与 Video-LLaMA 同向的事实污染或预算退化，则反驳“跨架构普遍脆弱性”假说，并在区间精度内界定该效应具有**接口/能力依赖性**（不声称现代模型“绝对免疫”）。

## 8. Experiment E1：事后选择收益估计与数学有效置换规范（P0 修订五）

E1 的明确定位是**利用既有冻结资产执行的零 GPU 前置探索诊断**，用于摸清逐查询 CIDEr 效用异质性中有多少属于跨参考一致信号、有多少属于参考采样噪声。**E1 不是决定 E2/E3 科学价值的唯一准入门槛**——即便 CIDEr 层面的逐查询异质性难以在推理前预测，E2 与 E3 关于视频事实转移与语义冲突因果敏感性的科学问题依然独立成立。

### 8.1 严格区分四个不同层级的收益估计量

为杜绝概念混淆与“伪上界”误导，E1 将四类统计量明确分离并并列汇报：
1. **同参考集事后最大分数（Same-Reference Post-Hoc Max）**：在同一完整参考集 $R_v$ 上对每个视频取 $\max_{k \in \mathcal{K}} \text{CIDEr}(y(v,k), R_v)$。该值必然包含严重的参考采样选择偏差，仅作基线参照，**绝不宣称为真实可实现上界**；
2. **跨参考集验证的事后选择收益估计（Cross-Reference Validated Post-Hoc Selection Gain）**：将每条视频的人工参考句随机平衡劈分为互不相交的两半 $(R_{1,v}, R_{2,v})$，在 $R_{1,v}$ 上挑选最优预算 $k^*(v; R_1) = \arg\max_{k \in \mathcal{K}} \text{CIDEr}(y(v,k), R_{1,v})$，在**独立的另一半 $R_{2,v}$** 上评估该选定输出与固定最佳基线（如 `A1`）的配对差：
$$\hat{\Delta}_{\text{xRef}}(v) = \text{CIDEr}\big(y(v, k^*(v; R_1)),\, R_{2,v}\big) - \text{CIDEr}\big(y(v, A1),\, R_{2,v}\big)$$
   **重要边界**：该量记为“跨参考集验证的事后选择收益估计”，**不称作严格 oracle 上界，也不宣称完全消除了所有胜者诅咒**（因为 $R_{1,v}$ 与 $R_{2,v}$ 仍共享同一视频画面及同一组标注者的语言风格相关性）；
3. **不使用参考答案的折外策略收益（Out-of-Fold Pre-Inference Policy Gain）**：在严格按 YouTube `source_id` 分组的 5 折交叉验证中，**明确区分训练目标与推理输入特征**——在训练折内部，允许使用开发集参考答案与已有冻结预测计算监督标签（如逐查询最优预算或净收益差）；但在预测模型输入侧，仅允许输入推理前可观测特征 $\mathbf{x}_{\text{pre}}(v, C)$（如 X-CLIP 相似度、top-1/top-2 落差、候选池内部一致性与句长），**严禁任何参考答案或尚未生成的输出文本进入输入特征**；在留出验证折上评估预测策略相对固定 `A1` 的真实得分差；
4. **独立未触碰队列上的实际可部署策略收益（Deployable Out-of-Sample Policy Gain）**：仅在未来若需验证具体策略时，在协议冻结后的独立新来源队列上一次性评估。

### 8.2 修正置换漏洞：为何“同步置换”数学恒等，以及如何执行有效“解耦置换”

**对 `v1.0` 的关键数学纠错**：若在视频内部用同一个随机置换 $\pi_v$ 同时重排选择侧 $R_1$ 和评价侧 $R_2$ 的预算标签，那么选出的索引变为 $\pi_v^{-1}(k^*)$，代入 $R_2$ 后取出的仍是**完全相同的那条字幕及其完全相同的 $R_2$ 得分**——置换统计量恒等于观测值，鉴别力为零！

**规范的解耦评价侧置换方案（Decoupled Evaluation-Side Permutation）**：
- **零假设 $H_0$**：在每条视频内部，于参考半集 $R_1$ 上选出的“最优预算” $k^*(v; R_1)$ 在独立参考半集 $R_2$ 上并不比从候选预算集合 $\mathcal{K}$ 中随机抽取一个预算具有更高的期望得分（即跨参考集的一致排序信号为零）。
- **打破的对应关系**：固定每条视频在 $R_1$ 上的选定索引 $k^*(v; R_1)$，**仅在评价侧 $R_2$ 上对预算—得分映射施加独立随机置换 $\sigma_v$**（打破选择侧与评价侧之间的臂对齐关系），计算置换统计量：
$$T_{\text{obs}} = \frac{1}{N} \sum_{v=1}^{N} \text{CIDEr}\big(y(v, k^*(v; R_1)),\, R_{2,v}\big), \qquad T_{\text{perm}}^{(b)} = \frac{1}{N} \sum_{v=1}^{N} \text{CIDEr}\big(y(v, \sigma_v^{(b)}(k^*(v; R_1))),\, R_{2,v}\big)$$
- **手工数值示例（验证鉴别有效性）**：假设某视频在 3 个预算臂 $(A0, A1, A7)$ 上，$R_1$ 得分为 `(60, 80, 70)`，$R_2$ 得分为 `(62, 78, 69)`：
  - *错误同步置换*：设 $\pi = (A1, A7, A0)$，重排后 $R_1 = (80, 70, 60)$、$R_2 = (78, 69, 62)$；$R_1$ 仍选中第 1 位，对应 $R_2$ 仍为 `78`，6 种置换全部恒得 `78`（零鉴别力！）；
  - *正确解耦置换*：固定 $R_1$ 选出第 2 臂（观测 $R_2$ 得 `78`），仅对 $R_2$ 得分 `(62, 78, 69)` 做 6 种独立置换，在 6 种置换中第 2 臂以各 $1/3$ 概率取到 `62`、`78`、`69`，零分布期望为 `(62 + 78 + 69) / 3 = 69.67`，观测超额 `+8.33`；若反过来 $R_2$ 实为噪声 `(78, 62, 69)`（即 $R_1$ 选中的臂在 $R_2$ 反而最差），观测值 `62` 低于零分布均值 `69.67`（超额 `−7.67`）。由此证明解耦置换能严格鉴别跨参考一致性与纯采样噪声！
- **双基准并行解释**：上述解耦置换检验的是“跨参考选择是否优于随机选臂”；而配对统计量 $\hat{\Delta}_{\text{xRef}}(v)$（以固定 `A1` 在 $R_2$ 上的得分为参照，配合来源聚类自助法）直接回答“跨参考逐查询选臂是否优于最佳固定单臂 `A1`”。二者互补，缺一不可。

### 8.3 参考集劈半的实现细节（IDF、尺度、重复劈半、聚类与 MSVD 适配）

- **独立 IDF 拟合**：在每次劈半中，**分别仅用 $R_1$ 全队列参考句拟合 $R_1$ 的文档频率（DF），仅用 $R_2$ 全队列参考句拟合 $R_2$ 的 DF**，彻底切断两半之间的语料级 DF 泄漏；
- **评价尺度说明**：半集参考句数量减半（MSR-VTT 由 20 句变为 10 句）会系统性改变 CIDEr 绝对幅值，因此所有比较均严格限制在**同一半集尺度 $R_2$ 内部配对求差**，不将半集绝对分与 20 句全集绝对分混比；
- **重复劈半与来源聚类**：执行 $B_{\text{split}} = 20$ 次固定种子独立随机平衡劈半并取视频级均值，再在最外层按 YouTube 来源簇执行配对自助法估计不确定性，同时汇报单次劈半间标准差以反映劈半随机性；
- **MSVD 非均匀参考数适配**：MSVD 每视频人工参考句数量不统一（通常约 20–80 条），劈半时对每条视频独立执行等规模平衡抽半（每半取 $\lfloor |R_v| / 2 \rfloor$ 条，奇数时每次随机丢弃 1 条以保证两半完全对称），并事前记录 `test670` 中的最小单视频参考数，避免低参考数视频产生异常极端方差。

## 9. Experiment E2 与 E3：事实转移与受控因果主实验设计（P0 修订一、二、四）

### 9.1 Experiment E2：自然检索下的配对视频事实转移（对应 RQ1 / H1）

- **数据复用与队列隔离**：直接复用已冻结的 MSR-VTT `A0 / A1 / A7` 预测输出（零新增主模型 GPU 成本）。严格区分两个互不重叠的独立来源抽样子集（均要求每 YouTube 来源最多 1 条视频，按 top-1 X-CLIP 相似度低/中/高三层先验随机分层，**严禁按 CIDEr 涨跌抽样**）：
  1. **E2a 标注校准与可行性试点队列（100–120 个独立来源视频 × 3 臂）**：用于完成标注手册定稿、实测人工吞吐率、验证两阶段标注一致性、估计配对不一致率与方差（供正式样本量计算），以及独立校准辅助自动评价器。**为杜绝选择偏差，若在审视 E2a 结果后对任何研究细节做出调整，E2a 绝不并入确认性样本池！**
  2. **E2b 正式分析队列（180–200 个与 E2a 源级零重叠的独立来源视频 × 3 臂）**：在标注规程与主假设完全冻结后一次性盲法标注并运行预设的 4 项 Holm 主检验（`A1 vs. A0` 与 `A7 vs. A1` 上的 $N_C$ 与 $N_S$），同时完整汇报八类状态转移明细、核心事件覆盖率及证据对齐子集 `Align(T)` 占比。

### 9.2 Experiment E3：视觉输入固定下的四臂最小配对靶事实干预（对应 RQ2 / H2）

E3 彻底吸纳 P0 修订四的四项核心要求，杜绝与历史 `HardWrong` 或实验 B 的任何混杂重叠：

#### 9.2.1 共享基础输入 `Base` 与四臂结构
所有四臂严格共享同一查询视频 $v$、同一冻结参数 $\theta$、同一解码配置 $d$ 与同一基础证据状态 `Base`：
- **主设置（跨模型共享核心设置，`Base = A0`）**：
  - `Base`：$T = \emptyset, V = \emptyset$（零外部证据基线）；
  - `Sup`：$T = (c_{\text{Sup}}), V = \emptyset$（单条支持预定义靶事实 $f^+$ 的外部字幕）；
  - `Con`：$T = (c_{\text{Con}}), V = \emptyset$（单条包含最小冲突靶事实 $f^-$ 的外部字幕）；
  - `Neu`：$T = (c_{\text{Neu}}), V = \emptyset$（单条对靶事实严格中性的对照字幕）。
  - *采用 `Base = A0` 为主设置的科学优势*：无头部多条字幕缓冲干扰、无外部视觉张量差异，使 Video-LLaMA（$I_{\text{x-gate}}$ 零外部视觉态）与现代原生视频 VLM（$I_{\text{prompt}}$）在**完全一致的四臂文本输入**下可进行干净的跨模型行为对比！
- **单一敏感性设置（仅在 Video-LLaMA 上执行，`Base = B3`）**：保留逐查询哈希锁定的 3 条固定检索图文对作为共同 `Base = B3`，仅在第 4 个纯文本空 clip 槽位（$r = 3$ 严格不变）注入 `Sup / Con / Neu`，用以检验在已有 3 条真实检索上下文背景下，单条新增冲突的边际因果效应是否被稀释或放大。**严禁同时铺开 $k=1, 3, 5, 7$ 多个不同头部预算导致实验失控。**

#### 9.2.2 中性对照 `Neu` 与最小配对文本的严格构造规范
- **`Neu` 的四项刚性标准（明确不再使用含 `Unverifiable` 命题的字幕）**：
  1. **相对靶事实严格中性**：既不蕴含 $f^+$，也不蕴含或反驳 $f^-$，也不通过强常识联想暗示 $f^+$ 或 $f^-$（例如若靶事实是“切胡萝卜 vs. 切土豆”，`Neu` 不能出现“正在做胡萝卜汤”或“拿着削皮刀削土豆皮”）；
  2. **与查询视频其余画面事实相容**：`Neu` 须真实描述查询视频 $v$ 中另一条与靶槽位无关的可见事实（如人物穿着、场景环境或另一独立可见元素，判定为 `Supported`），**不包含其他错误事实**；
  3. **多维表面匹配与实测 token 记录**：在构造 `Sup / Con / Neu` 三条单句时，匹配句法结构简洁度、VideoUFO 语料风格与词频层级，并**实际使用目标模型分词器（Vicuna-7B 与现代 VLM 各自 tokenizer）统计并汇报三臂实际 subword token 长度均值与配对绝对差中位数**（目标配对差 $\le 2$ subword tokens）；同时保留诚实表述——*匹配 token 长度、句法与自然度显著降低了表面文本混杂，但不能宣称“完全剥离了所有文本表层变化”*；
  4. **无视频自然度盲审**：随机抽取 25% 的 `Sup / Con / Neu` 文本组，在不展示视频的前提下由独立审阅者盲评语法流畅度与自然度，防止 `Con` 出现生硬的“编辑伪迹”。

#### 9.2.3 靶事实范围、清晰分解的正负效应与基线分层
- **靶事实聚焦高频核心两维**：每条视频锚定唯一预定义靶槽位，平衡覆盖两类最高频且可明确核验的事实类型——`Action-Role`（动作谓词或论元角色，50%）与 `Entity`（核心交互物体/主体，50%），避免四维均分导致子维样本过薄。
- **剔除混合的 `Sup − Con`（原 `TFFL`），改为清晰分离的四项行为对比**：
  1. **主终点 1（冲突诱发靶错误增加，`Con vs. Neu`）**：$\Delta P(f^-) = \mathbb{P}(f^- \in y_{\text{Con}}) - \mathbb{P}(f^- \in y_{\text{Neu}})$；
  2. **主终点 2（冲突导致靶正确抑制，`Con vs. Neu`）**：$\Delta P_{\text{supp}}(f^+) = \mathbb{P}(f^+ \in y_{\text{Con}}) - \mathbb{P}(f^+ \in y_{\text{Neu}})$；
  3. **次要终点 1（支持促进靶正确采纳，`Sup vs. Neu`）**：$\Delta P_{\text{fac}}(f^+) = \mathbb{P}(f^+ \in y_{\text{Sup}}) - \mathbb{P}(f^+ \in y_{\text{Neu}})$；
  4. **次要诊断 2（中性文本背景偏移，`Neu vs. Base`）**：检验加入一条与靶无关的相容文本是否本身已造成靶事实提取率漂移。
- **按 `Base` 输出状态严格分层**：由于部分查询在 `Base` 下可能原本就未说出 $f^+$ 或原本已误说出 $f^-$，论文同时汇报：
  - **总体边际采纳概率差**（全部样本 $N$ 上的主估计量，保持无条件配对随机化完整性）；
  - **基线分层条件转移率**：在 $f^- \notin y_{\text{Base}}$ 子集上汇报**靶错误新增率**，在 $f^- \in y_{\text{Base}}$ 子集上汇报**靶错误持续率**；在 $f^+ \in y_{\text{Base}}$ 子集上汇报**靶正确丢失率**。绝不把总体概率差直接等同于每个案例的“新增错误”。

#### 9.2.4 最小配对因果证据 vs. 自然 VideoUFO 冲突的严格划界
保留自然检索生态效度验证（在 VideoUFO 真实 top-20 候选池中筛选经人工核验为自然支持靶事实 vs. 自然冲突靶事实的候选子集），但在科学推论上划清红线：
- **最小配对四臂（`Base / Sup / Con / Neu`）** 提供的是**受控行为因果证据**；
- **自然 VideoUFO 检索冲突对比** 提供的是**真实外部语料环境下的观察性关联佐证**（因为自然检索字幕同时在长度、背景信息量、多事实冲突数与句式上变化，**绝不将自然 `Sup` 与自然 `Con` 的差值直接解释为单一事实冲突的纯因果效应**）。
- 同时修正过强模态表述：在纯文本干预设置中，避免的是“**外部字幕与其自身配对外部视频特征**”之间的内部不一致；而**查询视频 $v$ 与冲突字幕 $c_{\text{Con}}$ 之间的图文语义冲突本身正是本实验主动施加的目标干预**。

## 10. Experiment E5：解耦的跨模型、跨接口与跨数据集验证（P0 修订六）

为彻底避免将“换模型架构 + 换证据接口 + 换数据集域”混为一谈，E5 采用**严格的 2×2 解耦验证设计**，并明确将 **E4（新证据选择算法开发）移出主要计划贡献**（仅作为未来工作或后续独立分支考量；即便未来评估任何启发式策略，也必须以实际效用 $N_S$、事实风险 $N_C$、覆盖率与端到端算力成本为核心评价，绝不以单一 AUROC 定夺部署价值，且严禁将“未观测到显著退化”宣称为非劣效证明）。

### 10.1 2×2 解耦验证结构

| 验证轴 | 固定不变的因素 | 变化的因素 | 具体执行方案 | 可合法得出的结论边界 |
|---|---|---|---|---|

### 10.3 MSVD 匹配 `k=0` 的收据复核与真实成本修正

## 11. 人工标注架构、单位对齐、自我偏好防御与真实工作量核算（第 X 节修订）

审慎评估表明：**本升级方案最大的现实瓶颈不是 GPU 算力，而是高质量人工视频核验的人力吞吐与一致性保障**。本节对 `v1.0` 过于乐观的“每视频 2.5–3.5 分钟”估算进行彻底修正，按真实工序拆解并解决标注单位不一致与自动裁判自我偏好两大隐患。

### 11.1 先解决标注单位对齐，再计算三值一致性（三阶段解耦标注流）

若两位标注员各自自由切分原子命题，必然出现命题边界和条数不一致（一人切 3 条、一人切 4 条），此时**直接套用命题级 Cohen's $\kappa$ 在数学上是无效的**！本设计采用成熟的三阶段解耦规程：
- **Stage 0（手册标定与双人切分一致性审计，25–30 视频）**：两位标注员先在 25–30 个独立标定视频上**独立切分命题并独立执行受限对齐**，计算**切分单元级 F1 / 重合率（Unitization Overlap F1）与对齐一致率**；根据分歧修订《原子命题切分与受限对齐手册 v1.0》，直至切分单元 F1 $\ge 0.85$；
- **Stage A（共享盲法切分与对齐表生成）**：正式标注中，由经过标定的单一规范化切分员（或“中性 LLM 规范提议 + 盲法人工编辑全量逐条审核”，全程**隐藏臂名与外部检索字幕**）生成每条视频唯一的共享盲法命题与受限对齐工作表；
- **Stage B（双人独立盲法真值判定与核心事件标注）**：两位独立标注员观看完整静音查询视频，在**完全相同的共享命题列表**上各自独立标注 `{S, C, U}`（并勾选 1–2 个核心事件）。由于标注单位 100% 锁定，此时计算命题级 **Krippendorff's $\alpha$（名义三值）** 与 **Cohen's $\kappa$** 严格有效！
- **Stage C（第三方分歧裁决 + 事后检索对齐标记）**：由第三位仲裁者盲法裁决 Stage B 全部三值分歧；**仅在真值与对齐彻底锁死后**，再由独立核对步骤标记每个新增 `C` 命题是否与所供外部文本 $T$ 语义对齐（`Align(T)`），彻底隔绝确认偏误。

### 11.2 辅助自动评价器的校准隔离与自我偏好防御

- **双集合物理隔离**：人工标注集切分为独立的**自动评价器校准集**（用于调整原子提取/核验提示与阈值，例如 E2a 试点中抽取的 60 视频）与**自动评价器独立验证集**（例如 E2a 其余 60 视频，从未参与调优，用于无偏汇报人机 $\kappa$、按臂偏差与长度偏置）；
- **自我偏好（Self-Preference Bias）防御**：如果 E5 选定 `Qwen2.5-VL-7B-Instruct` 作为被测现代生成器，**严禁仅使用 Qwen2.5-VL 家族充当 E5 的自动裁判**！必须采用**跨模型家族辅助裁判**（例如以 `InternVL2.5-8B` 或 `LLaVA-Video-7B` 交叉核验），且在所有核心科学假设（H1–H3）的确认性结论中，**始终以双盲人工核验结果作为唯一主要依据**，自动裁判仅作全队列敏感性参考。

## 12. 统计分析、功效核算与防数据泄漏铁律（P0 修订七）

1. **彻底区分三个统计概念**：
   - **SESOI（最小实际有意义效应）**：基于任务语义设定的科学关注门槛（例如 E2 中 $|\Delta N_C| \ge 0.15$ 条/视频、E3 中 $\Delta P(f^-) \ge +6$ 个百分点）；
   - **MDE（最小可检测效应）**：在给定样本量 $N$、配对标准差/不一致率、显著性水平 $\alpha$（经族内 Holm 校正后）与目标功效（如 80%）下，统计检验能够稳定检出的最小效应量；
   - **试点可行性检查（Pilot Feasibility Check）**：M0/M1 试点只用于检验流程是否可跑通、切分与三值一致性是否达标、人工真实吞吐是多少、以及估计正式样本量所需的配对方差/不一致率——**不把“120 视频试点是否达到 $p < .05$”当作是否否定存在事实效应的科学裁决，也绝不在看过试点效应方向后把试点样本并入正式确认集！**
2. **移除所有缺乏依据的机械硬门控**：删除 `v1.0` 中未经论证的 `AUROC 0.65 / 0.68`、`污染率 15%`、`TFCE 8%` 等武断门槛，改为基于独立试点测得的方差与不一致率，在冻结正式协议前执行公开透明的先验功效核算。下表给出不同配对不一致率下的双侧配对检验参考样本量（按族内 Holm 最严阈值 $\alpha_{\text{eff}} = 0.05 / 2 = 0.025$、功效 80% 估算）：

| 场景与目标效应 | 典型配对不一致率 $p_{\text{disc}}$（或配对 SD $\sigma_d$） | 单次检验 80% 功效所需独立来源视频 $N$ | 经 2 项 Holm 校正（$\alpha=0.025$）所需 $N$ | 统计解读 |
|---|---|---|---|---|
| E3 靶错误采纳差 $\Delta P(f^-) = 10\%$ | $p_{\text{disc}} = 0.16$ | $\sim 126$ | $\sim 152$ | $N = 160\text{–}180$ 具备良好检测效能 |
| E3 靶错误采纳差 $\Delta P(f^-) = 7\%$ | $p_{\text{disc}} = 0.15$ | $\sim 240$ | $\sim 290$ | $N = 160$ 仅具中等功效（约 55%），须以 CI 宽度客观解读 |
| E2 错误命题数差 $\Delta N_C = 0.20$ 条/视频 | $\sigma_d = 0.75$ 条/视频 | $\sim 111$ | $\sim 135$ | $N = 160\text{–}180$ 具备充分效能 |
| E2 错误命题数差 $\Delta N_C = 0.15$ 条/视频 | $\sigma_d = 0.75$ 条/视频 | $\sim 196$ | $\sim 238$ | 试点实测 $\hat{\sigma}_d$ 后可精确锁定最终 $N$ |

3. **推断方法与措辞严密性**：
   - 所有主比较采用固定种子的 10,000 次来源聚类配对自助法（95% 逐项百分位 CI）与 10,000 次双侧 **Monte Carlo 符号翻转置换 $p$ 值**（明确标注为 Monte Carlo 近似，分辨率 $10^{-4}$，不称无条件精确 $p$ 值）；
   - 各主实验内预设极简主检验家族并执行 Holm 校正（E2 主族 4 项、E3 主族 2 项、E5 各解耦轴主族各 2–4 项），次要指标与分面拆解归入探索性汇报（BH FDR 控制）；
   - 任何不显著结果**绝不解读为等效（equivalence）或非劣效（non-inferiority）**，严格按 95% 置信区间涵盖范围解读；
   - `Uncertain` 标签处理同 `v1.0`：主终点 $N_C$ 与 $N_S$ 以完整样本数 $N$ 为分母，`Unc` 独立汇报占比，不剔除任何含 `Unc` 的查询。

### 14.2 四种实验结果下的克制、诚实分支预案

1. **分支 1（H1 与 H2 均获支持，且 H3 显示清晰跨接口规律或边界）**：按上述标准结构成文，核心贡献稳固落在“共同零证据参照的配对事实转移评价 + 视觉受控靶事实行为因果识别 + 跨接口与新数据边界分析”。
2. **分支 2（H1 事实转移清晰，但 H2 单条最小配对冲突效应未达校正显著）**：绝不强行归因于“模型完全免疫”或事后加样！按 95% 置信区间宽度诚实界定：*在单条冲突文本与视觉锁定条件下，未能证实超过当前检测精度的定向污染效应；自然大预算中的事实变化更可能与多条上下文联合干扰、句长扩张或未控语义因素相关*。
3. **分支 3（H1 与 H2 在正式样本中均未获统计支持）**：**绝不默认宣称“证明 CIDEr 存在指标失真”**，而应严格按实际估计精度（置信区间宽度、核心事件覆盖与句长/词面分布证据）客观汇报“在当前采样精度下未检出大额原子事实变动”，并理性评估是否仍具独立诊断价值或直接转回路线 C（投稿 `v0.8`）。
4. **分支 4（现代原生视频 VLM 与 Video-LLaMA 在共同查询上呈现显著分化）**：正视并突出**接口与基础能力依赖性**——对比两者相对各自零外部证据基线的 $(N_C, N_S)$ 轨迹与 E3 敏感度，说明不同视觉编码与证据注入接口对外部字幕的依赖与风险特征存在系统差异（不宣称现代模型绝对免疫）。

## 15. 尚待用户、ChatGPT 与导师共同裁决的开放问题

在进入任何代码编写或标注试标之前，以下 **6 项核心决策** 仍需共同确认（详见 `OPEN_SCIENTIFIC_DECISIONS.md`）：
1. **资源与路线抉择**：面对真实人工工作量（路线 A 试点约 **35–43 人时**；完整路线 B 约 **130–196 人时**，同时兼顾法律 RAG 论文），是先启动**路线 A**实测一致性与吞吐后再做 Go/No-Go，还是直接启用**路线 C**将已完备的 `v0.8` 投向 SCI Q3？
2. **人工团队落实**：M0/M1/M2/M3/M4 所需的 2 名独立盲法标注员 + 1 名仲裁员（及 Stage A 盲法切分复核）人选能否落实？
3. **E2 主终点确认**：是否正式批准以双主终点 $(\Delta N_C, \Delta N_S)$ 替代单一标量 `B_fact`，并将“核心事件覆盖率”纳入重要次要指标？
4. **第二现代模型最终选型**：从 `Qwen2.5-VL-7B-Instruct`（Apache 2.0）、`LLaVA-Video-7B-Qwen2`（Apache 2.0）与 `InternVL2.5-8B`（MIT）中确定主力模型（并指定跨家族模型作为可选辅助自动裁判以防自我偏好）。
5. **未触碰确认队列核实**：核查 BN 服务器上获取 **VATEX** 公开英文子集（600–800 独立来源，须重跑 X-CLIP 特征与 VideoUFO 检索）的可行性与有效视频留存率，并决定是否同步在 VATEX 上测试原 Video-LLaMA。
6. **MSVD 匹配零点范围与 `v0.8` 暂缓投稿纪律**：确认 MSVD 采用 trace-matched 3 臂（`A0+A1+A3`，~1.5–2.2 GPU 小时）还是 4 臂（加 `A7`），并确认在 Q2 路线决定前暂缓投出 `v0.8` 以避免重复发表冲突。
