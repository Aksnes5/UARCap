# Stage M0-small：最低成本人工标注可行性试点协议（v0.1）

> **协议状态**：`DESIGN_REFINED_AWAITING_FEASIBILITY_AUTHORIZATION`（**本轮尚未实际抽取任何视频、尚未启动任何标注、尚未编写任何抽样或分析代码**；须待用户审阅并明确授权后方可执行）  
> **核心定位**：将原 `v1.1` 路线 A（35–43 人时 + MSVD GPU）拆分为极低成本前置闸门——**仅用 16 个独立来源历史 MSR-VTT 视频、0 GPU 小时、约 9–13 人时**，先行实测标注规程是否可操作、L1–L4 一致性是否达标、以及 AI 草稿辅助是否真能提效且不漏召回。

---

## 1. 试点目的与严格禁令

### 1.1 五项明确工程与方法学目标
1. 检验《视频事实性人工标注手册 v0.1》的原子切分规则、防无限细分原则与 `S/C/U/Ø` 边界在真实 MSR-VTT 字幕上是否清晰可操作；
2. 检验 L2 核心事实预先选取（`R_core`）的稳定性和双人覆盖评分一致性；
3. 实测全部 **5 项独立一致性指标**（R1 切分 F1/召回、R2 三值 $\alpha/\kappa$、R3 L3 对齐 F1、R4 L2 加权 $\kappa$、R5 `Align(T)` $\kappa$）；
4. 精确计时测量每道工序的真实人工吞吐量（分钟/视频），并**实证对比“纯人工切分”与“AI 草稿 + 人工盲审”的真实耗时与命题召回率**（绝不预设 AI 一定更快更好！）；
5. 试跑 L1–L4 全四层结构（含 8 视频 L3 与 8 视频 L4 靶模拟），为是否进入 Stage M1 及 M1 的合理规模提供硬数据支撑。

### 1.2 三条绝对红线（严禁逾越）
- **绝不用于验证假设 H1 / H2 / H3**：16 个视频完全不具备假设检验统计效能，**严禁根据 M0-small 结果宣布“事实错误机制成立”或“不存在事实效应”**；
- **绝不并入未来正式确认样本**：M0-small 属于流程压力测试与手册校准样本，其 16 个 YouTube 来源 ID 将被永久记录并从未来 M1 与 E2b 正式队列中排除；
- **本阶段不启动任何 GPU 任务**：包括 MSVD 3 臂在内的全部新增 GPU 推理一律暂缓，直至 M0-small 判定通过。

## 2. 样本规模、复用资产与盲法抽样原则

- **最终推荐规模**：**16 个来源独立的历史 MSR-VTT 视频**（位于 12–20 建议区间正中，且可精确均分为 `8 + 8` 两组执行 AI 草稿对照审计、L3 试标与 L4 靶模拟）。
- **100% 复用冻结资产**：直接复用 `bn_v06_full_ab` 已冻结的 `A0 / A1 / A7` 三臂字幕（16 视频 × 3 臂 = **48 条字幕**），**0 新增推理**。
- **事前分层随机抽样规则（待授权后执行一次，本轮不选样）**：
  1. 抽样池为 `test2690`（或已排除 300 先导的完整冻结查询池），按每个视频的 YouTube `source_id` 强制去重，**每来源至多入选 1 条视频**；
  2. 按 top-1 原始 X-CLIP 相似度三分位数（低/中/高三层）先验随机抽取（5 + 6 + 5 = 16 个独立来源视频），固定随机种子记录；**严禁查看或依据 CIDEr 涨跌、句长或错误率挑样**；
  3. 仅检查原始视频文件可读且未损坏；若偶遇损坏文件按预定备选清单顺序递补并记录。
- **匿名化与双盲分装**：每条视频的 3 条输出打乱顺序重新赋码为 `Cap_1 / Cap_2 / Cap_3`，映射密钥仅由不参与标注的协调人保存；外部检索字幕 $T$ 在 L1/L2 结束前彻底封存。

## 3. 标注者具体工作流与职责分工（5 步闭环）

参与人员最小配置：**2 位独立盲法标注员（A / B）+ 1 位仲裁/协调员（C，可由导师或第三位合作者担任）**。每位成员必须同步在 `TEMPLATE_05_TIME_LOG_M0SMALL.csv` 中用秒表记录各步骤实际耗时（精确到 0.5 分钟）。

### Step 1：视频先行提取 L2 核心事实清单（全部 16 视频，纯人工）
- A 与 B **在完全未见过任何生成字幕前**，各自独立静音观看 16 段完整视频，填写 `TEMPLATE_01_CORE_FACTS_L2.csv`（每视频 1–3 条核心事实）；
- C 比对 A 与 B 的核心事实清单重合度（计算清单核心事件重合率），经简短校准合并为 16 段视频的唯一标准核心事实清单 $\mathcal{K}_{\text{core}}(v)$。

### Step 2：命题切分与 AI 草稿召回率/效率对照审计（全部 16 视频 = 48 字幕）
- 将 16 个视频随机平分为 **组 I（8 视频，24 字幕）** 与 **组 II（8 视频，24 字幕）**：
  - **组 I（纯人工双人独立切分基准）**：A 与 B 各自独立盲法手写原子命题，计算**双人切分单元重合 F1 与命题数 ICC（R1）**；同时将中性开源模型生成的 AI 草稿与双人仲裁后的标准人工命题比对，精确测出 **AI 草稿命题召回率（Recall）与系统性遗漏类型**；
  - **组 II（AI 草稿 + 人工盲审修正流）**：向 A 与 B 提供匿名化的 AI 初始命题草稿，由二人各自独立审核修正并计时，与组 I 纯人工切分耗时直接对比，实证检验 AI 草稿是否真能提效且不引入切分偏置！
- 完成后由 C 汇总 48 条字幕的唯一**共享盲法规范命题表**进入 Step 3。

### Step 3：L1 三值真值判定 + L2 核心覆盖打分（全部 16 视频 = 48 字幕）
- A 与 B 在完全相同的 `TEMPLATE_02_ATOMS_TRUTH_L1.csv` 共享表上，静音回看视频，独立完成：① 每条原子命题的 `{S, C, U}` 判定（含 `uncertainty_reason`）；② 每条字幕对照 Step 1 核心事实清单的 `{0, 0.5, 1.0}` 覆盖打分；
- 独立提交后计算 **R2（L1 命题级 Krippendorff's $\alpha$、Cohen's $\kappa$、视频级 `N_C`/`N_S` ICC）** 与 **R4（L2 线性加权 $\kappa$、视频级 `R_core` ICC）**，由 C 盲法裁决全部 L1/L2 分歧并锁定真值。

### Step 4：L3 精细转移与事后证据对齐试跑（随机指定 8 视频，24 字幕）
- 仅在 Step 3 真值彻底锁死后，对预先随机指定的 8 个视频揭开“哪条是零证据基线”的成对分组（仍隐藏具体是 `A1` 还是 `A7`），A 与 B 独立在 `TEMPLATE_03_TRANSITIONS_L3.csv` 上执行受限同指对齐与八类转移标记，计算 **R3（对齐 F1 与转移标签 $\kappa$）**；
- 对齐锁定后，再向二人开放对应视频的外部检索文本 $T$，独立判定新增错误是否满足 `Align(T)`，计算 **R5（二元 $\kappa$ 与正类一致率）**。

### Step 5：L4（E3 靶事实构造与五态判定）流程模拟（其余 8 视频，无需新跑模型）
- 选取其余 8 个视频，由 C 依据静音视频试构造 8 组预定义靶事实 $(f^+, f^-)$ 与最小配对文本草稿（`Sup / Con / Neu`），评估单条靶事实构造真实耗时与自然度审查难点；
- 利用现有匿名输出（或模拟测试句）让 A 与 B 在 `TEMPLATE_04_E3_TARGET_L4.csv` 上独立完成 **L4 五态判定（`NEITHER / ONLY_POS / ONLY_NEG / BOTH / AMBIGUOUS`）**，计算 L4 五态 Cohen's $\kappa$ 并计时。

## 5. 流程可行性裁决标准（Proceed / Revise / Stop）

M0-small 完成后，不看任何假设检验 $p$ 值，仅依据以下**操作与信度指标**做出三选一工程裁决：

| 裁决等级 | 必须满足的实测条件 | 后续行动 |
|---|---|---|
| **PASS（可进入 Stage M1）** | 1. 切分重合 F1（R1）$\ge 0.80$；<br>2. L1 三值 Krippendorff's $\alpha$（R2）$\ge 0.70$；<br>3. L2 核心覆盖加权 $\kappa$（R4）$\ge 0.70$；<br>4. 单视频 L1+L2 团队总耗时 $\le 15$ 分钟（使后续扩大规模人力可承受）；<br>5. 若 L3 对齐 F1（R3）$\ge 0.75$ 且 R5 $\kappa \ge 0.70$，则保留 L3 子集；否则进入“降级通过”（仅保留 L1+L2+L4，删去 L3）。 | 按实测耗时、可用人手与方差估算需求，**动态规划 Stage M1 样本量**（不机械硬定 120 视频）；并择机解冻 MSVD 3 臂 GPU 任务。 |
| **REVISE（修订手册再小测）** | 任一核心信度指标处于边缘区间（如 R2 $\alpha \in [0.55, 0.70)$ 或 R1 F1 $\in [0.68, 0.80)$），但分歧集中于 1–2 类明确规则模糊点（例如粒度或身份判定），且耗时可控。 | 针对分歧点修订《标注手册 v0.2》，仅允许在 **8 个新独立视频**上做一次复测；复测仍不达标则自动触发 STOP。 |
| **STOP（停止升级，转投 `v0.8` Q3）** | 1. 修订后 L1 三值 $\alpha$ 仍 $< 0.60$ 或 L2 $\kappa < 0.60$；**或**<br>2. 实测单视频总耗时 $> 20$ 分钟，导致按保守推算完整方案需 $> 220$ 人时、超出团队现实上限；**或**<br>3. 标注团队无法持续落实双人盲法与仲裁。 | **理性止损，启用路线 C**：零追加 GPU 投入，直接完善已完备的 `v0.8` 通用投稿包并投向 SCI Q3 期刊。 |
