# Visual signature generation

The formal archive contains 600 queries and 4,200 D Top-7 pair slots, with 2,622 unique representative clip IDs in the official VideoUFO manifest. A clip is the first member of the frozen caption group's clip list, matching the generator arm builder. The locator joins the official clip and source ID. It reads one declared representative of an archive member and checks optional available byte hashes.

Supply either an already verified JSONL with `clip_id`, `source_id`, `path`, optional `member` and optional `sha256`, or a read-only inventory JSON with `assets` containing known directories or ZIP/TAR paths. Run `scripts/generate_visual_signatures.py index --inventory <inventory> --retrieval <formal_retrieval.jsonl> --clips <clips_full.tsv> --out <location.jsonl>`. It lists exact MP4 matches, records ambiguities and indexes archive metadata without bulk extraction. Put the verified mapping in the V2 preflight path `data/source_witness/videoufo_clip_locations.jsonl`. Compressed TAR archives may require sequential reading. An existing trusted member index is preferable for repeated access.

The `sign` phase computes video SHA, 16 unique uniform decoded frame indices, PTS and duration, dHash, DCT pHash and center-crop pHash. Cache keys pin the decoder policy and local shard/file witness. Missing assets and invalid decoding become UNVERIFIED. The comparator distinguishes byte duplicates, near-duplicate risk under fixed offsets/crop, no obvious signature risk, and unverified pairs. The near-duplicate screen has unknown recall for other edits and anonymous sources.

The risk sensitivity output retains parent-paired baseline estimands and separately excludes confirmed and confirmed-plus-high-risk queries. Missing signatures remain visible in denominators. Any historical v0.8 result retains its original source and version. The factorial decoder stages only the fixed Top-1 assets for the 40 planned queries using eight frames per clip.
