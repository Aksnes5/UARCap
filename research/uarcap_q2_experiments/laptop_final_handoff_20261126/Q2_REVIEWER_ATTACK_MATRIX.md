# 审稿问题与可提交证据

| 问题 | 目前可回答的部分 | 仍需承认的边界 |
| --- | --- | --- |
| 与 Fang 等前作的区别 | 固定继承实现在百万级库下研究访问与效用。本阶段连接现实任务、可验证的事实端点与两类证据干预。 | 检索预算、质量重排和跨门控已有前作。 |
| 候选相似度为什么不等于收益 | 检索相似度、进入提示的选中证据、生成端效用是三个测量对象。 | 尚无机制能排除所有其他解释。 |
| 为什么 CIDEr 预算方向不同 | 数据分布、参考形式、模型和注入接口均会改变响应。修正逐视频键错位后保留语料均值。 | 不能仅由方向变化断言事实与传统指标必然背离。 |
| 数据集可否直接比较 | 报告各自同查询差值。 | 单参考、多参考和核心事件定义存在差异。 |
| 长度是否混杂 | 固定 Qwen cohort 的详细提示、配对长度和长度相近分析。 | 该修改同时改变信息表达目标，长度是后处理变量。PENDING。 |
| 跨模型公平性 | 报告预算差分，EVCap 有同系统受控拆分入口。 | 模型接口、训练分布和视觉表示仍有整体区别。 |
| 为什么采用机器评价 | 先覆盖大规模生成，再由原概率样本和独立评审核验。 | 没有真人数据，暂称自动代理。 |
| 两个评价器会共同出错吗 | 给出实际逐臂差和配对变化差，按相同事实集合比较。 | 一致并不提供真值。独立核验尚待执行。 |
| 错误自然证据来源 | 指向实际 Top-7 字幕、秩、clip 和原子事实对应。 | 语义任务 PENDING，不能推断内部来源。 |
| 受控干预是否适用自然检索 | E3-Bridge 用真实外库来源构造文本干预。 | 需要 >=30 个合法候选，文本注入不能完全重现自然多模态运行。 |
| 中性是否成立 | 独立双 tokenizer、文本逻辑、逐命题视觉验证和兼容门禁。 | 旧 Neu 已失效，V2 尚无真实通过候选。 |
| 16 帧是否遗漏动作 | 同命题的两组视觉输入与时间戳。 | 32/64 均为帧采样，完整视频核查仍需要人工。 |
| 数据污染 | 官方来源列已验证，旧正式 E3 与历史 MSR-VTT 有两条重叠，V2 排除。 | CaReBench 匿名源和近重复不能据此排除。 |
| 是否有事后选择 | 原协议目标和主比较单列，修复版本和候选淘汰有账本。 | 本轮延伸属于探索性。 |
| 主要终点是否被改写 | 仅原两个终点进入既定家族，预算与采样、成本另报。 | 人工收据全未提供。 |
| 如何解释负面结果 | 同样保留效应估计、分母、未确认及科学门禁。 | 不把不显著解释为不存在。 |
| 有何应用意义 | 同系统对预算、质量、参考冲突、覆盖和实际算时作权衡。 | 全预算曲线与必要资产仍 PENDING。 |
