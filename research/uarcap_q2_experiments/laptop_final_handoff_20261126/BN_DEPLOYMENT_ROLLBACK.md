# 安全撤回与恢复

发布路径固定为 `deploy/laptop-20261126-v1`，输出写到 `outputs/laptop-20261126-v1`。旧运行目录与 git 分支作为只读事实源。安装首先写出带时间戳的队列快照 `task_queue.before_q2l_*.json`，之后在相同目录原子更新队列。旧任务被安全替换时，原记录保存在 `superseded_task_records`，原任务状态及输出依旧可查。

1. 记录当前实时任务、审批记录、快照 SHA 和正在运行的服务。若本发布任务还在执行，等待自然结束，再进行队列撤回。
2. 使用同一 BN 版本命令和批准文件，将 `--install` 换成 `--rollback`。它仅从 active 队列撤回 `q2l_v1_` 项，保留任务状态、其他项目维护人员新增的工作和全部结果。被判定失效的旧 E3 任务继续保存在历史记录中。
3. 重新部署同一版本可保留已完成任务。输入或配置改变时，新建 release 路径、任务 ID 和输出目录。完整性不匹配的旧输出留存供查看。
4. 旧队列快照可用于人工核查。若后续记录已写入，先比较差异再恢复特定条目。共享 GPU 忙时任务包装器等待或让调度器重试。外部 PID 由原工程管理者处理。
